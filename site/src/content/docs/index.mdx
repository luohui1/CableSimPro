## 给谁用

<CardGrid>
  <Card title="电缆厂技术部" icon="document">
    导入厂家结构表，逐项核对标准尺寸、电气参数与短路容量，生成型号载流量表和正式规格书。
  </Card>
  <Card title="研究院" icon="magnifier">
    新建工程，做直埋等敷设方式的载流量研究，改条件对比结果，输出计算书和研究报告；需要时把有限元仿真提交到 Slurm 超算集群。
  </Card>
</CardGrid>

## 四项核心能力

<CardGrid>
  <Card title="载流量计算" icon="rocket">
    IEC 60287 稳态载流量、GB 50217 校正和热网络交叉校核。结果注明口径（单回路、全回路共同或条件上限），缺数据时明确拒绝，不估算兜底。
  </Card>
  <Card title="电缆设计" icon="pencil">
    型号库与结构表导入、按产品标准核对尺寸、计算电气参数与短路容量、生成载流量表和规格书，版本经审核后才可交付。
  </Card>
  <Card title="电缆仿真" icon="setting">
    有限元温度场、暂态与电热耦合仿真，并与 IEC 结果对照；原生求解在超算上运行，结果保存网格与收敛证据。
  </Card>
  <Card title="Agent" icon="comment">
    在对话中读取工程、整理条件、起草研究；Agent 只提出方案，保存、计算和发布都由人确认。
  </Card>
</CardGrid>
