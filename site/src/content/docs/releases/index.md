当前为开发中的版本，宿主版本号 0.1.0 系列，工程输入格式第 1 版（`cablesim.domain/1`）。在软件“设置 → 关于”中可以看到宿主版本、输入格式，发行包的 `/api/release-info` 还会返回构建编号和源码提交。各计算插件的版本见[方法清单](../methods/catalog/)。

## 本版本包含

### 安装与运行

- Windows 10 / 11 x64 与 Linux x86_64 离线安装包：自带 Python 3.12 运行时和全部依赖，安装与计算全程离线，不需要管理员权限。
- 升级前自动快照工程库，健康检查失败自动恢复；支持回退到上一版本。
- 工程库备份与恢复（界面、命令行与接口）。

### 电缆型号

- 厂家结构表导入：Excel / CSV，工作表选择、列映射保存与复用、系列声明、逐行预览与逐项来源，人工确认后入库。填写系列声明时即检查同名系列，入库报错显示在对应按钮旁。
- 型号系列：批量标准核对、批量载流量计算、批量审核和独立改版；批量操作的结果显示在工具栏下方。
- 公开样本对照：各规格共用的说明在表格上方只写一次。
- 部件与研究模板：把已保存型号的部件或成功运行的研究定义冻结为参考草稿，人工确认后采用到另一个工程；冻结证据按工程单位显示。
- 型号设计：结构、执行标准、标准尺寸核对、电气参数、短路容量、载流量表、规格书的生成、评审与发布。
- 标准核对插件发行 1.8.6（方法 1.8.5）：修复型号设计页“执行标准核对”预检通过但运行失败的问题。

### 载流量与仿真

- IEC 60287 稳态载流量：多回路直埋、排管与矩形回填，单芯与独立屏蔽三芯，护套与铠装损耗，交叉热源降额。
- GB 50217 附录 D 载流量校正；简化热网络交叉校核。
- 有限元温度场、暂态、护套损耗与电热耦合（Slurm 超算），与 IEC 的对照及收敛证据。
- 运行记录、两次运行对比、参数扫描。

### 交付

- 计算书（客户版 / 内部审核版）PDF 与 HTML 存档；规格书 PDF。
- 正式交付接口：规格书、计算书、载流量表和研究报告的固定来源预览与 PDF / Excel 导出，支持按工程或系列批量导出。

### Agent

- 工作台内的 Agent 对话：读取工程、研究、型号与运行结果；每一次建立、修改、运行和导出都是固定内容的提案，须由人在对话中接受后执行。
- 对话中建立研究、重算与对比、编制载流量表、核对型号并生成计算书和规格书；计算书与规格书经正式交付服务输出，含四个签栏和追溯页。
- 对话中导入厂家结构表：上传原件、保存预览、草稿入库、标准核对四步，逐步人工接受。
- 长对话自动压缩；上下文窗口与最大输出在“设置 → AI 模型”中设置。
- 接入 OpenAI 兼容接口的模型，包括内网私有化部署的模型。
- 离线安装包暂不含 Agent 对话服务，目前只有从源码运行的一键演示提供 Agent 对话。
