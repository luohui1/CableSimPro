## 部署与安全

- **没有账号与权限管理**。访问到服务的人都可以读写全部工程，只能在单机或受信任的内网中使用，不要暴露到公网。见[内网部署](../../install/intranet/)。
- 安装包只支持 Windows 10 / 11 x64 和 glibc 兼容的 Linux x86_64，不支持 ARM，也不保证所有 Linux 发行版。
- 一个数据目录同时只能运行一个实例。
- Agent 对话服务异常退出后不会自动重启；工作台其余功能继续可用，重新启动程序即可恢复。
- Linux 版随包的 Node.js 需要系统提供 libstdc++，并满足安装前核对的最低 glibc 版本。
- Agent 对话记录（`数据目录/agent/`）不在工程库备份范围内，需要保留时单独备份。

## 界面

- “电缆型号库 · 结构表导入与系列”页面在侧栏中没有单独入口，从“资源 → 电缆型号版本”页的“导入厂家结构表”进入。
- 标准核对的判定写作“待补数据”，方案对比中同一类情况写作“缺项”，两处含义相同。

## 数据

- 公开厂家目录只有结构尺寸，缺少材料密度、出厂实测值等资料；这类型号可以导入、核对和计算载流量，但补齐资料并通过评审前不能发布规格书。
- 示例库中标有“演示”的型号和工程用于核对文档与计算流程，不代表厂家产品承诺。
- 结构表导入生成的型号，其结构层用途等字段尚无逐项出处，目前不能创建为参考部件；研究模板目前只支持 IEC 60287 稳态载流量的单工况研究。

## 计算方法

每种方法的完整限制写在插件清单中，并显示在对应的方法页：

| 方法 | 主要限制 |
| --- | --- |
| [IEC 60287](../../methods/iec-60287/) | 地下稳态、恒温地表；不支持分层土壤、多介质分区和土壤干燥；部分单芯多回路排列需要外部损耗系数。 |
| [GB 50217 校正](../../methods/gb-50217/) | 仅 10 kV 及以下、单根基准；不支持排管、桥架、多层、回填和外部热源；D.0.6 / D.0.7 未实现。 |
| [热网络](../../methods/thermal-network/) | 仅单回路三根相同无铠装单芯电缆；附加损耗系数为输入假设；只作交叉校核。 |
| [有限元](../../methods/fem/) | 需要 Slurm 超算集群；二维截面模型，不含三维端部、绞合和土壤水分迁移。 |
| [标准核对](../../methods/standard-check/) | 仅已核验的 XLPE 结构与第 2 类导体 R₂₀；未收录的标准与条款标为未覆盖。 |

标为“未经独立验证”的能力只作参考研究使用，见[方法清单](../../methods/catalog/)。

## Agent

- 需要接入支持工具调用的 OpenAI 兼容模型；未接入时 Agent 不可用，其他功能不受影响。
- Agent 的写操作都是提案，须由人在对话中接受；审核、批准和发布不能由 Agent 完成，它的回答不是工程依据。
- 有限元、原生仿真与超算作业不能在对话中提交，须在工作台中确认。
- 对话中导入结构表，每条消息的附件合计不超过 1 MiB，单批最多 100 个规格。
