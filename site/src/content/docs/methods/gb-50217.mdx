插件 `cablesim.gb50217-correction` 不自己计算载流量。它把**有出处的单根电缆基准载流量**（厂家样本或已保存的载流量表）按 GB 50217—2018《电力工程电缆设计标准》附录 D 的校正系数换算到实际敷设条件。

## 原理

校正后的允许电流等于基准值乘以各适用校正系数之积：

$$
I = I_0 \prod_i K_i
$$

环境温度不在表 D.0.1 的格点上时，按标准 D.0.2 规定的公式计算温度校正系数：

$$
K_t = \sqrt{\frac{\theta_m - \theta_2}{\theta_m - \theta_1}}
$$

$\theta_m$ 为导体最高允许温度，$\theta_1$ 为基准环境温度（空气 40 °C、土壤 25 °C），$\theta_2$ 为实际环境温度。其余系数只按表内条件取值，表外的土壤热阻率、根数或间距**不插值、不外推**，直接拒绝。

## 公式来源

全部系数和公式取自 GB 50217—2018 附录 D（标准印刷第 72–74 页）：

| 条款 | 条件与取值规则 |
| --- | --- |
| 表 D.0.1 | 10 kV 及以下，环境温度校正，取表内唯一单元格 |
| D.0.2 | 其他环境温度按上式计算，不是表格外推 |
| 表 D.0.3 | 土壤热阻率校正，只适用于表 C.0.1-2 的 1 kV PVC、70 °C、基准土壤热阻率 1.2 K·m/W |
| 表 D.0.4 | 同深度直埋、并列 2–6 根，净距为表内条件；不用于三相交流单芯电缆 |
| 表 D.0.5 | 空气中单层、并列 2–6 根，中心距与直径之比为表内条件；不用于三相交流单芯电缆 |

系数通过[标准依据库](../standard-check/#标准依据库)查询，只接受已核验、唯一命中、带原件摘要和页码的结果。每个系数保存查询条件、单元格位置、公式输入和依据库发行摘要；依据库发行变化时拒绝静默换表，已保存的工程继续固定原来的依据。

## 适用范围

- 10 kV 及以下；均匀土壤直埋，或空气中单层水平等间距排列。
- 基准必须是同型号、同正常导体温限、同中心埋深的**单根**电缆载流量，已经乘过并列系数的基准不能再用。
- 每个回路为一根多芯电缆；并列电缆须为同一型号和直径，间距一致。
- 并列校正的结果是所有回路等负荷时每根电缆的允许电流，不是并联电流之和。

## 超出范围时

不在表内的条件不插值、不外推，插件拒绝计算并指出需要修改的字段，不输出电流。常见提示：

| 情况 | 提示 |
| --- | --- |
| 排管、桥架、多层或回填 | “仅覆盖均匀土壤直埋或空气单层敷设；排管、桥架、多层与回填未覆盖。” |
| 日照或强制风冷 | “日照或强制风冷不在本次已实现的表格范围内。” |
| 有外部热源 | “存在外部热源，本方法不叠加热源校正。” |
| 系统电压高于 10 kV | “环境温度校正只覆盖附录 D 的 10 kV 及以下范围。” |
| 实际中心埋深与基准不同 | “实际中心埋深与基准不同；附录 D 不提供通用埋深校正，请改用完整计算。” |
| 基准环境温度不是空气 40 °C 或土壤 25 °C | “本版只接受表 D.0.1 的基准：空气 40 °C / 土壤 25 °C；不作系数比值外推。” |
| 厂家基准的土壤热阻率与实际不同 | “表 D.0.3 不适用于任意厂家基准；实际与基准土壤热阻率不同，请使用完整计算。” |
| 并列根数、净距或中心距比不在表内 | 原因代码 `CORRECTION_TABLE_NOT_COVERED`，指向敷设截面中的电缆位置 |
| 并列电缆间距不一致 | “并列电缆间距不一致，本版不采用平均间距。” |
| 三相交流单芯电缆并列 | “表 D.0.4 / D.0.5 不适用于三相交流单芯电缆。” |
| 并列电缆型号不同 | “并列电缆必须为相同型号与直径，不对混合型号套表。” |
| 没有填写系统线电压 | “请填写系统线电压；不能由型号额定电压代替。” |
| 标准依据库发行已变化 | 原因代码 `BASIS_VERSION_CHANGED`：“标准依据库发行已变化；请读取当前方法契约并重新核对依据，不能静默换表。” |
| 没有勾选“基准条件已人工核对” | “请核对基准载流量、单根敷设条件、正常温限和原件出处，再确认基准已核对。” |

“完整计算”指 [IEC 60287](../iec-60287/) 或[有限元](../fem/)方法。D.0.6、D.0.7 本版未实现，相关条件明确拒绝，不能用 D.0.4 / D.0.5 代替。

## 输入要求

| 参数 | 单位 | 要求 |
| --- | --- | --- |
| 基准载流量 | A | 必填；同型号、单根、同温限、同埋深 |
| 基准环境温度 | °C | 必填；空气 40 °C 或土壤 25 °C |
| 基准土壤热阻率 | K·m/W | 必填 |
| 基准类型 | — | 厂家基准，或表 C.0.1-2 的标准基准 |
| 基准中心埋深 | m | 必填，须与实际埋深相同 |
| 基准原件名称与条件出处、原文页码 | — | 必填 |
| 基准原件或保存工件摘要 | — | 必填，原件的 SHA256 |
| 基准条件已人工核对 | — | 必须由工程师勾选 |
| 标准依据库发行摘要 | — | 由方法契约给出 |

实际环境温度、导体温限、介质、并列根数和间距取自研究中保存的同一份输入。

## 验证算例

下列算例用手算的系数乘积核对插件结果，系数经标准依据库实际查询，并核对查询返回的页码和原件摘要。算例中的 400 A 基准是为核验给定的值，不是厂家额定值。

| 条件 | 系数（条款） | 结果 |
| --- | --- | --- |
| 空气 30 °C，导体温限 90 °C，基准 40 °C | 1.09（D.0.1） | 400 × 1.09 = 436 A |
| 表 C.0.1-2 基准（1 kV PVC、70 °C），土壤 20 °C，热阻率 1.5 K·m/W | 1.05（D.0.1）× 0.93（D.0.3） | 390.6 A |
| 土壤 30 °C，三根直埋、净距 0.1 m | 0.96（D.0.1）× 0.85（D.0.4） | 326.4 A |
| 空气 30 °C，三根单层、中心距为 2 倍直径 | 1.09（D.0.1）× 0.98（D.0.5） | 427.28 A |
| 土壤 27 °C（不在表格点上），导体温限 90 °C | D.0.2：√((90−27)/(90−25)) ≈ 0.9845 | 公式值，不是表格插值 |

同一组测试还核对拒绝路径：三根直埋、净距 0.15 m 不在表内（`CORRECTION_TABLE_NOT_COVERED`）；厂家基准改变土壤热阻率被拒绝；依据库摘要变化时报 `BASIS_VERSION_CHANGED`；温度错误指向需要修改的那一个值。

## 已知限制

- 结果的可信度取决于基准：基准由工程师核对，校正结果不是 IEC 完整热路计算，也不代表厂家保证值。
- 不支持排管、桥架、多层、回填、日照、强制风冷和外部热源；不提供埋深校正。
- D.0.3 只用于表 C.0.1-2 的标准基准；D.0.4、D.0.5 不用于三相交流单芯电缆。

## 与 IEC 结果比较

在研究中用“方法对比”与 IEC 60287 比较时，只与“全回路共同能力”口径配对，分别列出两者的允许电流和差值，以及各自的方法范围，不判定优劣。
