标准核对由两个插件配合完成：

- `cablesim.standards-basis`（标准依据库）：离线、只读地查询已逐格核验的标准数值，返回原值、单位、适用条件、页码和来源摘要；
- `cablesim.standard-check`（产品标准尺寸核对）：用依据库的数值逐项核对型号的结构尺寸和导体 R₂₀，记录条款、余量、数据缺项和未覆盖的范围。

## 原理

对每一项结构尺寸，按型号的额定电压、导体截面、芯数和材料，在执行标准的对应表格中查出规定值，再与型号的标称值、最小值或实测值比较：

| 核对内容 | 示例 |
| --- | --- |
| 绝缘标称厚度与最薄点 | GB/T 12706.2—2020 表 7（XLPE） |
| 内衬、隔离套、外护套厚度 | GB/T 12706 第 2 部分相关条款 |
| 铠装（钢带、钢丝）尺寸 | 与芯数、外径对应的表格 |
| 导体 20 °C 直流电阻 | GB/T 3956 第 2 类导体上限 |

每一条记录写明所用条款、规定值、实际值、余量和结论；缺少实际值（例如需要出厂实测的最薄点）时记为“缺项”，依据库尚未收录的条款记为“未覆盖”，**不会用相近条款或推测值代替**。标准符合与否只说明尺寸，是否批准发布由人工另行决定。

## 标准依据库

依据库的每个数值都经过两路独立核验（原页转录与独立提取），保存原件的页码与 SHA256。查询必须唯一命中；空格、缺项和版本变化明确区分。依据库作为插件整体发行，方法会记录所用发行的摘要；依据库更新后，已有工程保持原来的绑定，需要工程师重新确认才会更换。

在软件的“资源 → 标准与规则”中可以按条款或数值检索依据库，查看每个值的原页出处并复制引用。

## 适用范围

- 已核验的 XLPE 绝缘、表内额定电压，单芯与三芯结构；第 2 类导体 R₂₀ 的已核验条目。
- 其他材料、导体类别或表外数值保留为“未覆盖”。
- 标准结构提案：由明确的输入提出圆形 XLPE 结构，提案须人工确认后才成为型号设计。

## 输入要求

型号的执行标准声明（标准及版本）、额定电压、芯数、导体截面与类别、各层材料与尺寸；需要实测的项目填写出厂实测记录及来源。
