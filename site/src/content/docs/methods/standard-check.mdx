标准核对由两个插件配合完成：

- `cablesim.standards-basis`（标准依据库）：离线、只读地查询已逐格核验的标准数值，返回原值、单位、适用条件、页码和来源摘要；
- `cablesim.standard-check`（产品标准尺寸核对）：用依据库的数值逐项核对型号的结构尺寸和导体 R₂₀，记录条款、余量、待补数据和未覆盖的范围。

## 原理

对每一项结构尺寸，按型号的额定电压、导体截面、芯数和材料，在执行标准的对应表格中查出规定值，再与型号的标称值、最小值或实测值比较。每一条记录写明所用条款、规定值、实际值、余量和判定。限值、公式、修约和判定都在插件中执行，不用 IEC 60287 的热计算替代产品标准核对。

## 公式来源

| 核对内容 | 条款 | 规则 |
| --- | --- | --- |
| XLPE 绝缘标称厚度 | GB/T 12706.2—2020 §6.2 表 7；GB/T 12706.3—2020 §6.2 表 6；GB/T 11017.2—2024 §6.2.2 表 2 | 按额定电压与截面查表 |
| 绝缘最薄点 | GB/T 12706.2/.3—2020 §17.5.2 式 (4) | 不小于 0.9 × 标称厚度 − 0.1 mm |
| 绝缘厚度偏差 | §17.5.2 式 (5) | (最大厚度 − 最小厚度) / 最大厚度 ≤ 15% |
| 铜带屏蔽厚度与搭盖率 | GB/T 12706.2—2020 §10.2.3；GB/T 12706.3—2020 §10.2.2 | 三芯单带标称不小于 0.10 mm，最薄点不小于单带标称的 90%；搭盖率标称 15%、最小 5% |
| 内衬层厚度 | GB/T 12706.2—2020 §8.2.3 表 9；GB/T 12706.3—2020 §8.2.3 表 7 | 按假定直径查表 |
| 外护套标称厚度与最薄点 | §14.3 式 (3)；附录 A、附录 B | 标称厚度为 0.035 × 假定直径 + 1.0，修约到 0.1 mm；最薄点不小于 0.8 × 标称 − 0.2 mm |
| 假定直径 | 附录 A（A.2.4、A.2.9、A.2.10） | 每步按附录 B.1 修约到 0.1 mm；最薄点按表 B.1 修约到 0.01 mm 后比较 |
| 铠装材料、尺寸与测量 | GB/T 12706.2—2020 §13.2、§13.5 表 10/11、§13.6、§13.7、§17.7 | 圆丝测量平均直径不小于标称的 95%，钢带最薄值不小于标称的 90%；双钢带间隙不大于带宽一半 |
| 隔离套 | GB/T 12706.2—2020 §13.3.3 | 按相邻金属层与纵向阻水声明判定是否需要 |
| 110 kV 金属护套与外护套标称厚度 | GB/T 11017.2—2024 §6.6.2 表 3、§6.7.2 表 4 | 按截面查表 |
| 第 2 类导体 R₂₀ | GB/T 3956—2008 §5.2.2、§5.3.2 表 2 | 不大于表列上限；厂家声明的上限不作为实测值 |

依据库保存原件的页码和 SHA256，不分发标准全文。

## 判定

| 判定 | 含义 |
| --- | --- |
| 满足 | 有完整输入和标准依据，判定满足 |
| 不满足 | 有完整输入和标准依据，判定不满足 |
| 待补数据 | 判定所需的数值缺失；需要出厂实测的项目（如绝缘最薄点）在取得实测值之前也是待补数据，不用标称值代替 |
| 未覆盖 | 依据库尚未收录该条款或版本，依据栏显示“本库暂未收录”；**不能视为满足**，由工程师按标准原文人工核对 |

不适用于本型号结构的条款不参与判定。层标称厚度、单带标称厚度、最薄点和最大、平均实测厚度互不替代；采用更厚的设计标称值时，最薄点要求随之提高。标准符合与否只说明尺寸，是否批准发布由人工另行决定。

## 标准依据库

依据库的每个数值都经过两路独立核验（原页转录与独立提取），保存原件的页码与 SHA256。查询必须唯一命中；空格、缺项和版本变化明确区分。依据库作为插件整体发行，方法会记录所用发行的摘要；依据库更新后，已有工程保持原来的绑定，需要工程师重新确认才会更换。

在软件的“资源 → 标准与规则”中可以按条款或数值检索依据库，查看每个值的原页出处并复制引用，见[资源库](../../guide/resources/#标准与规则依据浏览)。

## 适用范围

- 已核验的 XLPE 绝缘、表内额定电压，单芯与三芯结构；第 2 类裸铜、镀层铜和铝导体 R₂₀ 的已核验条目。
- GB/T 12706.1/.2/.3—2020、GB/T 11017.2—2024、GB/T 3956—2008 中已实现的条款。
- 标准结构提案：由明确的输入提出圆形 XLPE 结构，提案须人工确认后才成为型号设计。

## 超出范围时

核对不会因为条款未收录而失败，也不会用相近条款、其他版本或推测值代替：

- 依据库没有收录的条款或版本记为“未覆盖”，例如 GB/T 11017.1—2024（110 kV 绝缘、金属护套和外护套的最薄点）、GB/T 11017.2—2014（铜丝平均间隙算法）。
- 非 XLPE 绝缘、第 1、5、6 类导体电阻、表外尺寸、供需协议变更和未核验的制造试验要求记为“未覆盖”。
- 缺少故障电流和持续时间时，金属屏蔽或护套截面不作合格判定。
- 假定直径链中有未覆盖的分支（如附加包带、未知构造）时，依赖它的护套公式停止判定。
- 缺少判定所需的数值时记为“待补数据”，在型号设计中定位到对应的结构层或字段。

运行本身失败时（例如依据版本需要重新核对、输入字段缺失），型号设计显示该次运行的实际错误和缺失字段的位置，见[型号设计 · 标准核对](../../guide/type-design/#3-标准核对)。

## 输入要求

型号的执行标准声明（标准及版本）、额定电压、芯数、导体截面与类别、各层材料与尺寸；材料须有明确的标准类别，不从名称推测。需要实测的项目填写出厂实测记录及其来源。

## 验证算例

三个真实型号的公开数据经手工核对，人工算值与插件结果对拍。它们是公开资料的核对草稿，不是三个整体合格的产品：

| 型号 | 已判定的项目 | 未完成判定的项目 |
| --- | --- | --- |
| 江南 YJV22 8.7/15 kV 3×240 | 绝缘标称厚度 4.5 mm，满足（GB/T 12706.2 表 7） | 绝缘最薄点要求 3.95 mm、厚度偏差、铜带、内衬与外护套、R₂₀ 上限 0.0754 Ω/km：缺少厂家数据 |
| 江南 YJV22 26/35 kV 3×240 | 绝缘标称厚度 10.5 mm，满足（GB/T 12706.3 表 6） | 绝缘最薄点要求 9.35 mm 等：缺少厂家数据 |
| 起帆 64/110 kV 1×800 | 绝缘标称厚度 16.0 mm、外护套标称厚度 4.5 mm，满足（GB/T 11017.2—2024） | 最薄点：GB/T 11017.1—2024 未收录；皱纹铝套厚度与短路容量：缺少数据 |

另有一组独立公式对拍（给定相同的三芯结构作为条件输入）：8.7/15 kV、240 mm² 时外护套前假定直径 66.0 mm，外护套标称厚度 3.3 mm，最薄点 2.44 mm；26/35 kV 时假定直径 94.7 mm，标称厚度 4.3 mm，最薄点 3.24 mm。3×300 钢带铠装时铠装前假定直径 70.3 mm、铠装后 73.5 mm。逐项数值见[产品标准尺寸核对](../notes/standard-check/)。

## 已知限制

- 第 1 部分的内衬层、护套、最薄点及成缆分支尚未全部覆盖；带隔离套或金属套的完整尺寸链尚未接齐。
- 设计输入、厂家上限与实测值分别标记；本核对不批准要求、型号或产品认证。
- 依据库只覆盖文档列出的完整表及条款，不外推、不跨版本补值；标准全文不随软件分发。
