交付文件只读取已经保存的工程和运行记录生成，**不会重新计算**，也不会自动提交审核或批准。每份文件都能追溯到所用运行的输入快照、方法版本和插件封签。

| 文件 | 从哪里生成 | 依据 |
| --- | --- | --- |
| 规格书 | 型号设计 → 规格书 → **生成规格书**；发布后为 **导出 PDF** | 型号的结构、电气参数、载流量、短路容量和标准核对五部分结果 |
| 载流量表 | 型号设计 → 载流量表中计算；正式文件通过下文的正式交付接口导出 | 一次载流量表运行，保留每条工况的条件、回路、单位、口径和缺项；普通单次研究不能冒充载流量表 |
| 计算书 | 研究工具栏 → **生成计算书** → 预览 → **下载 PDF** | 研究中选定的一次完整运行 |
| 研究报告 | 正式交付接口 | 同一工程中明确选择的 1–16 次运行，按运行逐一呈现方法、条件、结果及已有比较，不生成运行里不存在的结论 |

## 客户版与内部审核版

- **客户版**：结论、敷设图、分组结果与方法依据，供交付客户。
- **内部审核版**：另含完整输入、诊断和来源明细，供内部校核。

规格书在型号发布前是“编制草稿”，页眉页脚标明未批准发布；签字栏供人工填写，电子批准与发布状态以系统记录为准。

## 交付存档

侧栏“记录 → 交付”列出所有已生成的交付文件，可按工程或型号筛选并重新下载存档。存档就是当时生成的文件，不会按新数据重新计算。

## 追溯

- 计算书的“来源”页列出所用运行、宿主对输入与结果一致性的校验和方法版本。
- 运行必须属于所选工程、已完成并通过输入 / 输出完整性校验；只完成一部分的运行保留缺项原状。
- 历史运行按其历史状态呈现，不会借当前方法版本或默认参数替换。
- 有限元温度场必须有合格的收敛证据才能正式导出。

## 面向集成的接口

需要把交付文件接入其他系统时，可以使用宿主的正式交付接口：先预览固定来源，再导出 PDF 或 Excel，并支持按工程或系列成员批量导出整包。接口说明见[正式交付文件契约](../../develop/host/formal-deliveries/)和[接口参考](../../develop/api/)。
