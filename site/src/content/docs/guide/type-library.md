型号库保存电缆型号的固定版本，研究按版本引用它们。数据可以来自厂家结构表、厂家资料（PDF 原件）、工程师给定或型号设计。每个数值都保留来源和可信分档：原表实测、标准限值和工程补充互相区分，不会混在一起。

## 两个入口

| 页面 | 地址 | 用途 |
| --- | --- | --- |
| 电缆型号版本 | 侧栏“资源 → 电缆型号版本” | 浏览全部型号版本，按来源筛选，查看每个版本的结构与出处；右上角“从厂家资料导入”用于导入 PDF 原件。 |
| 电缆型号库 · 结构表导入与系列 | `/resources/cables/structure-import` | 导入厂家结构表（Excel / CSV），管理型号系列，批量核对、计算和审核。当前版本侧栏还没有入口，需要直接输入地址。 |

## 导入结构表

结构表是厂家目录里“每行一个规格”的表格，例如 YJV22-8.7/15 kV 各截面的导体外径、绝缘厚度、内衬、钢带、护套厚度、外径和重量。导入分五步，完整演示见[快速上手：电缆厂](../../quickstart/factory/)。

1. **选择文件**：`.xlsx`、`.xls` 或 `.csv`，不超过 10 MiB。格式不支持、超限或空文件在上传前就会被拒绝。
2. **选择工作表**：一个文件里有多张表时选其中一张，页面列出列名和示例值供确认。
3. **列映射**：把原表的列对应到目标字段和单位，确认数据起始行。映射可以命名保存，下次导入同一厂家的表时直接复用。
4. **系列声明**：系列名称、制造商、型号、额定电压、芯数、数据身份和各层材料；原表出处（手册名、表号、页码）自动带出。
5. **预览入库**：逐行校验。每行标为“可入库”“缺项”或“错误”，错误会指出原表的行号和列；勾选“确认来源与系列声明”后才能入库。

入库的规格是“草稿 · 待人工核对”的第 1 版。原表没有的数值（如屏蔽厚度、导体电阻）只会按有出处的规则补充，并标明出处和可信分档，例如“取同电压等级公开结构表的列示值”“取 GB/T 3956—2008 表 2 标准上限，非厂家实测值”。

:::note[修改了声明怎么办]
在预览请求进行中修改系列声明或返回上一步，旧预览会作废，不能用来入库。以最后一次预览为准。
:::

## 系列与规格

“系列与规格”标签列出全部型号系列。打开一个系列可以看到每个规格的状态、缺项和下一步，点规格名查看每个数的原表来源，点 **打开型号设计** 进入该规格的型号设计。

勾选规格后可以批量操作，每个操作都要勾选“确认所选规格与版本”才会执行，结果逐个规格列出：

| 操作 | 做什么 |
| --- | --- |
| 批量核对 | 对每个规格运行产品标准尺寸核对，保存真实运行，列出符合项、缺项和依据库未收录项。 |
| 批量计算 | 按一套统一工况（埋深、土壤热阻率、环境温度、接地方式等，须写明来源）对每个规格计算载流量；超出方法范围的规格会被拒算并说明原因。 |
| 批量审核 | 对已提交审核的版本做人工批准或退回；尚未提交审核的草稿会整批拒绝批准。 |

需要修改已入库的规格时，在规格的来源对话框里选择“将当前设计保存为新版本”，填写改版说明并确认，建立独立的新版本草稿。旧版本和它的运行记录保持不变。

## 其他标签

- **公开样本对照**：把软件计算的外径、重量、导体直流电阻和载流量与厂家公开样本逐项对照，并标明哪些是厂家声明、哪些是研究参考情景。
- **材料与环境**：查看厂家手册里与材料、敷设环境有关的原始资料。这些资料只供查阅，不会自动变成计算输入。
- **数据交换**：把资料和工程导出为 JSON 或 Excel 交换文件，或导入其他实例导出的交换文件。

## 从厂家资料（PDF）导入

在“电缆型号版本”页点 **从厂家资料导入**，上传厂家样本 PDF。软件逐页识别表格和参数，列出候选值、页码和置信情况，由工程师逐项核对后生成型号草稿。扫描件需要可用的文字识别（OCR）能力；没有可用的识别时会明确提示，不会假装识别。
