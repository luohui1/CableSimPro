仿真研究用有限元等数值方法计算电缆和敷设区域的温度场与损耗，用来检查 IEC 60287 解析假设之外的影响，例如有限区域、非均匀土壤、暂态过程和电热耦合。

## 研究任务

| 任务 | 用途 |
| --- | --- |
| 运行温度 | 给定负荷下的稳态温度场。 |
| 暂态温升 | 负荷阶跃或变化时导体温度随时间的变化。 |
| 护套损耗 | 金属护套、铠装中的感应损耗。 |
| 电热耦合 | 损耗与温度相互影响（电阻随温度变化）的稳态解。 |
| 混合载流量参考研究 | 有限元标签与数据驱动模型的对照研究，只作参考。 |

在 **新建研究** 中选择任务和有限元方法（如“电缆有限元仿真 · 电缆有限元热场（IEC 损耗反馈）”“研究敷设截面 IEC 与收敛有限元对比”）。各方法的适用范围见[方法清单](../../methods/catalog/)。

## 在哪里计算

有限元求解、批量仿真和模型训练在 Slurm 超算集群上运行；原生参考插件中规模固定的小型有限元参考算例声明为本机运行。每个方法在哪里运行以[方法清单](../../methods/catalog/)的声明为准，运行前预检也会写明求解位置；只在超算运行的方法遇到超算未配置时会提示配置，不会改到本机硬算。配置方法见[仿真计算环境](../../install/hpc/)。提交后的作业在“记录 → 运行与作业”中查看状态、刷新或取消。

## 结果与证据

- **温度场**：中间视图可以切换敷设截面、电缆截面和三维，温度场按物理尺度绘制。没有有效结果时显示“无数据”，不绘制伪造的场。
- **与 IEC 对照**：同一工况下有限元与 IEC 的温度、电流、损耗逐项对比。两者模型假设不同（如有限计算域与半无限土壤），差异本身不是误差证明，报告会写明差异来源。
- **收敛证据**：保存多档网格的结果、网格和能量平衡检查；没有合格收敛证据的有限元结果不能用于正式导出。

方法原理与验证依据见[有限元对照](../../methods/fem/)；已复现的公开算例和文献案例列在侧栏“方法 → 验证算例”。
