仿真研究用有限元等数值方法计算电缆和敷设区域的温度场与损耗，用来检查 IEC 60287 解析假设之外的影响，例如有限区域、非均匀土壤、暂态过程和电热耦合。方法原理、收敛判据和验证算例见[有限元对照](../../methods/fem/)。

| 研究任务 | 用途 |
| --- | --- |
| IEC 与有限元对比 | 同一保存工况下逐回路反求允许电流，与 IEC 结果并列 |
| 运行温度 | 给定负荷下的稳态温度场 |
| 暂态温升 | 负荷阶跃、周期或应急负荷下导体温度随时间的变化 |
| 护套损耗 | 按相序与接地拓扑计算金属护套、铠装中的感应损耗 |
| 电热耦合 | 损耗与温度相互影响（电阻随温度变化）的稳态解 |
| 混合载流量参考研究 | 有限元标签与数据驱动模型的对照研究，只作参考 |

## 1. 准备：配置超算

有限元求解、批量仿真和模型训练在 Slurm 超算集群上运行。每个方法在哪里运行以[方法清单](../../methods/catalog/)的声明为准；只在超算运行的方法遇到超算未配置时会提示配置，不会改到本机计算。

**打开哪里**：**设置 → 计算位置**，“超算连接”区域。

**填什么**：

| 字段 | 含义 | 要求 |
| --- | --- | --- |
| SSH 别名 | 本机 SSH 配置中的主机别名 | 从列表中选择 |
| 分区 | 提交作业使用的 Slurm 分区 | 必填 |
| 远程工作目录 | 超算上存放作业文件的目录 | 完整路径，须可写 |
| 环境、环境目录 | 超算上的 Python 环境及其根目录 | 必填 |
| 单批核时预算 | 一次提交允许占用的核时上限 | 大于 0，最多 2000 |
| 累计核时预算 | 全部作业累计的核时上限 | 不小于单批预算，最多 20000 |

**点什么**：**保存连接**，再点 **测试连接**。测试依次检查主机可达、分区存在、目录可写和环境可用，失败项分别显示“无法连接”“不存在”“不存在或不可写”“不可执行”。

**看到什么**：状态为“已配置”。管理员用外部配置文件指定超算时，本页只读。完整说明见[仿真计算环境](../../install/hpc/)。

## 2. 新建仿真研究

**打开哪里**：工程浏览器的 **新建研究**。

**填什么**：研究名称；研究任务（例如“IEC 与有限元对比”）；方法参数来源，可以选“插件声明的默认值（缺项需填写）”，或沿用本工程已保存的 IEC 研究参数；敷设截面（必选）。

**点什么**：**建立研究**，进入研究的“温度场”模块，页签为“结果与 IEC 对照”“场图”“取样”“方法参数”“诊断”和“收敛”。

## 3. 填写有限元参数

**打开哪里**：“方法参数”页签的“本次计算参数”。先核对网格、计算域、材料来源和热边界，数值求解选项在“高级参数”中。

**填什么**（以“IEC 与有限元对比”为例）：

| 参数 | 含义 | 单位 | 默认或常见取值 | 要求 |
| --- | --- | --- | --- | --- |
| 网格尺寸 | 电缆附近的单元尺寸 | mm | — | 界面以 mm 输入，保存为 m |
| 远场网格尺寸、网格过渡宽度 | 远离电缆处的单元尺寸及过渡区宽度 | mm | — | 不小于 0 |
| 节点上限 | 单次计算的自由度上限 | — | — | 不小于 100 |
| 截面计算边界 | 计算域的侧边与底边 | m | — | 必填 |
| 多档网格比例 | 收敛检查的网格加密倍率序列 | — | 1.5、1.0、0.75 | 至少三档 |
| 计算域放大倍数 | 检查边界影响时放大计算域的倍数 | — | 2 | 2–4 |
| 温度迭代容差 | 相邻两次迭代的温度变化门槛 | K（温差） | 0.1 K | 0–0.1 K |
| 载流量校核容差 | 反求允许电流的精度 | A | 0.5 A | 0–1 A |
| 确认均匀土对照、确认冻结损耗系数 | 确认 IEC 列按均匀土壤对照、有限元使用冻结的 IEC 损耗系数 | — | 未勾选 | 分层或回填时须勾选确认 |
| 参数来源 | 本组参数的出处说明 | — | — | 必填 |

电热耦合另有温度迭代容差（K）、功率相对容差、最大反馈次数、反馈松弛系数和初始温度（°C）。容差和门槛都是**温差**，以 K 显示和输入；初始温度、环境温度等绝对温度以 °C 显示。

材料的热导率、体积热容、电导率及其有效温区必须有来源，没有默认热容。

## 4. 检查输入与预检

**点什么**：**检查输入**（超算未配置时也可以先做），或 **预检并运行**。

**看到什么**：“预检步骤”区域分两行：

- **输入完整性与范围**：“已通过输入检查”，或“请修正下列缺项”并逐条列出；
- **原生环境**：“已通过超算原生预检”，或“未通过，请核对下列说明”。

“超算核时预算”区域显示“提交 <分区> · 本次核时预算上限 X 核时”和每个工况的节点（自由度）与单元数。实际核时以 Slurm 记账为准。全部通过后，勾选确认并点 **确认并运行**。

## 5. 提交与进度

**看到什么**：“超算运行记录”显示状态（准备、已提交、后处理、连接中断、取消中）、作业号（尚未分配时为“等待 Slurm 回执”）、已用核时与预算以及排队位置。

**可以做什么**：**停止** 当前作业；连接中断后 **恢复原作业** 继续读取原作业，不重新提交；**重新读取进度**。读取失败不会改变已保存的运行。

## 6. 收敛研究

有限元结果必须有合格的收敛证据，才显示为正式值并允许正式导出。

**打开哪里**：“收敛”页签，“自动加密与扩域”。

**点什么**：**设置收敛预算**，在“确认收敛研究预算”中填写累计核时预算（大于 0，不超过 2000），点 **确认预算并开始**。

**看到什么**：

- 逐级提交：每级网格减半或计算域加倍，最多 12 级；完整计算网格上限 400 万节点；达到门槛即停，资源不足或预算耗尽时保留已有结果。
- 收敛判据：“网格与扩域各连续两级变化均小于 X K”（默认 0.1 K）。达到后显示“保存核验已达到门槛 · 门槛 0.1 K”，并在最终网格上反求允许电流。
- “自动收敛保存记录”表逐级列出级别、网格（m）、域深（m）、自由度、热点温度（°C）、变化（K）、核时、墙钟时间（s）和保存运行；图中给出逐级网格与扩域的热点温差。
- 边界说明：“Kennelly 镜像远场”或“环境定温截断”，以及“地表等温”。

**可以做什么**：**停止后续级别**、**恢复原作业**、**回收原作业结果**、**完成载流量封存**、**用当前版本继续**、**重试**。

| 提示 | 处理 |
| --- | --- |
| 尚未收敛：网格与扩域未达到连续两级门槛 | 增加预算继续，或检查网格与计算域设置 |
| 温度收敛已达标；最终允许电流运行失败：… | 按失败原因处理后重试最终一级 |
| 累计核时预算须大于 0 且不超过 2000。 | 修正预算 |

## 7. 读结果

| 页签 | 内容 | 怎么判读 |
| --- | --- | --- |
| 结果与 IEC 对照 | 导体温度、允许电流及与 IEC 结果的对照 | 两者模型假设不同（有限计算域与半无限土壤、集总温度与层内梯度等），差异本身不是误差证明；报告写明差异来源 |
| 场图 | 温度分布、等温线和最热点，按物理尺度绘制 | 没有有效结果时显示“无数据”，不绘制替代的场 |
| 取样 | 指定位置的温度 | — |
| 诊断 | 求解器、网格和能量平衡信息 | 用于核对计算过程 |
| 收敛 | 逐级曲线与门槛 | 没有达到门槛的结果不能正式导出 |

对照类结果标为“仅供参考，未经工程批准”，不自动批准，也不代替 IEC 载流量。

## 8. 超算作业列表

**打开哪里**：工程概览的“超算作业”，或侧栏“记录 → 运行与作业”。

**看到什么**：“所有研究超算作业”表列出研究与运行、Slurm 作业号、状态、已用核时（未结算时显示“未结算”）、开始与结束时间，每页 20 项。**作业详情** 显示所属工程、所属研究、记录、作业号、状态和已用 / 预算核时；**核对状态** 向超算重新查询。

| 状态 | 含义 |
| --- | --- |
| 排队、已提交、准备中、运行 | 作业在超算上排队或运行 |
| 后处理、回收结果 | 求解完成，正在核验和取回结果 |
| 已封存 | 结果已核验并保存 |
| 部分完成 | 部分工况成功 |
| 失败 | 作业失败，原因见作业详情 |
| 连接中断、待恢复 | 与超算的连接中断，原作业保留，可以恢复 |
| 取消待确认、已取消 | 已请求取消或已取消 |
| 资源不足、达到预算上限 | 资源或核时预算不足，已有结果保留 |

## 9. 没有配置超算时

- “求解位置”显示超算方法“未配置”，预检提示“超算未配置，请前往设置 → 计算位置。输入已保存。”，**确认并运行** 不可用。
- **检查输入** 仍可在本机完成；IEC 60287 等解析计算、参数扫描、标准核对、正式交付和备份恢复照常可用；已保存并通过校验的仿真结果仍可查看。

## 10. 状态与报错

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 本方法不能在本机求解。 | 方法只在超算运行，超算未配置 | 先“检查输入”；配置超算后再提交 |
| 配置与能力声明冲突；超算路由与能力声明冲突，请由管理员修正配置后重新预检。输入已保存。 | 计算位置配置与插件声明不一致 | 由管理员修正配置 |
| 已有超算配置无效，请修正后保存。 | 保存的配置不完整或无效 | 修正后保存 |
| 先保存修改，再检查连接。 | 超算设置有未保存的修改 | 先保存 |
| 计算位置暂不可读 | 读取能力声明失败 | 重新读取 |
| 输入有未保存修改，请先保存。 | 有尚未保存的修改 | 保存后再预检 |
| 超算进度读取失败，保存运行未改变；进度连接中断，原作业保留 | 与超算的连接中断 | **重新读取进度** 或 **恢复原作业** |
| 运行操作失败，原运行已保留 | 停止或恢复操作没有成功 | 稍后重试 |
| 运行完整性未通过 | 保存的运行与工件核对不一致，拒绝显示数值 | 保留现场，交给维护人员核对 |
| 插件校验失败，请联系管理员重新安装或校验插件。保存的输入和运行记录不变。 | 插件封签不一致 | 见[常见问题](../../reference/faq/#插件封签或摘要不一致接口返回-409) |
