型号设计是一个电缆型号的工作区。从侧栏“型号设计”打开已有型号，或用 **新建 → 新建型号** 建立：可以从型号库中的版本开始，也可以由标准结构提案生成初始结构（例如“XLPE 标准结构提案”）。

左侧按顺序列出各部分，每部分右侧标明状态（当前 / 过期）。上游修改后，依赖它的结果会标为过期，需要重新计算。

## 结构

- **电缆截面** 与 **三维剥切**：按真实尺寸绘制，可以在图上查看尺寸。
- **分层表**：每层的材料、尺寸和来源。可以添加结构层或线芯。
- **材料核对**：每层材料绑定到资源库中的固定材料版本。**批量绑定材料版本** 按同名同类预选，没有唯一匹配时不自动绑定；**批量填写密度与出处** 用于补充计算用料所需的密度。
- **外径与用料**：由结构推导成品外径和单位长度用料。缺少材料密度或构造输入时明确提示“结构外径或用料缺少完整输入”，不估算。

## 要求与标准

声明型号的执行标准（如 GB/T 12706.2—2020、GB/T 3956）及其版本。声明来自资源库中的“标准与规则”，带完整来源摘要；未声明执行标准的型号不能通过发布前检查。

## 标准核对

按执行标准逐项核对结构尺寸（绝缘、护套、铠装、内衬等的标称厚度和最小值），列出符合项、缺项、需要出厂实测值的项和依据库尚未覆盖的条款。方法原理见[标准核对](../../methods/standard-check/)。

## 电气参数与短路容量

计算导体直流与交流电阻、集肤与邻近因数、电容、充电电流和介质损耗等电气参数，以及导体和金属屏蔽（护套）的短路容量。依据见[型号电气参数与短路容量](../../methods/notes/type-electrical/)。

## 载流量表

一个型号的载流量表由若干条工况组成（敷设方式、埋深、土壤热阻率、环境温度等），每条工况一个允许电流。**添加工况** 后勾选，点 **计算所选工况**。每条工况保留条件、口径和来源；超出方法范围的工况拒算并写明原因。依据见[型号载流量表](../../methods/notes/type-rating-table/)。

需要更深入地研究某个工况时，点工具栏的 **用于载流量研究**，以这个型号新建一个研究。

## 方案对比

对比同一型号不同设计方案之间的差别。

## 规格书

规格书由结构、电气参数、载流量、短路容量和标准核对五部分结果组成，共八章：封面、标准、结构、电气、载流、短路、核对、修订。

| 页签 | 内容 |
| --- | --- |
| 内容 | 按章查看规格书正文，可在“客户版”和“内部审核版”之间切换。 |
| 预览 | 规格书的版面预览。 |
| 审核与发布 | 列出所有阻止发布的项，分为：需要工程师补输入、需要出厂实测值、标准依据未覆盖、人工确认关口。每类都有处理入口。 |
| 修订记录 | 每一版的变更摘要、编制人和来源。 |

发布流程：

1. **生成规格书**：按需补算五部分结果，生成当前版本；客户版直接下载 PDF。内部审核版可以用 **导出内部审核稿** 下载。
2. 补齐“审核与发布”中的全部阻止项后，**采纳为版本草稿**。
3. **提交评审**：填写变更摘要和编制人。
4. 审核人 **批准**，型号发布。
5. 发布后按钮变为 **导出 PDF**，导出的规格书即为正式文件。

输入或来源在生成之后发生变化时，规格书标为“已过期”，需要重新生成后才能交付当前客户版。
