## 工作对象

| 对象 | 是什么 |
| --- | --- |
| 工程 | 一个实际项目，例如“城南线路 · 110 kV 直埋单回”。工程里有敷设模型、负荷和若干研究。 |
| 研究 | 在工程里用某个计算方法回答一个问题，例如“额定载流量”“暂态温升”。研究固定引用一个电缆型号版本和一个方法版本。 |
| 运行 | 研究的一次计算。每次运行都保存当时的输入快照、方法版本、结果和证据，之后不会被改写。 |
| 型号设计 | 一个电缆型号的设计工作区：结构、要求与标准、标准核对、电气参数、短路容量、载流量表、规格书。 |
| 电缆型号版本 | 型号库里的一个固定版本，供研究引用。来源可以是厂家结构表、厂家资料、工程师给定或型号设计。 |
| 资源 | 材料与部件、模板与计算方案、标准与规则，同样按版本引用。 |
| 交付 | 计算书、规格书等交付文件的存档，可重新下载，不会重新计算。 |

## 界面布局

左侧是导航：**首页**（继续工作和需要处理的事项）、**待办**、**工程**、**型号设计**、**资源**、**记录**（运行与作业、交付）、**方法**（插件、验证算例）。顶部可在“工作台”和“Agent”两种用法之间切换，**新建** 用来建立研究或型号。

打开一个研究后：

- **命令栏**：分析类型（载流量、方法对比、参数扫描等）、试算与实时（方法支持时）、预检并运行、保存、撤销与重做、生成计算书。
- **左栏**：工程模型（敷设、电缆、负荷）、研究列表和交付。
- **中间**：敷设截面、电缆截面或三维视图，下方是结果区（结果、结果详情、验证与范围、方法参数），右下角是 **运行记录**。
- **右栏**：输入、方法和 Agent 三个页签。

**试算** 用当前输入快速算一次，结果标明“未保存”并显示与已保存结果的差值；勾选 **实时** 后每次修改输入都会自动试算。试算不写入工程，正式结果要通过 **预检并运行** 保存。各模块的分步操作见[载流量研究](ampacity-study/)、[型号设计](type-design/)、[仿真研究](simulation/)和[资源库](resources/)。

## 结果状态

| 状态 | 含义 |
| --- | --- |
| 当前 | 结果与现在的输入、引用版本和方法版本一致。 |
| 已过期 | 输入、引用或方法已经变化，需要重新运行才能作为依据。 |
| 未运行 | 研究或模块还没有运行过。 |
| 运行中 | 正在计算；超算作业另有排队、后处理等状态。 |
| 当前 · 部分成功 | 部分工况成功、部分失败；失败原因在运行记录中。 |
| 失败 | 运行没有取得有效结果；原因在运行记录中。 |
| 历史结果 | 之前的运行。保留原样，可查看、对比和追溯，不会被新的运行覆盖。 |

“待办”汇总资料缺项、过期结果和需要人工确认的事项，可以逐个打开处理，也可以让 Agent 帮你整理。

## 单位

计算和保存一律使用 SI 单位，界面按工程习惯显示：

| 物理量 | 界面显示 | 保存（SI） |
| --- | --- | --- |
| 长度 · 尺寸 | mm / m | m |
| 温度 | °C | K |
| 电流 | A | A |
| 热阻率 | K·m/W | K·m/W |
| 损耗 | W/m | W/m |
| 电阻 | Ω/km | Ω/m |

鼠标悬停在数值上可以看到完整精度。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| Ctrl+K | 搜索工程、研究、型号、电缆型号版本、资源或插件 |
| Ctrl+B | 收起或展开侧栏 |
| Ctrl+S | 保存 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做 |

## 基本原则

- **不产生假结果**：缺少数据或超出方法适用范围时明确拒绝，并说明缺什么，不用估计值兜底。
- **每个结果可追溯**：结果都能追到输入快照、数据来源、方法版本和插件封签。
- **人来批准**：Agent 和计算插件只给出结果与建议，型号发布、规格书批准等关口由人确认。
