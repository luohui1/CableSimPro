资源库保存计算会引用的基础资料。每条资源都有版本和状态，研究与型号引用的是**某个固定版本**：资源更新后，已有的研究和型号不会被悄悄改变，需要工程师主动更换引用并重新计算。

| 资源 | 内容 |
| --- | --- |
| 电缆型号版本 | 型号库中的全部版本，按系列分组，标明内容完整度（完整结构 / 公开规格 · 缺 N 项）、主要来源和状态。见[型号库与结构表导入](../type-library/)。 |
| 材料与部件 | 导体、绝缘、屏蔽、护套、铠装、填充和土壤等材料的物性，按用途区分（例如“PVC · 超过 3 kV 绝缘参考”），并列出已登记物性的覆盖情况。 |
| 模板与计算方案 | 敷设模板和计算方案。导入的资源草稿经审核发布后，研究才能引用。 |
| 标准与规则 | 已收录的标准条款，例如 GB/T 12706.2—2020 表 7 绝缘标称厚度。可以按量或条款检索，选中表格中的值查看完整依据（页码与核验方式），并复制引用。 |

## 来源与可信分档

资源里的每个数值都带出处，例如标准的表号和页码、厂家手册、文献表格或工程师给定的说明，并标明可信分档（如“参考”）。依据库尚未收录的条款会明确标为“未覆盖”，不会用相近条款代替。

## 导入与发布

资源可以用“导入资源草稿”导入，或在“电缆型号库 · 数据交换”中导入其他实例导出的交换文件。草稿经审核发布后才能被研究引用。

## 与插件的关系

标准依据库（`cablesim.standards-basis`）作为插件发行：标准核对、GB 50217 校正等方法通过它查询条款和系数，并在结果里记录所用依据库的发行摘要。更换依据库版本不会自动改变已有工程的绑定。
