## 建立研究

**新建 → 新建研究**（或首页右上角 **新建研究**），选择：

| 项目 | 说明 |
| --- | --- |
| 所属工程 | 已有工程，或“新建工程”。 |
| 研究任务 | 额定载流量、运行温度、客户问询选型、暂态温升、护套损耗、电热耦合、混合载流量参考研究。 |
| 引用型号版本 | 型号库中的固定版本。之后型号库出现新版本，研究仍按选定的版本计算，除非主动更换。 |
| 计算方法 | 已安装插件中适用于该任务的方法，如 IEC 60287 载流量、GB 50217 载流量校正、有限元方法。 |

从型号设计页点 **用于载流量研究** 也可以建立研究，型号会自动带入。完整演示见[快速上手：研究院](../../quickstart/research/)。

## 敷设与工况

新研究按敷设模板生成工程模型，例如“直埋单回 · 品字形”。IEC 60287 方法支持多回路直埋、排管和矩形回填。

右栏“输入”页按类别列出工况：

- **负荷**：各回路电流。
- **供电系统**：系统线电压（可选，用于记录供电条件；IEC 的介质损耗按电缆额定相电压计算）。
- **环境**：地表温度、介质（土壤）热阻率，以及回填、排管等区域的物性。
- **设计准则**：导体温限。
- **附加热源**：交叉的其他电缆或热管道等外部热源。
- **敷设参数**、**分层参数**：埋深、间距、排列方式和各区域的分层。

每个数值都带来源标记（工程师填写、计算得出或引用资源）。修改后需要保存才会参与正式运行。

“方法”页选择方法版本并填写方法参数。方法要求的参数没有给出时，预检会指出缺哪一项，例如皱纹铝护套需要声明间隙的有效热阻率及其来源；软件不会自动套用缓冲带或空气的数值。

## 试算、预检与运行

- **试算**：用当前输入快速算一次，结果标明“未保存”，并显示与已保存结果的差值。勾选 **实时** 后每次修改都会自动试算。
- **预检并运行**：先检查输入完整性和方法适用范围，说明求解位置（本机或超算）。有超出范围的项时不能运行，并逐条给出原因。确认后运行，结果保存为一次新的运行。

## 读结果

结果区顶部给出结论，例如“允许电流 944.8 A，受限于回路 1 · 电缆 · 运行 350.0 A 时最热导体 33.5 °C，距 90.0 °C 温限 56.5 K”。“结果详情”按温度与电流、损耗、热阻等分组列出全部数值；“验证与范围”列出方法的适用范围和本次运行的核验证据。

多回路时，允许电流有三种口径，结果里会写明是哪一种，不能混用：

| 口径 | 含义 |
| --- | --- |
| 单回路能力 | 只有一个回路，回路内三相互热仍计入，按该回路各电缆的温限求上限。 |
| 全回路共同能力 | 所有回路同时通过相同的平衡电流，任一电缆先达到温限即限制共同电流。 |
| 其他回路固定负荷下的条件上限 | 只调节目标回路，其余电缆保持保存的负荷；各回路的条件上限不能同时使用。 |

详见[载流量口径与热网络参考](../../methods/notes/rating-basis/)。

## 参数扫描

把一个输入（如土壤热阻率、埋深）按给定范围逐点计算，得到允许电流随该参数变化的曲线。每个采样点都是真实计算；失败的点保留为缺口，不做插值补齐。

## 运行记录与对比

结果区右上角 **运行记录** 列出这个研究的全部运行（时间、方法、状态），可以打开任一次的输入和结果。勾选两次运行后 **对比所选运行**，按“结论量值”“限制对象”“输入差异（SI）”分组列出差别。

全部研究的运行也汇总在侧栏“记录 → 运行与作业”。

## 计算书

工具栏 **生成计算书** 用所选的一次已保存运行生成计算书，不重新计算。客户版包含结论、敷设图、分组结果与方法依据；内部审核版另含完整输入与诊断。生成后在“预览”页 **下载 PDF**，也可以保存 HTML 存档。见[正式交付文件](../deliverables/)。
