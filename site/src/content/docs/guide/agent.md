Agent 是工作台里的助手。它能读取工程、研究、型号和运行结果，帮你整理缺项、解释结果、起草修改方案；**它只提出方案，不替你做决定**。

## 打开 Agent

- **Agent 页面**：侧栏顶部从“工作台”切换到“Agent”，在对话框里说明要做的事。用 `@` 引用某个研究或型号，用 `/` 选择常用任务。
- **工作台里的 Agent 页签**：研究页和型号设计页右栏的“Agent”页签，Agent 默认以当前打开的对象为上下文。
- **首页“让 Agent 整理”**：让 Agent 汇总待办事项和下一步。

使用前需要在“设置 → AI 模型”接入模型，见[接入模型](../../install/model/)。未接入时，Agent 页面会提示去设置，其他功能不受影响。

## Agent 能做什么

- **读取与解释**：列出工程里的研究、最近的运行结果、受限于哪根电缆、还缺哪些输入，并说明出处。
- **整理待办**：按影响说明资料缺项、过期结果和下一步。
- **提出修改方案**：例如“把土壤热阻率改为 1.5 K·m/W 并补充来源”。方案以字段级的前后对比呈现，说明基于哪一次修订。
- **试算**：按方案做一次不保存的试算，帮助判断改动的影响。试算不写入工程，也不代表批准。

## 由人决定的事

| 动作 | 谁来做 |
| --- | --- |
| 保存对工程输入的修改 | 人审核 Agent 的方案后，**按住批准**；批准走与工作台相同的保存路径。也可以拒绝。 |
| 运行计算、提交超算作业 | 人在工作台确认预检后运行。 |
| 型号提交评审、批准发布 | 人在型号设计的“审核与发布”中完成。 |
| 交付文件的签字与发布 | 人完成；Agent 不能代签。 |

方案卡片显示每一项改动的旧值和新值（带单位）、核验结果和追溯详情。基于的修订已经过期时，方案需要重新生成，不能直接套用到新数据上。

## 边界

- Agent 的回答引用工程数据和方法结果，但它的话本身**不是工程依据**；需要作为依据的数值要来自保存的运行和有出处的输入。
- 自定义指令只能改变表达方式和关注点，不能放宽权限、数值核验或批准规则。
- 长期记忆按工程和研究隔离，记忆的内容不是工程依据，也不代表批准；可以在设置里查看、纠正和删除。
- Agent 调用的工具与界面按钮背后是同一套接口，不会绕过预检、来源要求和方法适用范围。
