Agent 是工作台内的对话式助手。它读取工程、研究、型号和已保存的运行结果，把需要写入的每一步整理成待审提案；**提案须由人在对话中接受后才会执行**，Agent 不能自行批准。

:::caution[离线安装包暂不含 Agent 对话]
Agent 对话由一个独立的对话服务提供。当前的 Windows / Linux 离线安装包不打包、也不启动这个服务，因此安装包中没有对话界面，其余功能不受影响。目前只有按源码运行的一键演示会启动它，见[从源码运行](../../install/#从源码运行开发与评估)。
:::

## 打开 Agent

- **Agent 页面**：侧栏顶部从“工作台”切换到“Agent”。新对话页列出常用任务，也可以直接输入要办的事。
- **工作台里的 Agent 页签**：研究页和型号设计页右栏的“Agent”页签，以当前打开的对象为上下文。
- **首页“需要处理”**：通过其中的 Agent 入口整理待办事项。

使用前需要在“设置 → AI 模型”接入模型，见[接入模型](../../install/model/)。未接入模型时，对话页会提示打开模型设置；对话服务没有运行时，页面显示“Agent 对话服务未连接”。

## 对话如何进行

- **发送消息**：在输入框中说明任务。任务进行中发送的消息会排队，在当前一步完成后处理。
- **常用任务**：新对话页按“载流量研究”和“电缆型号”分组列出，如查看研究结论、新建直埋校核、改条件重算并对比、查看结构和主要参数、改结构并出规格书、导入厂家结构表。
- **附件**：导入厂家结构表时可附上 CSV / XLSX 原件，每条消息的附件合计不超过 1 MiB。
- **结果卡片**：载流量卡读取保存运行中的数值和方法版本，型号卡读取平台保存的结构，文件卡可预览和下载实际存档。卡片中的数字来自保存记录，不由模型生成；对象卡上的“在工作台打开”跳到对应页面。
- **长对话**：较早的内容会自动压缩，保留任务目标、已完成和未完成的步骤、待审提案与关键量；完整的消息和卡片仍保存在原对话中。上下文窗口与最大输出在“设置 → AI 模型”中设置。

## 提案与接受

每一次建立、修改、运行和导出都是一张独立的待审卡，列出改前、改后、影响以及完整参数与来源。提案保存后内容固定，需要调整时由 Agent 重新提出。

| 操作 | 结果 |
| --- | --- |
| 接受 | 平台按与工作台相同的路径执行，真实回执交回 Agent 后才继续下一步。 |
| 拒绝或停止 | 不写入任何数据。 |
| 修订已过期、对话重启后尚未确认 | 提案不会被执行，需要重新提出。 |

## 可以交办的任务

| 范围 | 任务 |
| --- | --- |
| 载流量研究 | 由保存的工况或完整方法参数建立研究、计算、修改条件后重算、比较保存的运行、导出计算书。 |
| 电缆型号 | 由型号库或标准结构建立型号、修改结构、保存标准依据，按新修订核对结构、电气、载流量、短路、标准五个部分，生成规格书；编制整张载流量表。 |
| 厂家结构表 | 附上原件后分四步导入，见下文。 |
| GB 50217 校正 | 须由工程师明确给出基准载流量及其来源和页码。 |
| 三维实体 | 须具备插件声明的运行环境。 |

有限元、原生仿真与超算作业仍须在工作台中确认，不能在对话中提交。缺少工程输入、材料属性、标准依据或有效结果时，Agent 会明确拒绝并说明缺项。

## 计算书与规格书

对话中生成的计算书和规格书经正式交付服务输出：提案固定预览内容与来源，接受后导出 PDF，含设计、校核、审核、批准四个签栏、独立的追溯页和完整来源快照。编制单位、文件编号和版次须由用户明确提供；没有真实签核记录的签栏保持空白。

规格书按用途分两种：

- **内部审阅稿**：结构、电气、载流量、短路、标准五个部分均有保存的运行即可生成，缺项随文列出。用户未说明用途时按内部审阅稿处理。
- **客户稿**：须先补齐缺项，或由人声明发布范围。

文件的组成与追溯方式见[正式交付文件](../deliverables/)。

## 导入厂家结构表

在对话中附上厂家结构表原件后，导入分四步进行，每一步都需要人工接受：

1. **上传原件**：登记原件及其摘要。
2. **保存预览**：核对工作表、列映射、单位和逐行缺项。
3. **草稿入库**：按预览保存为型号草稿。
4. **标准核对**：对入库的规格执行产品标准尺寸核对。

需要注意：

- 原件已带系列声明时，导入只能修改系列名称，其余公共值以原件为准。工程值及其依据在导入后按型号修订逐项提出，并给出来源。
- 原件没有系列声明时，须完整填写系列声明。
- 单批最多 100 个规格，超出须拆分。
- 入库的是草稿，导入不代表型号已审核或发布。

界面中的导入向导见[型号库与结构表导入](../type-library/)。

## 边界

- Agent 的回答引用工程数据和方法结果，但回答本身**不是工程依据**；作为依据的数值须来自保存的运行和有出处的输入。
- 审核、批准和发布型号、签发交付文件由人完成，Agent 不能代办。
- Agent 调用的工具与界面操作使用同一套接口，同样受预检、来源要求和方法适用范围约束。
- 自定义指令只影响表达方式和关注点，不能放宽权限、数值核验或批准规则。
- 模型密钥只保存在平台后端的系统凭据或环境变量中，对话服务不接触密钥。
- 长期记忆按工程和研究隔离，记忆内容不是工程依据，也不代表批准；可以在设置中查看、纠正和删除。
