IEC 60287、GB 50217 校正、热网络、标准核对等解析方法在 CableSimPro 所在的服务器上直接运行（“本机”）。有限元温度场、暂态、电热耦合、批量仿真数据集和混合模型训练等计算量大的方法在 **Slurm 超算集群** 上运行；原生参考插件中规模固定的小型有限元参考算例（如直埋有限元温度、圆截面网格参考）声明为本机运行。没有配置集群时，只在超算运行的方法会在运行前预检中提示超算未配置，不会改到本机计算。

## 每个方法在哪里运行

每个计算能力在插件清单里声明求解位置：

| 声明 | 含义 |
| --- | --- |
| `local` | 只在本机运行 |
| `slurm` | 只在超算运行 |
| `either` | 两者均可，按计算位置设置选择 |

声明见[方法清单](../../methods/catalog/)。研究的运行前预检会写明本次在本机还是超算上求解。

## 配置超算连接

打开“设置 → 计算位置”，在“超算连接”中填写：

| 项目 | 说明 |
| --- | --- |
| SSH 别名 | 从服务器上已登记的 SSH 主机别名中选择。别名、主机地址、账号和密钥由管理员事先写在运行 CableSimPro 的系统账户的 `~/.ssh/config` 中，CableSimPro 不保存密码或私钥。 |
| 分区 | 提交作业使用的 Slurm 分区名。 |
| 远程工作目录 | 集群上事先建好的绝对路径，作业文件放在其下的 `jobs` 目录。测试连接不会创建目录。 |
| 环境 | 集群上的 Python 或 Conda 环境根目录。 |
| 单批核时上限 | 一批作业允许使用的核时，最多 2000 核时；超出的提交会被拒绝。 |
| 累计核时上限 | 所有作业合计允许使用的核时，不小于单批上限，最多 20000 核时；用完后新的提交会被拒绝。 |

保存后用 **测试连接** 检查 SSH、分区和目录是否可用。保存会记录修订，必要时可以撤销到上一份设置。

:::caution[用专用系统账户运行]
“SSH 别名”下拉框会列出运行 CableSimPro 的系统账户 `~/.ssh/config` 中登记的**全部**主机别名，能打开设置页的用户都看得到。内网多人使用时，请用专门的系统账户运行 CableSimPro，并只在它的 `~/.ssh/config` 中登记超算集群的别名。
:::

### 集群上需要准备什么

- 能从 CableSimPro 服务器通过 SSH 免密登录的账号，以及有写权限的工作目录。
- 一个 Python（或 Conda）环境，安装仿真插件声明的原生依赖：仓库中的 `plugins/requirements-native.txt`（网格、有限元求解器等）。插件清单列出各自依赖，安装插件不会自动安装依赖。
- 作业所需的计算节点和分区访问权限。

## 作业与证据

提交到超算的作业在“记录 → 运行与作业”中可以看到排队、运行、完成状态，支持刷新和取消。作业完成后，宿主取回结果并与输入、方法版本、网格与收敛证据一起保存；实际使用的核时也会记录。仿真结果的验证依据见[有限元对照](../../methods/fem/)。
