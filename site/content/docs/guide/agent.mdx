Agent 是工作台内的对话式助手。它读取工程、研究、型号和已保存的运行结果，调用计算插件，把需要写入的每一步整理成待审提案；**提案须由人在对话中接受后才会执行**，Agent 不能自行批准。

离线安装包自带 Agent 对话服务，使用前需要[接入模型](../../install/model/)；对话服务的配置与排错见 [Agent 对话服务](../../install/agent/)。

## 打开 Agent

- **Agent 页面**：侧栏顶部从“工作台”切换到“Agent”。新对话页列出常用任务，也可以直接输入要办的事。
- **工作台里的 Agent 页签**：研究页和型号设计页右栏的“Agent”页签，以当前打开的对象为上下文。
- **首页“需要处理”**：通过其中的 Agent 入口整理待办事项。

未接入模型时，对话页提示“还没有配置 AI 模型”；对话服务没有运行时，页面显示“Agent 对话服务未连接”。其余功能不受影响。

## 对话如何进行

- **发送消息**：在输入框中说明任务。任务进行中发送的消息会排队，在当前一步完成后处理。
- **常用任务**：新对话页按“载流量研究”和“电缆型号”分组列出，例如查看研究结论、新建直埋校核、改条件重算并对比、查看结构和主要参数、改结构并出规格书、导入厂家结构表。
- **附件**：导入厂家结构表时可附上 CSV / XLSX 原件，每条消息的附件合计不超过 1 MiB。
- **结果卡片**：载流量卡读取保存运行中的数值和方法版本，型号卡读取平台保存的结构，文件卡可预览和下载实际存档。卡片中的数字来自保存记录，不由模型生成；卡片上的“在工作台打开”跳到对应页面。

## 提案卡片怎么看

需要写入数据时，Agent 不会直接执行，而是在对话中显示一张提案卡片：

| 部分 | 内容 |
| --- | --- |
| 标题 | 操作和对象，例如“修改工程输入 · 直埋载流量”；状态为“待你审阅” |
| 改动 | 每一项的字段名，以及“原值”和“保存值”（带单位）；改动较多时折叠，点“完整改动”查看全部 |
| 影响 | 平台预览得出的后果，例如哪些结果会变为历史结果、哪项核对会受影响 |
| 来源与参数 | 改动所依据的来源、方法和完整参数 |
| 操作 | “接受”和“拒绝” |

提案保存后内容固定。需要调整时，拒绝并说明原因，由 Agent 重新提出。

## 接受与拒绝的后果

| 你的操作 | 结果 |
| --- | --- |
| 接受 | 卡片显示“已接受，正在执行；完成后继续处理下一步。”平台按与工作台相同的路径执行，真实回执交回 Agent 后才继续下一步。 |
| 执行失败 | 卡片显示“已接受，但执行未完成：……”及原因，数据以平台保存的记录为准，可在工作台核对。 |
| 拒绝 | 可以填写“拒绝的原因”（可不写），点“确认拒绝”。不写入任何数据，Agent 按原因调整，不会换一种方式重试同一写入。 |
| 停止对话 | 正在等待审阅的提案不会执行。 |
| 提案过期 | 对象在提案之后又被修改（修订已变化），或对话重启后尚未确认，提案不会执行，需要重新提出。 |

每一次建立、修改、运行和导出都是一张独立的卡片。接受一张卡片只授权这一步，不代表接受后续步骤。

## 长对话的上下文压缩

对话很长时，较早的内容会自动压缩为摘要，保留用户目标、已完成和剩余的步骤、当前对象、待审提案、已接受的回执、关键量与缺项。

- 完整的消息和卡片仍保存在原对话中，可以随时翻看；重启后仍可追溯。
- 工程状态以平台保存的记录为准，Agent 不能借摘要批准或重复执行写入。
- 压缩的触发时机取决于“设置 → AI 模型”中的上下文窗口和最大输出（未填写时按 64,000 和 16,384 token 处理）。
- 回复因长度中断时，Agent 先压缩再续接一次；仍然失败时在对话中明确说明未完成。

## 各技能的示例对话

Agent 按技能处理不同类型的任务。下面的对话用于说明流程，其中的研究、型号和数值取自[快速上手](../../quickstart/research/)使用的示例库，实际回复以你的工程数据为准。

### 载流量研究

读取研究结论；新建研究；修改条件后重算并对比。

> **你**：直埋载流量这项研究能带多大电流？
>
> **Agent**：研究“直埋载流量”最近一次运行的允许电流为 944.8 A（导体温限 90 °C），受限于回路 1 的电缆；按 350 A 运行时最热导体 33.5 °C。方法为 IEC 60287 稳态载流量，结果为当前结果。下方是载流量卡，可在工作台打开。
>
> **你**：把土壤热阻率改为 1.5 K·m/W，重新计算并和修改前对比。
>
> **Agent**：需要两步，每步都请你确认。
>
> **提案 · 修改工程输入**：介质热阻率，原值 1.00 K·m/W，保存值 1.50 K·m/W。
>
> **你**：接受
>
> **提案 · 运行研究**：直埋载流量，IEC 60287 稳态载流量。
>
> **你**：接受
>
> **Agent**：新运行完成，允许电流 801.1 A。与修改前的运行相比，输入差异只有土壤热阻率；两次的限制对象相同。修改前的运行保留为历史结果。

缺少输入或预检不通过时，Agent 停止并说明缺哪一项、在工作台哪里补录，不会换条件凑出结果。

### 载流量表

> **你**：给 YJV22-8.7/15 kV 3×240 出一张载流量表：直埋，埋深 0.7 m，土壤热阻率 1.0 和 1.5 K·m/W 两种，环境温度 25 °C。
>
> **Agent**：已核对型号的保存输入。表中每一行的条件都需要完整给出：还缺频率、相间距和金属套接地方式，请补充。
>
> **你**：50 Hz，品字形紧贴，两端接地。
>
> **提案 · 建立载流量表**：两行工况的完整条件。接受后建立研究，运行另行提案。

不同型号修订、敷设、口径或方法不会混在同一列；外径、边界或损耗数据缺失时停止，不插值、不外推。

### GB 50217 校正

> **你**：按 GB 50217 做并列敷设的校正。
>
> **Agent**：校正需要一个已保存的基准运行，以及你确认的基准条件、来源和页码。当前工程中有研究“直埋载流量”的运行，基准条件是否成立请你确认，并给出依据。

基准条件须由工程师确认；表外条件或方法不覆盖时停止，不插值、不借用其他电压或敷设方式的表。

### 厂家结构表导入与核对

在对话中附上原件后，分四步导入，每一步都需要接受。

> **你**：（附上 people-mv-sample.xlsx）把这张表导入型号库并核对，系列名称用“人民电器 YJV22-8.7/15 kV 三芯”。
>
> **提案 · 上传原件**：文件名、大小和 SHA256。
>
> **你**：接受
>
> **提案 · 保存预览**：工作表“表3 YJV22”，列映射与单位，11 个规格的逐行来源与缺项；系列声明以原件为准，只修改系列名称（原件 → 修改后）。
>
> **你**：接受
>
> **提案 · 草稿入库**：11 个规格，不跳过错误行。
>
> **你**：接受
>
> **提案 · 标准核对**：对 11 个规格各执行一次产品标准尺寸核对。
>
> **你**：接受
>
> **Agent**：已入库 11 个规格草稿并完成核对，结果按规格列出满足、待补数据和未覆盖的条目。规格仍是草稿，审核与发布需要在工作台完成。

需要注意：

- 原件已带系列声明时，导入只能修改系列名称，其余公共值以原件为准；工程值及其依据在导入后按型号修订逐项提出，并给出来源。
- 原件没有系列声明时，须完整填写系列声明。
- 单批最多 100 个规格，超出须拆分。界面中的导入向导见[型号库与结构表导入](../type-library/)。

### 新建型号设计

> **你**：照型号库里的 YJV22-8.7/15 kV 3×300 新建一个型号设计。
>
> **Agent**：型号库中有该版本，来源和缺项如下。新建会生成一个独立的型号工作区。
>
> **提案 · 新建型号**：名称、起点（型号库条目及其版本）、结构来源。
>
> **你**：接受
>
> **Agent**：已建立型号设计。需要标准核对时，先保存标准依据，再提出核对运行。

### 修改型号结构

> **你**：把这个型号的绝缘厚度改成 4.5 mm，重新核对并出规格书。
>
> **提案 · 修改结构**：绝缘标称厚度，列出型号当前的原值和新的保存值 4.5 mm；影响：结构、电气、载流量、短路、标准五个通道需要按新修订重新运行。
>
> **你**：接受
>
> **Agent**：后续逐项提出标准依据、各通道运行和规格书导出，每一项都需要你接受。

厚度变化不会被 Agent 推算成外径；依赖修改的结果需要按新修订重新运行。

### 标准结构依据

> **你**：GB/T 12706.2 中 8.7/15 kV、240 mm² 的绝缘标称厚度是多少？
>
> **Agent**：依据库给出的数值、条款和页码如下（结果卡显示来源）。导体外径等标准未规定的尺寸仍需工程师提供并注明依据。

标准表外的值、版本不符或来源不足时拒绝，不插值，也不换用其他标准；核对显示“未覆盖”时不会说成满足。

### 规格书与计算书

> **你**：给直埋载流量这项研究出一份计算书。
>
> **Agent**：计算书需要单位名称、文件编号和版次，请提供。
>
> **你**：单位“××电缆有限公司技术部”，编号 JS-2026-001，版次 A。
>
> **提案 · 导出计算书**：单位、文件编号、版次和所用的保存运行。
>
> **你**：接受
>
> **Agent**：已生成计算书 PDF，含四个签栏（没有真实签核记录的栏位留空）和追溯页。

规格书按用途分两种：

- **内部审阅稿**：结构、电气、载流量、短路、标准五个部分均有保存的运行即可生成，缺项随文列出。用户未说明用途时按内部审阅稿处理。
- **客户稿**：须先补齐缺项，或由人在型号设计的“审核与发布”中声明发布范围。

能否导出以平台的核验结果为准。文件的组成见[正式交付文件](../deliverables/)。

### 三维与几何证据

> **你**：看看这个型号的三维结构，给我 STEP 文件。
>
> **Agent**：型号设计中有已保存的几何运行及其工件，对应当前输入版本；文件卡可以下载 STEP。

没有保存的几何工件时，Agent 只说明缺什么并给出型号工作台的入口，不画替代模型，也不把截面示意说成真实实体。

## Agent 不能做的事

- **不能批准**：接受提案、审核和批准型号、发布型号、签发交付文件都只能由人完成。
- **不能代签**：交付文件的设计、校核、审核、批准签栏只读取真实签核记录；Agent 提案不充当签名。
- **不能提交原生计算**：有限元、原生仿真与超算作业须在工作台中确认，不能在对话中提交。
- **不能编造数据**：缺少工程输入、材料属性、标准依据或有效结果时明确拒绝并说明缺项，不使用默认值、演示值或推测值。
- **不能代替工程依据**：Agent 的回答不是工程依据；作为依据的数值须来自保存的运行和有出处的输入。
- **不能绕过规则**：Agent 调用的工具与界面操作使用同一套接口，同样受预检、来源要求和方法适用范围约束；自定义指令只影响表达方式和关注点，不能放宽权限、数值核验或批准规则。
- **拿不到密钥**：模型密钥只保存在平台后端的系统凭据或环境变量中，对话服务不接触密钥。

长期记忆按工程和研究隔离，记忆内容不是工程依据，也不代表批准；可以在设置中查看、纠正和删除。
