型号设计是一个电缆型号的工作区：结构、执行标准、标准核对、电气参数、短路容量、载流量表、方案和规格书都在这里完成。上游修改后，依赖它的结果标为过期，需要重新计算；已发布的版本只读，修改须建立新方案。

## 打开与新建

**打开哪里**：侧栏 **型号设计**。列表可以按名称查找、按发布状态筛选和分组，点型号名进入它的结构页。

**新建**：点 **新建型号**，在“新建型号设计”对话框中选择起点：

| 起点 | 填什么 | 点什么 |
| --- | --- | --- |
| 从型号库复制 | 查找型号，选择型号版本 | **建立草稿** |
| 按标准生成 | 生成范围、结构类型、额定电压、导体材料、导体截面（mm²）、导体几何、导体外径（mm）；多芯时还有芯间最小净距、中性线截面与外径、填充外包厚度、包带等效厚度；完整护层另有半导电屏蔽、护层构造及屏蔽与铜带参数 | **生成结构提案**，核对“结构提案”表，勾选“已核对标准值、推导条件与缺项”，再点 **确认并建立草稿** |
| 从资料导入 | 打开资料导入，选择已批准的厂家资料结果 | 见[型号库与结构表导入](../type-library/#提取厂家-pdf) |
| 空白 | 结构类型：单芯、三芯或四芯等截面 | **建立草稿** |

型号名称最多 80 字。按标准生成只给出标准规定的数值，标准未规定的尺寸（如导体外径）须由工程师提供并注明依据；缺少的物性和制造数据保持缺项。

| 提示 | 处理 |
| --- | --- |
| 请填写型号名称，再建立草稿。 | 填写型号名称 |
| 请选择一个可复制的型号版本，再建立草稿。 | 选择型号版本 |
| 请选择额定电压，再生成结构提案。 | 选择额定电压 |
| 请选择导体几何，明确推导条件或提供导体外径。 | 选择导体几何或填写导体外径 |
| 请先核对结构提案中的标准值、推导条件与缺项，并勾选确认。 | 核对后勾选 |
| 当前版本没有可用的结构提案方法，暂不能按标准生成。 | 检查标准核对插件的安装 |

## 工作区

- **左侧“型号浏览器”**分四组：结构（每个结构一项，如“结构 · 3 芯 · 9 层”）；要求（要求与标准、标准核对）；分析（电气参数、短路容量、载流量表、方案对比）；交付（规格书）。各项右侧标明状态。
- **命令栏**：保存、撤销、重做、**用于载流量研究**、规格书，以及当前模块的主操作。
- **型号名称**旁的编辑按钮打开“修改型号名称”（最多 200 字），修改写入草稿，需另行保存。

页头状态：已保存、未保存、读取中、保存失败、读取失败；只读状态为“保存运行 · 只读”“历史 · 只读”“已发布 · 只读”。型号含演示来源时另加“· 演示”，提示核对各字段的工程依据。

## 1. 结构设计

**打开哪里**：型号浏览器“结构”组。页签为截面、三维剥切、分层表、材料核对、外径与用料。

**添加结构层**：在截面或分层表中选中一层，点 **添加结构层**，新层插入所选层之前（未选层时插入外护套之前），点 **添加到草稿**。

| 字段 | 含义 | 单位 | 示例 | 要求 |
| --- | --- | --- | --- | --- |
| 所属位置 | 共同层或某一芯 | — | 共同层 | — |
| 结构层 | 层的类型 | — | 隔离层 | 同一位置不能重复 |
| 新层材料 | 从本型号已有的材料中选择 | — | — | 与资源库固定材料版本的绑定在“材料核对”中完成 |
| 新层厚度 | 层厚 | mm | 0.2 | 必须大于 0；没有工程依据时来源显示“未提供” |
| 新层构造 | 未给定、挤包或连续层、带层、丝层 | — | 挤包或连续层 | — |

**删除结构层**：选中后点 **删除结构层**，确认后删除。修改可以撤销，保存后需要重新计算受影响的结果。

**分层表**：每层的材料引用、尺寸（层厚或导体直径，扇形导体为扇形高度）和来源；“绘图外径”逐层累加，只读。

**材料核对**：每层材料绑定到资源库中已发布的固定材料版本。批量绑定按同名同类预选，没有唯一匹配时不自动绑定。

**外径与用料**：点 **更新结构推导**，预检后勾选“已核对输入来源与方法适用范围”，点 **确认并运行**。结果给出成品外径（mm）、理论每公里重量（kg/km）和建模长度（m），“外径与用料”表逐层列出体积（m³/km）、密度（kg/m³）、用量（kg/km）和依据。缺少密度或构造输入时明确提示，不估算。

| 提示 | 处理 |
| --- | --- |
| 请选择结构层、材料并填写正厚度。 | 补齐后再添加 |
| 该位置已存在相同结构层，请编辑已有层。 | 编辑已有层 |
| 当前 CAD 支持最多16芯。 | 减少芯数 |
| 截面暂不可绘制 | 点“定位……尺寸”或“定位……位置”按钮（例如“定位芯 1 · 绝缘尺寸”）跳到出错的字段，或“撤销上一步修改”；原因在“诊断详情”中 |
| 以下为历史推导；保存修改后点击『更新结构推导』。 | 保存后更新结构推导 |

## 2. 要求与标准

**打开哪里**：型号浏览器 **要求与标准**，页签为要求清单、执行标准、待批准导入。

**声明执行标准**：在“执行标准”页签点 **声明执行标准**，在“确认执行标准版本”中勾选“已核对执行标准版本”，点 **确认执行标准并查询依据**。声明保存为新修订并查询依据，旧判定保留为历史；要求的批准需要另行确认。完成后显示“执行版本已声明”，表中列出标准及版本、覆盖条款和依据。

**批准要求**：在“要求清单”点 **生成要求目录**（已有时为 **更新要求目录**），勾选要求，点 **批准所选要求**，填写审批人，勾选“本人已核对所选要求的来源和判定绑定”后确认。这一步不批准计算结果，也不发布型号。

要求的状态：待批准、已批准、版本冲突、未定义 / 未覆盖；缺字段的要求标为“待补数据”，不能批准。不适用于本型号结构的条款收在“不适用条款”中。

## 3. 标准核对

**打开哪里**：型号浏览器 **标准核对**。

**点什么**：**执行标准核对**，预检后 **确认并运行**。

**看到什么**：表格逐项列出要求、余量和判定。汇总为“声明范围内要求满足”“N 项不满足”“核对尚未完整覆盖”或“暂无适用要求”，另列“N 项待补数据”“N 项未覆盖”。右侧“依据”给出该次运行的条款、输入来源、公式中间值和摘要。

**怎么判读**：

| 判定 | 含义 | 下一步 |
| --- | --- | --- |
| 满足 | 有完整输入和标准依据，判定满足 | — |
| 不满足 | 判定不满足 | 点 **定位结构层** 修改结构，保存后重新核对 |
| 待补数据 | 缺少判定所需的数值，或需要出厂实测值 | 补齐有来源的输入后重新核对 |
| 未覆盖 | 依据库尚未收录该条款或版本（依据显示“本库暂未收录”） | 由工程师按标准原文人工核对，不能视为满足 |

**运行失败时**：界面显示该次运行的实际错误和缺失字段的位置；没有具体原因时显示“本次运行未取得有效结果，请查看运行记录中的失败诊断，不采用预检结论作为计算结果。”原始错误放在“诊断详情”中。常见原因：

| 提示 | 处理 |
| --- | --- |
| 当前标准依据与本次校核条件不一致，请在方法参数中重新核对并查询依据。 | 重新声明执行标准并查询依据 |
| 待补字段 · N | 按列表补齐字段 |
| 结构缺项 · 先补齐型号名片中的字段 | 补齐后再运行 |
| 标准核对插件文件与发布记录不一致，请联系管理员重新安装。 | 插件封签不一致，见[常见问题](../../reference/faq/#插件封签或摘要不一致接口返回-409) |
| 输入或方法已变化；保留原要求与判定，人工批准保持关闭。 | 重新核对后才能批准 |

方法原理与判定依据见[标准核对](../../methods/standard-check/)。

## 4. 电气参数与短路容量

**打开哪里**：型号浏览器 **电气参数** 或 **短路容量**，页签为“结果”和“方法参数”。

**填什么**（“方法参数”页签）：

| 参数 | 含义 | 单位 | 常见取值 | 要求 |
| --- | --- | --- | --- | --- |
| 频率 | 电源频率 | Hz | 50 | 页面给出的 50 Hz 是明示的试算初值，须核对实际电源频率 |
| 运行相电压 | 导体对地电压 U₀ | **V** | 8.7/15 kV 电缆填 8700 | 按 V 填写，不是 kV |
| 持续时间 | 短路持续时间 | s | — | 短路容量需要 |

每个参数都要写明出处，缺少出处的参数不产生对应的计算结果。修改的参数来源记为“工程师在方法参数中填写；未经批准”。点 **保存方法条件** 后才能运行；**试算** 的结果标为“试算 · 未保存 · 不作为发布依据”。

**点什么**：在“结果”页签点 **计算电气参数** 或 **计算短路容量**，预检后确认运行。

**看到什么**：汇总“N 项已计算”“N 项待补数据”“N 项未覆盖或拒绝”。电气参数包括导体直流与交流电阻、集肤与邻近因数、电容、充电电流和介质损耗；短路容量另给出电流—持续时间曲线。依据见[型号电气参数与短路容量](../../methods/notes/type-electrical/)。

## 5. 载流量表

一个型号的载流量表由若干工况组成，每个工况一个允许电流。

**添加工况**：点 **添加工况**，填写后点 **添加到工况表**：

| 字段 | 含义 | 要求 |
| --- | --- | --- |
| 工况名称 | 工况的中文名称 | — |
| 工况排列 | 单芯：直埋 · 品字、直埋 · 水平、排管 · 品字、空气；三芯：三芯直埋 · 单回、三芯直埋 · 三回水平、三芯排管 · 三回水平 | 按结构可选 |
| 交流频率 | 电源频率，单位 Hz | 大于 0、不超过 1000，默认 50 |

**编辑工况条件**：在“结果表”中选中工况，编辑“所选工况条件”：

| 字段 | 含义 | 单位 | 示例 | 要求 |
| --- | --- | --- | --- | --- |
| 载流量口径 | “全回路等负荷”，或“首回路变化，其他回路保持保存负荷” | — | 全回路等负荷 | 每行单独设置 |
| 环境 | 环境温度 | °C | 25 | — |
| 中心埋深 | — | m | 0.7 | — |
| 土壤热阻率 | — | K·m/W | 1.0、1.5 | — |
| 中心距 | 相邻电缆中心距离 | m | — | — |
| 接地 | 两端接地、单点接地或待明确 | — | 两端接地 | 待明确时不能计算 |
| 管内径、管外径、管材热阻率 | 排管的几何与材料 | m、K·m/W | — | 排管工况需要 |
| 条件来源 | 本行条件的出处 | — | — | 必填 |

**点什么**：勾选工况，点 **计算所选工况**，预检后确认运行。

**看到什么**：“载流量表”列出计算、工况、允许电流（A）、状态、余量（A）和条件，最多 100 行。状态为已计算、未运行、计算失败、待补数据、输入错误或超出范围；拒算的工况保留原因。

“方法参数”页签只编辑全表共用的方法参数；每行的排列、环境和载流量口径在“结果表 → 所选工况条件”中修改。四芯及 3+1 芯结构显示“四芯载流量 · 方法未覆盖”，可以点 **新建载流量研究** 改用适用的方法。需要更深入地研究某个工况时，点 **用于载流量研究** 以这个型号新建研究。依据见[型号载流量表](../../methods/notes/type-rating-table/)。

## 6. 方案对比

用于比较同一型号的不同设计方案，并把选定的方案采纳为新版本草稿。

1. **建立方案**：点 **建立方案**，填写方案名称（最多 80 字），点 **建立方案**。方案从当前已保存版本分支，原版本的计算结果不会成为新方案的当前结果。
2. **比较**：页签为“结果矩阵”（方案结果矩阵与全部适用要求对比）、“参数差异”和“截面对比”。指标包括外径、单位长度用料、导体铜用料和标准核对通过情况；要求判定为满足、不满足、缺项或未覆盖，另有未运行、历史和无法判断。单元格中的 **补结构数据**、**打开标准核对** 跳到对应位置。
3. **采纳为新版本草稿**：在“采纳方案”中选择方案，点 **采纳为新版本草稿**，勾选“已核对方案、全部要求与保存结果；采纳不代表批准或发布”，点 **确认采纳**。缺项和未覆盖项随草稿保留。完成后可以 **打开新草稿规格书**。

## 7. 规格书

**打开哪里**：型号浏览器 **规格书**，页签为内容、预览、审核与发布、修订记录。

**点什么**：

- **生成规格书**：按需补算结构、电气、载流量、短路和标准核对五部分，生成当前版本并下载 PDF。被预检阻止时显示“查看结构推导条件”等入口。
- **文档版本**：客户版或内部审核版；内部审核版可以 **导出内部审核稿**，缺项随文列出。
- **正式交付（PDF / Excel）**：填写单位名称、文件编号和版次，核对来源与签栏后下载，见[正式交付文件](../deliverables/)。

**看到什么**：规格书共八章：封面、标准、结构、电气、载流、短路、核对、修订，客户版第 7 章为“标准核对表”，第 8 章为“文档修订记录与来源”。状态为草稿、待人工审核、已批准、已发布或已过期。

| 提示 | 处理 |
| --- | --- |
| 已过期：输入或来源已变化；重新生成后才能交付当前客户版。 | 重新生成规格书 |
| 当前规格书来源已过期，请先重新生成并保存。 | 正式交付不可用；重新生成后再导出 |
| 生成期间输入发生变化；已完成运行已保存，请保存后重新生成。 | 保存后重新生成 |
| 请先保存型号与方法条件 | 保存后再生成 |

## 8. 审核与发布

**打开哪里**：规格书的 **审核与发布** 页签。

**看到什么**：“N 项阻止发布”，按以下几组列出，每项都有处理入口：

| 分组 | 含义 |
| --- | --- |
| 需要工程师补输入 | 缺少有来源的设计输入 |
| 需要出厂实测值 | 标准要求按实测值判定的项目 |
| 标准依据未覆盖 | 依据库尚未收录的条款 |
| 需要人工批准 | 执行标准声明、要求审核、材料固定版本核对等人工确认关口 |

某一项不在本次发布范围内时，点 **声明本次发布不含此项**，填写不含原因（至少 5 个字），点 **本人确认不含此项**；该项移到“已声明不含”组，规格书封面列出“本次发布不含项”及原因和声明人。**撤销声明** 可以收回。

**发布流程**：

1. 阻止项处理完后点 **采纳为版本草稿**。
2. **提交评审**：填写变更摘要（最多 500 字）和编制人（最多 120 字），勾选“已核对当前版本与提交前校核清单”。状态变为待人工审核。
3. 审核人点 **人工批准**，勾选“我本人已核对来源、校核清单并确认此操作”。
4. 点 **发布型号版本**，同样勾选确认。发布后版本内容固定，按钮变为 **导出 PDF**。

提交评审绑定当时的内容摘要；内容变化后原提交失效，需要重新提交。导出或下载文件不会改变审核和发布状态。

**修订记录** 页签的“文档修订记录”列出每次提交的文件版本、变更摘要、编制人和日期；尚未提交时显示“尚未提交文档评审”。

## 9. 批量操作

**打开哪里**：型号设计列表的“型号批量操作”。

1. 勾选型号，在 **批量操作** 中选择生成规格书、下载规格书、建立方案或提交审核；生成与下载还要选择客户版或内部审核版。
2. 点 **预览批量操作**，逐项核对每个型号是否可操作，以及不能操作的原因。
3. 勾选确认后点 **确认<操作>（N 项）**。执行中可以 **停止剩余项**；结束后可以 **重新核对未完成项**。

提交审核只提交已采纳的新版本草稿，可以“统一填写”编制人和变更摘要后“应用到可提交项”。建立方案的名称为 1–80 字。

| 提示 | 处理 |
| --- | --- |
| 先勾选列表中的型号，再预览操作。 | 勾选型号 |
| 请先在方案对比中采纳为新版本草稿。 | 先采纳方案 |
| 已发布版本不可再次提交；需要修改时请先建立方案。 | 建立方案后修改 |

## 状态与报错

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| N 处未保存 · 保存后重算受影响的结果。 | 有尚未保存的修改 | 保存（Ctrl+S） |
| 型号有未保存修改 | 离开页面时有草稿 | 保存后再离开，或点“放弃修改并离开” |
| 请先保存结构修改 / 请先保存方法条件 | 运行前有未保存的修改 | 先保存 |
| 已过期 · 方法 … | 输入或方法已变化 | 重新运行该模块 |
| 尚未运行 | 有方法，没有结果 | 运行该模块 |
| 此版本只读 / 此型号版本保持只读，请建立新版本方案 | 历史或已发布版本 | 建立方案或新版本草稿 |
| 型号结构来源待补：请核对三芯尺寸、成缆绞距、屏蔽电阻与铠装绕包的真实依据，在结构页录入出处后重新计算。 | 结构参数缺少来源 | 在结构页录入出处后重新计算 |
| 计算方法暂时不可用，请重新读取；仍失败时联系管理员检查安装。 | 插件不可用 | 重新读取，或联系管理员 |
