插件 `cablesim.thermal-network`（参考方法 MV-THERMAL）是一个**可审计的简化稳态热网络**，用于在同一份输入上与 IEC 60287 等方法交叉校核。它不是完整的 IEC 60287 实现，不能替代正式计算。

## 原理

电缆各同心层的径向热阻：

$$
T_k = \frac{\rho_{th,k}}{2\pi}\,\ln\frac{r_{k+1}}{r_k}
$$

均匀半空间土壤中三根电缆之间的热阻矩阵（镜像法，地表恒温）：

$$
G_{ii} = \frac{\rho_{soil}}{2\pi}\,\operatorname{arcosh}\frac{h_i}{r_5}, \qquad
G_{ij} = \frac{\rho_{soil}}{2\pi}\,\ln\frac{D'_{ij}}{D_{ij}}\quad (i \ne j)
$$

$h_i$ 为电缆中心埋深，$r_5$ 为电缆外半径，$D_{ij}$ 为两缆中心距，$D'_{ij}$ 为电缆 $i$ 到电缆 $j$ 镜像的距离。导体相对环境的温升向量：

$$
\mathbf{u} = H\,\mathbf{q}_c + \mathbf{d}, \qquad
H = (1+\lambda)\,G + \operatorname{diag}\!\Big(\sum_k T_k + \lambda T_4\Big)
$$

$\mathbf{q}_c$ 为各相导体损耗，$\lambda$ 为屏蔽损耗比，$\mathbf{d}$ 为介质损耗的温升贡献。导体电阻随温度线性变化，三相温度和电阻逐相求解，用二分法求最热一相刚好达到温限时的电流，即参考载流量。

## 公式来源

公式是热传导和电路的基本形式，写法与 IEC 60287-2-1 的同心层热阻和镜像法一致，但不是逐条的标准实现。完整推导、单位约定和结果核算见[载流量口径与热网络参考](../notes/rating-basis/)。

| 计算项 | 公式 | 说明 |
| --- | --- | --- |
| 同心层热阻 | $T_k = \rho_{th,k}\ln(r_{k+1}/r_k)/(2\pi)$ | 金属等效层按热导率 400 W/(m·K) 的假设计算 |
| 土壤自热与互热 | 上面的 $G_{ii}$、$G_{ij}$ | 均匀半空间，地表恒温 |
| 交流电阻 | $R_{AC}(\theta) = R_{20}(1+k_{AC})[1+\alpha(\theta-20)]$ | $k_{AC}$ 为输入的交流附加系数；温度系数铜 0.00393、铝 0.00403（1/°C） |
| 电容与介质损耗 | $C = 2\pi\varepsilon_0\varepsilon_r/\ln(r_2/r_1)$，$W_d = 2\pi f C U_0^2\tan\delta$ | $U_0$ 为相对地电压 |
| 载流量 | 二分法求 $\max(\theta_A,\theta_B,\theta_C)=\theta_{limit}$ | 迭代 70 次，搜索上界低于热反馈的奇异阈值 |

## 适用范围

- 单回路、三根相同的无铠装单芯电缆；导体屏蔽、绝缘、绝缘屏蔽、金属屏蔽、外护套等同心层；水平或等边三角排列。
- 均匀土壤，地表恒温，轴向无限长；三相平衡电流，每相一根电缆。
- 交流附加系数和屏蔽损耗比是**输入假设**，不自动计算集肤、邻近效应或护套环流。

## 超出范围时

不符合上述条件时插件拒绝计算，不改用默认值，也不静默修正输入。常见提示：

| 提示 | 情况 |
| --- | --- |
| “简化参考仅支持单回路、单截面、单个稳态负荷” | 多回路、多截面或多个工况 |
| “简化热网络不支持逐电缆负荷覆盖；请使用带明确损耗输入的 IEC 互热方法。” | 给各电缆单独指定了电流 |
| “简化热网络仅支持均匀土壤；回填区或土壤分层计算尚未接入。……” | 敷设截面有回填区或土壤分层 |
| “简化参考仅支持均匀土壤直埋稳态，无排管” | 排管敷设 |
| “简化参考仅支持单芯电缆”“简化参考仅支持平衡三相且每相一根电缆” | 三芯电缆、并联或不平衡负荷 |
| “简化参考要求原六层同心结构，不支持铠装或额外层” | 有铠装或其他附加层 |
| “领域研究需要明确 R20，不采用演示电阻” | 型号缺少导体 R₂₀ |
| “此简化方法要求两层半导电材料热阻率一致” | 导体屏蔽与绝缘屏蔽的热阻率不同 |
| “坐标不是受支持的平排或等边品字形，不能按模板覆盖坐标” | 电缆位置不是平排或等边品字形 |

另外：埋深小于电缆外半径的 10 倍、或电缆位置重叠时拒绝计算；给定运行电流超出线性热反馈的稳定范围时拒绝该电流的解（这不是真实电缆热失控阈值的精确判断）；零电流时介质损耗已使温度达到温限，则没有可用的正载流量。运行温度超过 150 °C 时另行警告材料线性外推已失去工程可靠性。

## 输入要求

导体截面与 R₂₀、各层厚度与热阻率、埋深与排列、土壤热阻率、地表温度、导体温限，以及显式给出的交流附加系数（0–1）和屏蔽损耗系数（0–2）。各参数的单位和范围见下方插件清单。

## 验证情况

清单中的验证等级为“未经独立验证”，没有声明验证用例。

- 回归测试只保证重构前后数值不变，不是正确性证据。
- 每次求解输出温度方程的最大残差，并核对径向逐层温度与矩阵求得的表面温度一致。
- 用于工程之前，须针对目标电缆和敷设方式，用正式标准文本、厂家结构材料数据、独立实现或参考软件以及实测结果，分别验证电阻、损耗、热阻、温度与载流量。经 CIGRE TB 880 算例逐项核对的方法是 [IEC 60287 稳态载流量](../iec-60287/)。

## 已知限制

- 不支持排管、空气敷设、回填分区、干燥带、多回路、铠装、外部热源、接头与端部、谐波、暂态、周期与应急负荷，也不做绝缘配合校核。
- 金属屏蔽按连续等效铜圆筒处理，不反映实际铜丝间隙或接触热阻。
- 土壤温度图按电缆中心线热源叠加，靠近电缆表面的数值与矩阵求得的表面温度存在近似差别；该图不是有限元或三维仿真。
