有限元方法求解电缆截面和敷设区域的温度场与电磁场，用来检查 IEC 60287 解析假设之外的影响，并给出可视化的温度分布。主要由两个插件提供：

- `cablesim.simulation`（电缆有限元仿真）：多区域稳态导热、GetDP 时谐涡流、Elmer 稳态与瞬态热场，在 Slurm 超算集群上运行；
- `cablesim.native-reference`（有限元与线源参考）：单回路直埋的固定功率有限元温度、电热耦合和线热源交叉校核，在本机运行，作参考研究。

## 原理

截面稳态导热（二维、轴向无限长）：

$$
-\nabla\cdot\left(k\,\nabla T\right) = q \quad \text{于各区域}, \qquad T = T_{amb} \ \text{于地表等给定温度边界}
$$

$k$ 为各区域热导率，$q$ 为体积热源（导体、金属套、铠装损耗和介质损耗）。与 IEC 的“热阻串联”不同，有限元直接求解整个区域的温度分布，能够处理回填、分层土壤、多根电缆的真实几何。

- **IEC 损耗反馈**：损耗按 IEC 60287 公式计算，并随金属层平均温度迭代更新。
- **护套损耗**：GetDP 求解二维时谐涡流场，按相序与接地拓扑（单点、两端、交叉互联）计算护套环流与涡流损耗。
- **电热耦合**：电导率随温度变化 $\sigma(T)$ 与导热双向迭代，保存逐轮的温度、功率与能量残差。
- **暂态**：给定均匀初温和逐区体积热容，计算阶跃、周期或应急负荷下的温升过程。

## 公式与求解器来源

| 部分 | 来源 |
| --- | --- |
| 导体、金属套、铠装与介质损耗 | IEC 60287-1-1:2023，随金属层平均温度迭代 |
| 皱纹护套的环形等效 | IEC 60287-2-1:2023 §4.1.2.1、§4.1.5.1，气隙参数须有来源 |
| 管内空气 | IEC 60287-2-1:2023 的管内热阻，换算为固定等效导热率；不求解流体 |
| 远场边界 | 均匀半无限土壤、地表等温时的 Kennelly 镜像线热源；也可选择环境定温截断 |
| 护套损耗与电热耦合 | GetDP 3.5.0，二维磁准静态时谐场与场路联立 |
| 稳态与瞬态热场 | Elmer 26.1（求解器报告 9.0）；scikit-fem 用于交叉校核 |

外部求解程序不随插件分发，启动前检测版本，缺失或版本不符时明确失败，不退化到其他求解器。每次运行保存问题定义、网格、求解器版本和结果工件。

## 收敛与证据

有限元结果必须给出收敛证据：

- **IEC 与有限元对比**：按多档网格比例（默认 1.5、1.0、0.75）逐档求解，再把计算域放大（默认 2 倍）求解一次。最后两档网格之间、以及最细网格与放大计算域之间，最高温度变化都不超过温度迭代容差（默认 0.1 K）、允许电流变化都不超过载流量校核容差（默认 0.5 A），才输出偏差结论。
- **有限元热场的自动加密与扩域**：逐级把网格减半或计算域加倍，网格与扩域各自连续两级的热点温度变化都小于门槛（默认 0.1 K）才算收敛，之后在最终网格上反求允许电流。
- **迭代容差**：温度收敛容差、温度迭代容差和收敛门槛都是**温差**，以 K 显示和输入；初始温度、环境温度等绝对温度以 °C 显示。
- **能量平衡**：电热耦合同时检查温度、功率与能量残差。

没有合格收敛证据的结果不显示为正式值，也不能正式导出。逐级结果、核时和保存运行见[仿真研究 · 收敛研究](../../guide/simulation/#6-收敛研究)。

## 与 IEC 的对照

“研究敷设截面 IEC 与收敛有限元对比”在同一保存工况下逐回路反求允许电流，与 IEC 结果并列。两者的模型假设不同（有限元为有限计算域与侧底边界，IEC 为半无限均匀土壤；集总温度与层内梯度；标准介质损耗路径与体热源），**差异本身不是误差证明**，报告会列出差异来源，不据此判定优劣。网格和加倍计算域都通过后才输出偏差结论，结果标为“仅供参考，未经工程批准”。

## 适用范围与输入

- 截面为同心圆层电缆（单芯，或各芯独立屏蔽的三芯，视具体能力而定），多区域土壤、矩形回填与分层土壤；多区域稳态热场支持 1–64 根有正间隙的同心圆缆。
- 材料热导率、体积热容、电导率及其有效温区必须有来源；每个材料域的体积热容须有正文页码、表号与摘要，没有默认热容。
- 多回路的电损耗须有独立来源；反求某一回路的允许电流时，其他回路保持保存负荷。
- 求解在 Slurm 超算集群执行，配置见[仿真计算环境](../../install/hpc/)。

## 超出范围时

- 只在超算运行的方法遇到超算未配置时，预检提示“超算未配置，请前往设置 → 计算位置。输入已保存。”，不会改到本机计算。
- 超出材料有效温区、不收敛或几何不受支持（如相切以外的接触、非圆截面）时明确拒绝，不外推材料数据。
- 缺少网格、热容或材料来源时预检列出缺项，不使用默认值。
- 未收敛的结果保留在运行记录中，但不进入有效结论，也不导出为应急额定输入；单次求解不自动证明网格或时间步收敛。
- 多回路护套损耗的固定点系数不能用于 IEC 的变温迭代；只有单截面完整温度表并通过独立中心点验证后，才允许在声明范围内迭代。

## 验证算例

| 能力 | 验证算例 |
| --- | --- |
| 电缆有限元热场（IEC 损耗反馈） | 均匀半空间圆盘热源的 Kennelly 解析解；三芯导体、屏蔽、铠装热源守恒与 IEC 损耗交叉核对 |
| IEC 与收敛有限元对比 | 均匀半空间手算参考，网格与计算域收敛 |
| 暂态温升 | 均匀圆柱 Bessel 阶跃叠加（逐时间步）；独立平板 Fourier 解 |
| 有限元阶跃与预载暂态 | 镜像线热源解析解（恒温地表）与稳态极限 |
| 接地拓扑与护套损耗 | 独立的 Faraday / Kirchhoff 手算回路；公开 GetDP 电磁基准 |
| 双向稳态电热耦合 | 同轴 I²R(T) 手算；独立同轴解析解与 COMSOL 对照 |
| 完整接触热域、多端子电容场、同轴频域电流 | COMSOL 教程模型（COMSOL02、COMSOL06、submarine02/03）对照 |
| 平排护套回路 | Lunca 2023 论文表 3 的解析子模型 |
| GetDP 涡流、Elmer 热场 | 圆柱 Bessel（V01）、平板 Fourier 阶跃与周期（V02）、干湿土交叉校核（E03）、平排护套场路联立（E05）等 |

各算例与原文的最大相对偏差在软件的“方法 → 验证算例”中列出。本机参考能力（`cablesim.native-reference`）为“未经独立验证”，只作参考研究。

## 已知限制

- 二维截面、轴向无限长：不含三维端部与绞合效应、土壤水分迁移与干燥、对流流场；辐射只在多区域热场中作为对给定环境的局部交换，不含相互遮挡。
- 相切的外护套按零面积理想点接触，不代表实测的接触宽度或接触热阻。
- 暂态按恒定热物性和声明温度下冻结的电阻计算，不含 R(T) 双向反馈。
- 交叉互联按三个独立二维截面加电路计算，不含弯曲的三维效应和大地回流。
- 与 IEC 的对照结果为参考研究，不自动批准，也不代替 IEC 载流量或工程批准。
