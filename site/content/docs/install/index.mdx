CableSimPro 以离线安装包发行：Windows 10 / 11 x64 和 Linux x86_64 各一个 ZIP。包里带有固定版本的 Python 运行时、全部依赖和预构建的界面，**安装端不需要预装 Python、Node、编译器或 Git，也不需要管理员权限，安装过程不联网**。

安装包还带有固定版本的 Node.js 和 Agent 对话服务，安装后[接入模型](./model/)即可使用 Agent 对话，见 [Agent 对话服务](./agent/)。

## 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11 x64；或 glibc 兼容的 Linux x86_64（安装前核对包内记录的最低 glibc 版本） |
| 浏览器 | 较新的 Chrome、Edge 或 Firefox，推荐 1366×768 及以上分辨率 |
| 网络 | 安装和计算都不需要外网；只有接入模型服务或超算时，才需要与对应服务连通 |

不支持 ARM 平台，也不保证所有 Linux 发行版都可用；特定系统的图形运行库请先在目标机器上试装确认。

## 获取安装包

正式版本由发行方提供 ZIP 和同名的 `.zip.json` 回执。回执记录归档的 SHA256、源码提交和构建编号，收到文件后先核对摘要：

```powershell
Get-FileHash .\CableSimPro-Windows.zip -Algorithm SHA256
```

```sh
sha256sum CableSimPro-Linux.zip
```

开发中的版本可在代码仓库 GitHub Actions 的 “Offline release installation” 任务产物里下载（`CableSimPro-release-Windows`、`CableSimPro-release-Linux`）。这些是验证用的构建，不是正式发布。

## 安装并启动

<Steps>
<Step>

把 ZIP 解压到任意目录，例如 `D:\CableSimPro`。

</Step>
<Step>

把解压目录里的 `release.toml` 复制到解压目录之外长期保存，例如 `D:\CableSimPro-config\release.toml`（Linux 如 `/etc/cablesimpro/release.toml`），以后启动、升级和回退都用这一份。用文本编辑器打开这份副本，至少确认数据目录 `storage.data_dir`：默认是用户主目录下的 `~/CableSimPro-data`，**数据目录也必须在解压目录之外**。其他配置项见 [release.toml 配置](./configuration/)。

</Step>
<Step>

启动时用 `--config` 指向这份配置：Windows 在 PowerShell 中运行 `.\start.cmd --config D:\CableSimPro-config\release.toml`；Linux 运行 `sh start.sh --config /etc/cablesimpro/release.toml`。没有桌面的服务器加 `--no-browser`；只想完成安装和校验、不启动服务时加 `--no-start`。

</Step>
<Step>

首次启动会把运行时复制到 `数据目录/programs/<构建编号前 16 位>/`，在那里建立独立的 Python 环境，只从包内的 wheel 按哈希离线安装依赖，再做依赖完整性和导入检查。依赖缺失会明确失败，不会临时联网补装。

</Step>
<Step>

工程库不存在且 `initialization.seed_examples = true` 时，用随附的公开教学输入生成示例工程（不调用外部模型，不生成有限元结果），需要几分钟。随后服务启动，浏览器打开 `http://127.0.0.1:8100/`。

</Step>
<Step>

平台启动后，启动程序再启动 Agent 对话服务（默认端口 8111，只监听本机）。对话服务没有启动成功时，启动窗口会写明原因，其余功能照常可用；处理方法见 [Agent 对话服务](./agent/#故障排查)。

</Step>
</Steps>

安装完成后可以删除解压目录：解释器和程序都已装进数据目录，配置文件也已经放在外面。以后运行程序目录里的同名入口，并用 `--config` 指向这份配置文件：

```powershell
<数据目录>\programs\<构建编号前16位>\start.cmd --config D:\CableSimPro-config\release.toml
```

```sh
sh <数据目录>/programs/<构建编号前16位>/start.sh --config /etc/cablesimpro/release.toml
```

<Callout type="warn" title="Windows 路径长度">

安装程序会读取系统的 `LongPathsEnabled` 设置，按实际文件逐个检查路径长度。超出 260 字符限制时拒绝安装，并提示换一个更短的数据目录（例如 `D:/CableSimPro-data`），不要求修改系统策略。

</Callout>

## 启动时做了哪些检查

- 服务启动后同时检查 `/api/health`、`/api/release-info` 和前端首页，全部正常才打开浏览器。`/api/release-info` 返回当前构建编号和源码提交，用来确认访问到的是刚安装的版本。
- 启动程序持有独占运行锁，同一数据目录同时只能运行一个实例。
- 启动完成前，工程接口一律返回 `503 RELEASE_STARTING`，不会在仍可能回退的时间窗口里写入工程数据。
- 运行期间不执行 npm、pip、自动更新或任何外部下载。

## 从源码运行（开发与评估）

需要 Python 3.11+、Node.js 22.12+ 和 npm，首次运行要联网安装依赖。在代码仓库根目录：

```sh
python scripts/run_demo.py
```

它会构建界面，在 `.data/release/` 下用与安装包相同的发布种子生成示例库，然后在 `http://127.0.0.1:8100/` 启动；之后启动保留已有数据。常用参数：`--skip-install`（依赖已就绪）、`--no-browser`、`--port 8101`。按 Ctrl+C 停止。

一键演示同时构建并启动 Agent 对话服务（需要 Node.js 22.12+），退出时一并停止。Agent 需要先[接入模型](./model/)；模型密钥只从系统凭据或环境变量读取，不写入配置文件或工程库。
