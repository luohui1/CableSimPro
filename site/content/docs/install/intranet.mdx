---
title: "内网部署"
description: "让同一内网的多台电脑通过浏览器使用一台服务器上的 CableSimPro。"
---

默认配置只允许本机访问。要让同一内网的同事通过浏览器使用，在服务器上按[下载与安装](../)装好后，改三处配置并放行端口。

<Callout type="warn" title="没有账号与权限管理">

当前版本不提供登录、账号和权限服务，访问到服务的人都可以读写全部工程。只在受信任的内网中开放，必要时在前面加机构已有的访问控制（VPN、带认证的反向代理等），**不要直接暴露到公网**。

</Callout>
## 1. 修改 release.toml

```toml
[server]
host = "0.0.0.0"          # 监听全部网卡；也可以写服务器在内网中的固定 IP
port = 8100
open_browser = false
trusted_hosts = ["cablesim.example.com", "192.0.2.10"]
```

- `host` 必须是 IP 地址或 `localhost`，不能写主机名。
- `trusted_hosts` 列出同事在浏览器地址栏里实际输入的主机名或 IP（上例为示例值，请换成你们的）。宿主会拒绝其他 Host 的请求（返回 403），也拒绝来自其他站点的跨站写入。
- 保存后重启服务。

## 2. 放行端口

在服务器防火墙中允许内网访问 `port` 指定的端口（默认 8100）。只对需要使用的网段开放。

## 3. 访问

同事在浏览器打开 `http://<trusted_hosts 中的名字>:8100/`。界面和全部接口都走这一个端口。

## 放在反向代理后面

如果用 Nginx 等反向代理统一入口，代理把请求转发到 `http://127.0.0.1:8100`，并保留原始 Host：

```nginx
location / {
    proxy_pass http://127.0.0.1:8100;
    proxy_set_header Host $host;
    client_max_body_size 70m;   # 厂家 PDF 原件上传上限为 65 MiB
}
```

此时浏览器地址栏里的主机名仍要列入 `trusted_hosts`。上传大小：结构表等一般请求不超过 11 MiB，厂家 PDF 原件不超过 65 MiB，超过时宿主返回 413。

## Agent 对话

内网用户通过平台端口使用 Agent 对话：对话页和对话服务都经平台转发，对话服务本身只监听服务器本机（默认 8111 端口），**不需要**放行 8111 端口。模型请求由服务器上的平台进程发出，内网部署模型服务时，确认服务器能访问模型服务的地址。见 [Agent 对话服务](../agent/)。
