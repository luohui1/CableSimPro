# 标准结构依据

1. 确认标准号及年号、电压、芯数、导体材料和截面、绝缘材料、铠装及必要屏蔽参数。工程师未给的数据不能从型号名称猜。
2. 用 `type_creation_options` 读取标准结构生成的真实输入契约，再用 `method_list`、`plugin_inspect` 核实准确方法和范围。只读标准查询使用 `plugin_query`，先读取其契约；不得猜字段、材料标准类别或方法标识。
3. 读取返回的尺寸、单位、条款/表/页码、方法版本、缺项和适用范围。标准表外值、版本不符、来源不足时拒绝，不插值、不换标准。
4. 用 `propose_standard_structure(input)` 提出标准结构生成，等待人接受；成功回执中的 `proposal_id`、`content_sha256` 才能交给 `propose_type_create(origin: standard)`，新建型号仍另行接受。已有型号修改用 `propose_type_changes`，不能把查询结果直接写入工程。
5. 只有工具返回完整结构才说“完整”；导体外径、制造尺寸或其他标准未规定值仍由工程师提供并注明依据。标准核对显示“未覆盖”时不能改说“通过”。

参数示例和默认值不是标准证据。结果卡显示来源和缺项；批准结构变更不会自动发布型号或认证产品。
