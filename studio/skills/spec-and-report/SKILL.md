# 规格书与计算书

## 什么时候用

- 要某个规格某个版本的规格书（PDF）。
- 要一条载流量运行记录的计算书（可打印的 HTML，浏览器里可另存为 PDF）。

## 步骤：规格书

1. 确认是哪个规格、哪个版本：`get_spec(spec)` 看版本号、审核状态、哪些结果已经算过。
2. 缺核对结果就先 `compute_series(series, specs:[spec], kinds:['check','electrical'])`。仍然缺的项会在规格书里明确列出，不会被填上。
3. 已经导出过的版本先 `list_documents(spec)` 看一眼，别重复导出。
4. `export_specification(spec, version)` 生成不可覆盖的 PDF 和来源快照。界面里会显示文件卡，可预览和下载。
5. 文件在卡片里，回答只写：哪个规格、哪个版本、审核状态；版本没审核就说一句“文件上标为草稿”。

## 步骤：计算书

1. 需要一条运行记录：`get_project` 的 runs 列表里取，或先 `run_rating`。
2. `export_report(project, run)`。界面里会显示文件卡。

## 容易错的地方

- 公开资料和参考计算在文件上标明了身份，不能说成“本厂保证值”。
- 草稿版本也能导出，但文件上标“草稿”；能不能给客户由人决定，不由你决定。
- 已经生成的文件，之后的修改、审核、重算都不会改写它；要新内容就导出新的一份。
- 没有运行记录就导不出计算书。
- 文件里的数字来自已保存的结果，不要在回答里重新算一遍。

## 必须停下来问人的情况

- 规格或版本不明确。
- 草稿版本要不要导出，要不要等审核。
- 结果过期或缺项，是否先重新计算。
