# 型号三维与几何证据

1. 用 `object_find` 定位型号设计，用 `type_read` 读取保存结构、修订和运行；需要资源版本时用 `cable_model_read`。
2. 用 `run_list`、`run_read` 读取实际保存的几何结果与工件引用，核对它们属于哪个输入版本。已有卡片或对象入口可在老工作台打开。
3. 需要重新生成时，先用 `method_list`、`plugin_inspect` 核对几何方法、输入、执行位置和桥的支持范围。只有 `propose_study`、`propose_study_run` 能完整支持该能力时才逐项提出、等待人接受。
4. 原生环境不具备、执行位置受限或参数缺失时停止；返回具体缺项和型号工作台的几何入口。不得画替代模型、伪造 STEP 下载地址或把简单截面示意说成真实实体。

区分“结构可显示”“几何有效”“可用于分析网格”和“工程已核验”。没有保存工件不能声称体积、质量或网格有效；历史工件标明对应版本。原生求解不在云端本机执行。
