# 厂家结构表接入与核对

1. 用 `structure_import_inspect` 检查老平台实际能力，文件名只作为格式信息，不能当成已读取文件的证据。读取返回的支持状态、缺失接口及工作台入口。
2. 当前基线没有厂家 CSV/XLSX 批量结构表导入接口。工具拒绝时，明确说尚不能把该表导进型号库，指出需要数据模块提供的导入预览、字段映射、逐行来源和批准后入库能力。不得声称已经解析、导入或核对。
3. 不把 CSV/XLSX 当 PDF 上传，不把任意文本当已核对的结构，不转用另一套 Studio 操作层或产品数据库，也不逐条猜数绕过批量校验。
4. 接口将来可用时，先依据返回的契约检查原件摘要、厂家/资料名、页/表/行、字段单位、材料类别、缺项和异常行；所有写入仍须后端提案、人接受后执行。缺数据的行保留拒绝原因，不能用默认值补齐。
5. 对老平台已经存在的型号设计，可以用 `object_find`、`type_read(view: input)` 按 `next_page` 读取保存结构和缺项，再按 `cable-revision` 的批准流程创建或运行核对；输入页本身不是标准核对结果，也不表示新上传的表已导入。

来源说明必须与实际将保存的来源一致；未读过原件不报行数、成功数或规格值。用户拒绝导入提案后不自动重提。
