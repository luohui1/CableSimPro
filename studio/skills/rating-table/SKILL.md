# 载流量表

## 什么时候用

要把一个规格在若干种条件下的允许电流整理成表，随规格书交付。只算一个条件用 ampacity-rating，不用本技能。

## 步骤

1. 定规格和版本：`list_library` 或 `get_spec` 取规格标识和版本号；工程师没指定就问，指定“挑一个”时选一个三芯铠装的公开厂家规格并说明选了哪个。
2. 条件由工程师给，每条都要写明四项：敷设方式 layout、中心埋深 depth_m、土壤热阻率 soil_thermal_resistivity（K·m/W）、环境温度 ambient_temperature_c（°C）。几个值取组合，就一个组合写一条。
3. layout 的写法：三芯直埋单回 `three_core_buried_single`，三芯直埋三回水平 `three_core_buried_horizontal`；单芯有 `trefoil`、`flat`、`ducts`。不确定就问，或用 `get_project` 看某个工程的可用敷设方式。
4. `build_rating_table(spec, version, title, conditions)`：conditions 是数组，一行一个条件，一次最多 24 条；每条约 2～8 秒，一次不要超过 8 条。结果是一张表，每行对应一条运行记录。
5. 读返回：每行的允许电流和可信分档；方法不覆盖的条件写着拒算原因，不补估计值。
6. `open_in_workbench(target:'spec', spec, version)`。回答只写：哪个规格哪个版本、几个条件、最大和最小的允许电流各在哪个条件、有几条被方法拒算（说明原因）。

## 容易错的地方

- 条件里缺任何一项都不要自己补：问工程师。
- 表挂在这个版本上，版本改了结构就是新版本，旧表不会自动搬过去：要重新出表。
- 表是可重算的结果，不改版本的结构和审核状态；导出规格书时会带上这个版本已有的表。
- 带回填或包封的敷设写不进表，会被明确拒绝：如实转述。
- 失败的表不保存：工具会说明；不要用估计值补一张。

## 必须停下来问人的情况

- 规格和版本、任何一个条件的取值。
- 表里有条件被方法拒算，下一步怎么处理（改条件、去掉、还是保留拒算的行）。
