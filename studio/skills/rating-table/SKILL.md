# 载流量表

1. 用 `object_find`、`type_read`、`study_list` 定位准确型号版本和已有载流量研究。不要把型号设计和库版本混用。
2. 用 `run_list`、`run_read` 读取已有表或批量工况结果，保留敷设、埋深、土壤热阻率、环境温度、方法版本、来源及每行状态。失败或缺项行不给估计值。
3. 新算条件必须由工程师给全，并经 `workspace_read` 与保存输入核对。使用 `ampacity-rating` 的流程逐项提出研究、输入修改和运行；每个业务写入都等待人接受。
4. 只有桥实际提供对应研究驱动器或表操作时才创建整张表。没有专用生成工具时，说明当前只能读取已有表或逐项运行，给出老平台载流量表工作台入口；不能调用已经移除的 Studio 表操作。
5. 要交付已有结果，用 `propose_delivery` 提案并等待接受；只有返回真实保存文件才展示下载。文件未包含表时不要声称已经写进规格书。

不同型号修订、敷设、口径、方法或单位不能混成一列“相同条件”。外径、边界或损耗数据缺失时停止；不插值、不外推、不把公开手册值充作本次计算。
