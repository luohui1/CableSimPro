# 型号改版

## 什么时候用

工程师要改型号库里某个规格的结构尺寸，并看改完以后标准核对有什么变化。

## 步骤

1. `get_spec(spec)` 看结构表。只有 `origin` 为 table 的项能改，数值用结构表自己的单位（多为 mm）。
2. 改哪几项、改成多少、为什么改：工程师没说清就问。原因（note）是必填项，写工程师给的原因，不要自己编。
3. `revise_spec(spec, values, note)`，values 是“字段键 → 新值”。它会交审，审阅卡里逐项写改前和改后（带单位）。接受后生成新的草稿版本，原版本和它的结果原样保留。
4. `compute_series(series, specs:[spec], kinds:['check'])` 只对这个规格重新核对新草稿。
5. `list_check_failures(series, specs:[spec])` 或 `get_spec(spec)` 看新版的核对结论，和改版前对比：哪些项通过变成不通过，哪些项变化不大。
6. 回答：改了什么、新版本号、核对结论的变化。再 `open_in_workbench(target:'spec', spec, version)`。

## 容易错的地方

- 标称截面是规格的身份，不能改；要换截面就是另一个规格，需要导入。
- 随软件提供的演示结构没有结构表，不能改尺寸；要先导入本厂结构表。
- 返回 VERSION_CHANGED，说明规格已经有了新版本：重新 `get_spec` 再改，不要沿用旧版本号。
- 新版是“草稿”。提交审核、审核通过、发布只能由人做，你没有这类工具，也不要代办。
- 改尺寸可能让原来通过的项不通过（例如绝缘减薄）：如实报告，不要擅自再改回去。
- 新草稿一开始没有计算结果，要先算才有核对结论。

## 必须停下来问人的情况

- 改哪个值、改成多少、为什么改。
- 改后核对不通过，接下来怎么处理（回退、再改、还是保留供审核）。
- 修改的审阅被拒绝之后，换什么做法。
