# GB 50217 载流量校正

1. 用 `object_find`、`study_list` 找已保存的校正研究与基准运行，用 `study_read`、`run_read` 核对电缆版本、敷设、环境、基准电流、单位和来源。
2. 用 `method_list`、`plugin_inspect` 查已安装的校正方法及准确参数契约；用 `plugin_query` 时先读查询契约，不能凭记忆填写系数。
3. 基准条件是否成立由工程师确认。缺基准运行、没有确认、表外条件或方法不覆盖时停止，列明待补项；不可代签、插值或把其他电压/敷设的表拿来替用。
4. 用 `propose_study` 或 `propose_method_parameters` 提出明确的校正定义，再用 `propose_study_run` 提出运行；每项都由人接受。已安装的本地 GB 方法可以正式运行，是否提供 preview 不是执行位置的依据。基准确认必须来自工程师的明确确认，不能因其接受“创建研究”就自行补上。
5. 只读成功保存运行中的各项系数、条款/页码、校正后电流、适用范围及可信分档。回答区分原始基准和校正结果，保留精确的保存运行入口；未返回 IEC 温度、限制对象或余量时不能把 GB 结果套成 IEC 结果卡。

不自行相乘生成未被宿主保存的工程结论；修改输入后旧校正结果保留为历史，不自动成为新工况结论。
