# 新建型号

## 什么时候用

库里没有这款型号，也没有可导入的结构表：由工程师给出系列的写法和各层尺寸，或者先按标准生成初始结构再补齐。有结构表时用 cable-import-check，不用本技能。

## 步骤

1. 问清系列：名称、型号写法（例如 YJV22）、芯数（1 或 3）、额定电压 U0/U、执行标准（写到年号）。工程师没说的不要猜。
2. `list_series` 看库里有没有同名系列，有就问工程师是换名还是往已有系列里加规格。
3. `create_series(name, designation, cores, u0_v, u_v, standards)`：这是改动，会交审。接受后得到系列标识。
4. 规格的尺寸有两条路：
   - 工程师要“按标准生成”：先读 standard-structure 技能，拿到提案标识。
   - 工程师自己给数：直接 `create_spec(series, values, basis)`。values 的字段名和单位见工具说明（多为 mm）；每个数的依据（图纸号、标准条款）写进 basis，工程师没给依据就如实写“工程师给定”。
5. `create_spec` 也交审，审阅卡里逐项列出尺寸和出处。接受后是第 1 版草稿。
6. `compute_series(series, specs:[规格标识], kinds:['check','electrical'])` 算参数并核对，再 `list_check_failures(series, specs:[规格标识])`。
7. 审阅卡后面已有进工作台的按钮，不必再调 `open_in_workbench`。回答只写：建了什么（系列名、规格名、第 1 版草稿）；核对有几项不通过；需要工程师定的事，至多两件。尺寸和出处在审阅卡和卡片里，回答里不列。

## 容易错的地方

- 不替工程师编尺寸，也不用“常见值”补缺项；缺什么就问什么。
- 外径对不上（外径闭合不通过）、尺寸互相矛盾时，如实转述工具给的原因，不改数去凑。
- SERIES_EXISTS、SPEC_EXISTS 说明已经有了：不要重复建，问工程师是改名还是改尺寸出新版本（cable-revision）。
- 新规格是草稿，来源记为 Agent 填写、待工程师核对。提交审核、审核通过、发布只能由人做，你没有这类工具，也不要代办。

## 必须停下来问人的情况

- 系列的型号写法、芯数、电压、执行标准。
- 任何一个尺寸没有来源。
- 审阅被拒绝之后，换什么做法。
