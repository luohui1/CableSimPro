# 0.7.4 浅色工程工作区

## 实装

- 专业工作台和独立智能工程流继续共享一个 StudioProvider、工程版本、锁、审批与结果。
- 新浅色入口：一次交互式工程结构预览、一个资料流程说明资产。打开入口不创建工程。
- 工程画布切换三维结构、等比例截面、解析土壤温度和载流量曲线。视图切换不求解，原三维 canvas 保留。结果失效后移除场图与曲线。
- Agent 初始任务页含说明性敷设配图与任务入口。待审查时折叠草稿，把审批和候选参数放到主要区域；草稿可展开。
- 整合 PR13 的任务逻辑与 PR14 的局部工程资产/取景方法。统一显示几何实现；37股导体仅为外观，节距不是制造参数。GLB 仍导出原六层等效几何。
- 三张本地 PNG 配图、Three.js 源码和资产清单随包保留。没有在线配图依赖，没有字体文件。

## 生成接口与数据安全

开发中按用户指定尝试 Grok-image，但该会话返回 FORBIDDEN，未生成、未计入任何成功资产。配图采用原有公开代码生成的本地工程图；当前不宣称是 Grok 生成。后续图像服务结果可替换说明性资产，但不得替换真实模型、温度场或求解数据。

不得发送企业资料、真实客户参数、Key 或未授权标准全文到生成服务。显示资产不参与求解；材质外观不定义导热率/电阻。

## 测试

新增7条浏览器场景：无外发/无创建入口、四视图与canvas保留、过期场失效、审查与草稿、缺图回退、1440x900、390x844。保留旧客户端测试；原两份入口工程图改为一份交互结构与一份说明图的类型检查，不减少功能覆盖。三平台/Windows结果以同提交CI报告为准。

本地后端228项通过，显示几何18种配置通过。当前容器浏览器禁止localhost导航且WebGL不可用；浏览器及渲染验收使用GitHub runner，不修改容器浏览器策略。Windows设备比例是浏览器模拟，不是人工显示器验收。

## 未改变的边界

没有新增物理求解方法；土壤温度是均匀半空间解析结果，不是FEM，不反向修正载流量。现有单回路直埋/单根隔离竖向限制不变。未接入COMSOL、未做真实云端OCR/LLM准确率验收，无公网权限系统。本机研究预览，不是厂家合格数据或完整标准认证。
