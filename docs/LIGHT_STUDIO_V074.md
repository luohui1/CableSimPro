# 0.7.4 浅色工程工作区

## 实装

- 专业工作台和独立智能工程流继续共享一个 `StudioProvider`、工程版本、锁、审批、资料来源与结果。
- 新浅色入口提供一次交互式工程结构预览和一份资料流程说明资产；打开入口不创建工程。
- 工程画布可切换三维结构、等比例截面、解析土壤温度和载流量曲线。视图切换不求解，原三维 canvas 保留；输入变化后移除旧场图与旧曲线。
- Agent 初始任务页含说明性敷设配图与任务入口。待审查时折叠草稿，把审批和候选参数放到主要区域；草稿仍可展开恢复。
- 新增跨模式“工程状态带”：持续显示电缆结构、敷设条件、运行输入、资料/锁和当前结果；状态带只读取共享工程会话，点击后跳到真实工作台对象或 Agent 任务，不复制第二份业务状态。
- 整合任务逻辑与局部工程资产/取景方法。统一显示几何；37 股导体仅为外观，节距不是制造参数。GLB 仍导出原六层等效几何。
- 三张本地 PNG 配图、Three.js 源码和资产清单随包保留。没有在线配图依赖，没有字体文件。

## Grok-image 开发期资产流

2026-09-08 已通过 Grok-image（Grok Imagine 2.0）实际生成一张 2816 × 1584 的电缆数字孪生候选图，插件调用成功。该结果只用于确认开发期生成链路和视觉方向，不参与求解。

CableSimPro 后续开发默认使用 Grok-image 生成新的说明性工程候选图，但候选结果不能直接成为运行时远程依赖。进入仓库前必须经过人工技术审查、裁切/压缩、落盘、哈希与来源标记，并明确“说明图、非制造图、非仿真结果”。现有三张本地 PNG 来自项目参数化 Three.js 场景，不能改称为 Grok 作品。

不得向生成服务发送企业原件、真实客户参数、密钥、未授权标准全文或可识别项目资料。材质外观不定义导热率、电阻率或介电参数；生成图不能替代真实三维模型、温度场、载流量曲线和计算书。

## 测试

原有 8 条浅色工作区浏览器场景覆盖：无外发/无创建入口、四视图与 canvas 保留、过期场失效、审查与草稿、缺图回退、1440 × 900、390 × 844 和平板键盘流。

本轮新增工程状态带场景，验证同一提案和结果跨两种模式保持一致、指标跳转真实对象，以及窄屏内部横向浏览不造成页面级溢出。既有客户端测试不删除；三平台与 Windows 结果以同提交 CI 报告为准。

本地后端既有基线为 228 项通过，显示几何 18 种配置通过。当前容器浏览器禁止 localhost 导航且 WebGL 不可用；浏览器及渲染验收使用 GitHub runner，不修改容器浏览器策略。Windows 设备比例是浏览器模拟，不是人工显示器验收。

## 未改变的边界

没有新增物理求解方法；土壤温度是均匀半空间解析结果，不是 FEM，不反向修正载流量。现有单回路直埋/单根隔离竖向限制不变。未接入 COMSOL，未做真实云端 OCR/LLM 准确率验收，无公网权限系统。本机研究预览不是厂家合格数据或完整标准认证。
