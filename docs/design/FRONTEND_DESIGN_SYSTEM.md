## 1. 设计约束

### 1.1 用户与使用方式

- 主用户是电缆设计 / 仿真工程师：长时间在桌面端工作，频繁精确录入带单位的数值，反复比较方案，最后交付计算书。
- 界面的首要任务是**让人看清数据和它的状态**（来源、是否当前、是否满足准则、是否经过验证），其次才是美观。
- 不做营销式首页、大面积插画、装饰性渐变；不在设计稿中使用编造的工程数据或"已验证 / 已标定"之类的声明。演示数据必须标注"演示"。

### 1.2 显示环境

| 项目 | 约束 |
| --- | --- |
| 分辨率 | 1920×1080 为主要目标；1366×768 必须可用，不遮挡关键控件 |
| 系统缩放 | Windows 100% / 125% / 150% 都要检查 |
| 窄屏 | 窄屏只保证浏览与复核，不承诺在手机上完整编辑 |
| 离线 | 不加载远程字体、图片或脚本；字体用本机字体栈或随包分发且许可允许的字体 |

### 1.3 可访问性

- 正文与背景对比度 ≥ 4.5:1；大号文字、图形元素、控件边界 ≥ 3:1（WCAG 2.1 AA）。浅色和深色都要达标，由脚本自动校验。
- 键盘能完成所有主要流程；焦点始终可见。
- 状态不只靠颜色表达，必须同时有文字或图形（图标、形状、线型）。

### 1.4 文字与数值

- 中文、拉丁字母、等宽数字三种字形协调；数值一律使用等宽（表格）数字，便于纵向对齐比较。
- 单位始终可见，与数值保持同一基线；上下标（mm²、K·m/W）正确排版。
- 显示精度按物理量规则（[结果类型 §5](./RESULT_TYPES.md)），不显示虚假精度。

### 1.5 状态语言

以下状态必须各自有独立、可区分的视觉表达，不能合并成一个绿色对勾：

| 类别 | 状态 |
| --- | --- |
| 编辑状态 | 已保存、草稿、校验错误、版本冲突、已锁定 |
| 数据来源 | 演示、用户录入、厂家资料、标准值、推导值；已核对 / 未核对 |
| 运行执行 | 排队、执行中、成功、失败、已取消、中断 |
| 结果时效 | 当前、历史（输入已变化）、工件缺失或损坏 |
| 设计准则 | 满足、不满足、无法判断 |
| 验证等级 | 未验证、接口测试、解析基准、交叉验证 |

### 1.6 数据可视化

- **相别颜色**：三相需要固定分类色。候选：国内母线等场合常用的"A 黄 / B 绿 / C 红"，或 IEC 60445 的"L1 棕 / L2 黑 / L3 灰"。第 1 阶段一起比较，并且始终同时显示相别文字。
- **温度场色图**：使用感知均匀的顺序色图，不用彩虹色图（jet）；温差、比较结果使用发散色图。色图、刻度和单位要在浅色和深色下都清楚。
- **材料外观**：导体（铜 / 铝）、半导电层、绝缘、金属屏蔽、护套、土壤、回填有一套识别色，只用于辨认，界面上注明"外观不参与求解"。
- 图表（ECharts）、三维（Three.js）、截面（SVG）使用同一套 Token 派生的主题。

### 1.7 密度

默认是紧凑的工程密度：表格行高、控件高度约 28–32 px。以 1920×1080 下能同时看到模型树、画布、检查器为基准，不牺牲 1366×768 下的可用性。

## 3. 第 1 阶段：风格探索

### 3.1 用来比较的 3 个关键界面

同一组演示数据（明确标注"演示"），画在每个方向上：

1. **工作台**：模型树 + 电缆截面画布 + 属性检查器（带单位输入、来源标记、锁定字段、草稿状态）。
2. **研究设置**：方法选择、适用范围、预检问题列表（定位到字段）、运行按钮的可用 / 不可用状态。
3. **结果**：状态横幅（当前 / 历史）、关键数值、三相明细表、电流—温度曲线（含限值线）、截面温度场、准则检查、两个运行的比较。

每个方向都画浅色和深色两个版本的工作台，用来验证深色是否可行。

### 3.2 候选方向

| 方向 | 气质 | 色彩与形式 | 风险 |
| --- | --- | --- | --- |
| A 精密仪器 | 冷静、精确、现代 CAE 软件 | 冷中性灰为底，单一强调色（工程蓝），细线分隔，几乎无阴影，高密度 | 容易显得平淡，品牌辨识度低 |
| B 工程图纸 | 严谨、专业、与图纸和规格书一脉相承 | 暖白纸面、墨黑文字、制图线条、等宽标注、铜色强调 | 暖底色对温度场、材料色的干扰需要验证 |
| C 控制室 | 专注、适合长时间盯屏、数据最醒目 | 深色优先的石墨底，信号色表达状态，浅色版由深色派生 | 浅色为主的要求下，浅色版可能不如前两者 |

### 3.3 评价标准

1. 密集数值的可读性（三相表、检查器）
2. 各类状态能否一眼区分（§1.5）
3. 画布、温度场、图表是否清楚，不被界面颜色干扰
4. 长时间使用的舒适度
5. 与计算书（打印 / PDF）的一致性
6. 深色版本是否成立
7. 品牌辨识度

## 4. 组件清单（第 3 阶段范围）

**基础组件**：按钮（主要 / 次要 / 文字 / 危险）、图标按钮、文本输入、数值输入、选择框、复选框、单选、开关、标签页、分段控件、对话框、抽屉、提示、菜单、命令面板、徽标、进度、空状态、骨架屏、通知横幅。

**工程组件**：

| 组件 | 要点 |
| --- | --- |
| 数值输入 | 单位、合法范围提示、来源标记、锁定、草稿 / 错误 / 冲突状态；由参数 schema 的 `x-quantity` 驱动 |
| 数值显示 | 按物理量精度规则与显示单位；不可用时显示原因 |
| 状态标签 | §1.5 的各类状态，各自独立 |
| 对象树 | 回路、电缆类型、分层、敷设截面、研究、运行；筛选、展开、选中、键盘导航 |
| 属性表 | 分组、折叠、来源与编辑约束 |
| 文档标签 | 打开 / 关闭、草稿标记、只读标记 |
| 预检问题列表 | 严重程度、定位到字段、修改建议 |
| 结果渲染器 | 按[结果类型](./RESULT_TYPES.md)：数值、按实体对齐的明细表、表格、矩阵、曲线、时间序列、截面场、几何、准则检查 |
| 运行证据 | 输入版本、方法与插件版本、摘要、警告、局限说明 |
| 比较视图 | 先输入差异、再方法差异、再结果差异 |
| 截面画布 | 等比例绘制电缆分层与敷设布置；尺寸标注、缩放、选中联动 |
| 三维查看器 | 剖切、分层显示、视角预设 |

## 5. 旧界面沿用的行为规则（新界面验收清单）

来自旧界面及其 e2e 用例，新界面必须保持：

1. 草稿与已保存版本分开；未保存的草稿不能用于运行。
2. 保存时带基准版本；基准过期则明确失败，不覆盖他人修改，草稿保留。
3. 字段错误定位到具体字段；整体校验失败不部分保存。
4. 锁定字段不可编辑，提案也不能绕过。
5. 缺必需输入（如 R20）时不能运行，并说明原因、提供跳转。
6. 运行结果标明对应的工程版本；输入变化后，旧结果显示为历史，不冒充当前。
7. 比较两个运行时先显示输入差异。
8. 计算书从指定运行导出，不重新计算。
9. 离开页面前提醒未保存的修改；浏览器本地存储不保存工程数据和结果。
10. 撤销 / 重做只作用于已保存版本，版本号不倒退。
