# 前端需求

状态：2026-10-06 起前端为五区工作台（§2），本文是前端需求与验收的唯一依据；页面变化先改本文。

相关文档：[产品需求](../product/PRD.md) · [视觉素材](./VISUAL_ASSETS.md) · [系统架构](./SYSTEM_ARCHITECTURE.md) · [领域模型](./DOMAIN_MODEL.md) · [结果类型](./RESULT_TYPES.md) · [模块细则 §8 前端状态](./MODULE_DESIGN.md#8-前端状态与页面责任)

## 0. 结论

- 主要用户是**电缆厂**和**科研人员**。设计院的线路工程（里程、接地、感应电压）后置。
- 两个核心对象：
  - **型号**：一根电缆产品——结构、材料、执行标准。交付规格书；审核后发布到型号库，成为新版本。
  - **研究**：关于电缆在某种敷设和工况下的一个问题。交付计算书或数据、图表。研究里的电缆引用型号库的某个型号版本，也可以临时定义。
  - 研究归属**工程**：一个工程持有一份共用的工程模型（敷设截面、电缆、工况），可以有多项研究；在任一研究里修改模型，其他研究的结果标为待重算。
- 功能拆成**模块**（§3）。型号和研究里的模块都是可选的，由工程师决定做什么，没有固定步骤。
- “电缆方案设计与校核”指**型号工作区的业务定位**，不是新增模块。结构设计、要求与标准、标准核对、方案对比、规格书 / 校核报告各占一个模块；计算模块按需要添加。
- 计算全部来自插件；结果是不可变的运行快照，输入变化后旧结果显示为历史。
- 一套机制：**提案**。任何不是工程师直接编辑的修改（Agent、资料导入、库的新版本）都要审核后才生效；Agent 只提出提案，不能自行批准。
- 风格由一套全局规则约束（§5），所有页面只用同一组组件。

## 1. 用户与环境

| 用户 | 典型任务 | 交付 |
| --- | --- | --- |
| 电缆厂设计 / 技术人员 | 新型号开发、按客户要求定制结构、标准核对、电气参数、载流量表、短路容量；回答客户“在我们的敷设条件下能带多少电流” | 规格书、载流量表、给客户的计算书 |
| 科研人员 | 建模与仿真、参数扫描、方法对比、方法验证 | 数据、图表、计算书 |

- 长时间桌面使用，频繁精确录入带单位的数值，反复比较方案。界面首要任务是让人看清数据和它的状态（来源、是否当前、是否满足要求、验证等级），其次才是美观。不做营销式首页、大面积插画、装饰渐变；演示数据必须标注“演示”，不出现编造的“已验证”声明。
- 1920×1080 为主要目标，1366×768 必须可用；Windows 100 / 125 / 150% 缩放；离线可用（不加载远程字体、图片、脚本）；手机端暂不验收。
- 可访问性：WCAG 2.1 AA（正文对比度 ≥ 4.5:1，控件与图形 ≥ 3:1），浅色和深色都达标；键盘可完成主要流程；状态不只靠颜色。

## 2. 导航与工作区

全局侧栏：工作台 / Agent 切换 · 新建 · 工程列表 · 型号列表 · 库 · 插件 · 设置。工程、研究与型号都在同一个**工作台骨架**里打开：

```
┌ 顶栏：工程 / 研究名 · 状态（已保存 / 未保存 / 演示 / 历史） ───────────────────────────┐
├ 命令栏：模型（保存 · 撤销 · 重做） │ 计算（预检并运行） │ 交付（计算书 / 规格书）   当前状态 ┤
├ 浏览器 ───────┬ 结论栏：本次结论与关键数值 ─────────────────────┬ 属性 ────────────┤
│ 工程切换       │ 画布：敷设截面 · 电缆截面 · 温度场 · 三维（视图切换） │ 输入 │ 方法 │ Agent │
│ 模型：截面、    │ 工具浮在画布内                                   │ 选中对象的参数    │
│ 电缆、工况      ├ 数据区：结果页签（表、曲线、明细） · 运行记录 · 放大 ┤ 工况（始终可改）  │
│ 研究（任务、    │                                                 │ 本次计算的插件、  │
│ 运行状态）      │                                                 │ 运行位置与状态    │
│ 交付           │                                                 │                  │
└───────────────┴─────────────────────────────────────────────────┴──────────────────┘
```

五个区各管一件事，位置在所有页面不变：

- **命令栏 = 做什么**：保存、撤销、运行、交付；右端写当前状态（尚未运行 / 最近运行时间与结果 / 有未保存修改）。
- **浏览器 = 去哪里**：本工程真实存在的对象——模型（截面、电缆、工况）、研究（名称、任务、运行状态点）、交付；底部“新建研究”在本工程内新建，沿用工程模型。型号工作台的浏览器列出结构与型号模块。
- **画布 = 看模型和结果**：不是装饰。有温度场工件时默认显示温度场（等温线、热点、限值、探针读数）；没有时显示敷设截面并标注结果（如各电缆导体温度）；三维只用于电缆设计与有限元研究。
- **属性 = 改输入**：输入页（所选对象、工况、本次计算）、方法页（插件参数，按插件清单的分组与级别显示，高级参数折叠）、Agent 页（对话与方案，批准由人完成）。
- **数据区 = 查数字**：当前研究的结果页签；以曲线为主的研究（扫描、对比、批量）默认放大数据区。

工程首页（打开工程时）用同一骨架：画布只读显示工程模型，数据区列出本工程全部研究（任务、插件与运行位置、状态），属性栏为工程属性与 Agent。

- 每个页面、每个研究、每次运行都有可分享的 URL；浏览器后退可用。
- 型号顶栏分别显示基准版本、当前方案或新版本草稿；其含义与操作按 §3.3。研究顶栏显示所属工程。保存状态与发布状态分开，不把保存按钮写成发布。

工作台的规则：

- **壳只有一个**：顶栏、命令栏、浏览器、属性栏在一个工程、研究或型号里始终不变；切换模块或页签只替换画布、数据区和属性内容。不允许某个模块自带另一套导航或顶栏。
- **切换模块 = 一次导航**：地址为 `/<types|studies>/<id>/<模块>/<页签>`，画布视图与属性页写在查询参数里（`view`、`inspector`），每次切换写入浏览器历史。
- **未完成或未接入的模块也要有页面**：显示空状态说明原因（“未接入：没有提供该能力的插件”“尚未开发”），不能点了没反应。
- **草稿属于工程模型或型号，不属于页面**：切换模块不丢失草稿和选中对象；保存一次，保存全部。

### 2.1 按专业软件的方式工作

参照 CYMCAP、ETAP、COMSOL、Onshape 这类工程软件的通行做法：

- **固定骨架**：命令栏、浏览器、画布、数据区、属性栏的位置在所有模块里不变（§2）。属性栏输入页只显示所选对象、工况与本次计算，不退回整项研究的长表单；方法参数在方法页。批量参数放数据区表格，模块页面按 §3.1 / §3.2 的固定模板实现；数据区按页签拆分（§3.3 页签）。
- **参数在表单和表格里录入，不写在图上**：数值框带单位、精度和来源图标；回车确认，Tab 到下一项；成批的参数（分层、坐标、分段）用表格编辑，支持从 Excel 粘贴整列。
- **图上平时只画几何和必要的标识**：对象编号、相别、选中框。参数和计算结果放在属性栏与表格里；需要时用“图上显示”叠加层临时显示，默认关闭。
- **图上可以直接编辑选中对象**（参照 Onshape / SolidWorks 的驱动尺寸）：选中一个对象，图上出现它的关键尺寸（电缆的埋深与间距、回填区的宽高、结构层的厚度），双击数字即可输入新值，回车生效；拖动对象或边界时显示实时坐标并按捕捉步长取整。图上改与属性栏改是同一个值，双向同步，都进入同一份草稿和撤销记录。
- **对象的快捷操作**：选中后在对象旁出现小工具条（复制、排列成品字形 / 平行、对齐、删除）；右键菜单提供同样的操作。
- **画布操作**：缩放到对象、平移、捕捉、全图缩略窗；画布与数值表双向同步。
- **键盘**：撤销 / 重做、删除、复制、Esc 取消、Ctrl+S 保存。
- **计算记录与消息**：顶栏“运行记录”打开工作区共用抽屉，可按当前模块过滤；单次详情进入既有运行页。研究的方法间比较进入“方法对比”；型号的方案及对应运行比较进入“方案对比”。每次计算留输入快照、方法与插件版本、耗时、状态；预检问题、警告、错误进入消息面板，点击定位到对象或字段。
- **方法与交付**：方法选择放在计算模块顶部，描述与适用范围按需展开；插件专用输入放主区参数表，已有结构、敷设和工况参数只读引用并可跳回所属模块。顶栏“交付”定位到当前工作区的交付模块，不在各计算模块再建导出页面。

## 3. 功能模块

以下表格是模块页面的固定模板。每行对应一个模块；模块内部只提供该行列出的视图与表格，不另套一组“输入 / 方法 / 记录 / 导出”子页面。新增模块或改变布局前，先更新本表。

“几何画布”只画几何、选择状态和必要标识；标为“无”的模块直接以表格或报告预览为主区。场图、曲线放在明确的结果视图，数值与判定仍进入结果表及底部校核区。右栏随对象 / 行选择变化，不承载全部模块输入。表中的校核项均是目标输出，是否可判定取决于 §3.3 的要求绑定和实际插件；接入状态不表示本轮已验收。

### 3.1 型号模块

| 模块 | 几何画布画什么 | 选中对象 → 右侧属性 | 主区表格 / 结果视图 | 主操作 | 产生或展示的校核项 | 接入状态 / 依赖 |

| 结构设计（必有） | 等比例截面、层编号与尺寸；三维剥切只读 | 导体 / 某一层 → 材料引用、直接输入的尺寸、公差、来源；推导量只读 | 分层表；插件返回的外径、分层体积与单位长度用料表，标“推导” | 保存；“更新推导”为次操作 | 输入结构错误定位；工程尺寸判定展示标准核对的结果，不另算 | 领域编辑已有；通用结构 / 用料推导能力待接入，见 §8 |

| 电气参数 | 当前型号截面只读，用于选择导体 / 屏蔽等对象 | 导体 / 屏蔽或参数行 → 结果及来源；方法专用输入行 → 值、单位与依据 | 交流电阻、电感、电容、损耗结果表；实际方法专用参数表 | 计算电气参数 | 对已绑定电气要求展示插件判定；缺少判定能力时只展示数值 | 热网络已有部分属性；各参数按实际能力开放 |
| 载流量表 | 选中敷设工况的截面只读 | 某工况行 → 模板引用、温度 / 排列等该工况的参数与来源 | 工况—允许电流表；所选行的损耗、热阻及限制明细 | 计算所选工况 | 各工况下目标电流 / 温限要求的插件判定；失败或未覆盖行保留 | IEC 60287、热网络及扫描驱动；仅开放方法已声明的工况 |
| 短路容量 | 当前型号截面只读 | 导体 / 金属屏蔽 → 材料引用；试验条件行 → 持续时间、初末温度及来源；结果行 → 完整精度与证据 | 结论、导体 / 屏蔽允许短路电流表、0.1–5 s 对数时间曲线与方法输入表 | 计算短路容量 | 展示插件允许电流与范围、缺项；要求判定仅在已绑定相应能力时开放 | 型号电气插件已接入 IEC 60949 声明范围；完全相同三芯合并，用户时间点由插件计算 |
| 方案对比 | 所选方案的截面并排或叠加，仅显示几何差异 | 某方案 / 差异行 → 基准版本、修改项、来源、结果时效、待复核事项 | 参数差异表；全部适用要求 × 各方案的结果矩阵；外径、用料及性能比较表 | 采纳为新版本草稿；“记录偏离”为次操作 | 逐方案汇总各插件重查的结果与覆盖状态，不在本模块另写判定公式 | 多方案持久化及要求 / 运行关联待接入；表中只能展示真实结果 |
| 规格书 / 校核报告 | 无；使用报告预览 | 某章节 / 交付类型 → 模板、引用方案或版本、纳入的运行与要求集 | 章节选择表；结果时效 / 覆盖清单；偏离表；报告预览 | 生成所选交付 | 引用一致性与缺项提示；原校核结果及人工确认记录随报告交付，不重新判定 | 复用交付机制；型号模板与要求、方案引用待接入 |

型号的版本、方案及采纳 / 发布流程统一见 §3.3，不在各模块另起一套保存或版本规则。

### 3.2 研究模块

### 3.3 模块规则

- 除必有模块外，模块可以随时添加、移除，没有先后顺序；模块之间共享对象，每个参数只在一处编辑。
- “添加模块”按工作区类型列出 §3.1 / §3.2 的模块。计算模块的方法选择依据宿主发现的能力（`/api/methods`）；没有插件或参数未声明的能力显示“未接入”，不给猜测的表单。结构、要求、工况、对比和交付等业务视图不以出现在方法清单中为前提。
- 模块是工作区中的业务视图，插件是能力的提供者；一项业务可选择不同插件的方法，一个插件可提供多项能力。插件不自行发明页面骨架。方法、运行记录与交付入口统一按 §2.1 放置。

#### 页签

#### 版本与方案

- **版本**是型号审核发布后的固定状态，不可修改。**方案**是基于一个明确版本的候选改法，可同时存在多个；各自保存修改项、来源、已保存修订和对应运行。界面只用“版本”“方案”“新版本草稿”等明确状态，不另设“工作副本”称呼。
- 采纳方案，生成**新版本草稿**；审核后发布为新的固定版本。保存只保存当前编辑，不发布版本。新建型号先编辑首版草稿。
- 未保存的编辑不能用于运行；已保存的方案或新版本草稿可以预检、运行和比较，结果绑定其确定修订。底层修订号用于并发控制与追溯，不作为第三种方案对象展示。
- 方案对比统一在“方案对比”模块完成。每个方案都对全部适用要求重新检查；未接入、人工确认待完成、未运行、失败或历史结果的行保留，不能靠少查几项获得“全部满足”。采纳后的新版本草稿需确认结果引用仍对应相同输入与要求集。

#### 要求与校核项

- **要求是独立对象**：保存稳定标识、内容、适用对象 / 条件、单位与目标（适用时）、来源和版本、批准状态、判定方式及其绑定。要求定义与一次运行产生的校核结果分别保存。
- 标准要求由所选标准插件提供，注明标准版本、修订 / 勘误及条款 / 表格号；客户要求由技术规范书导入，保留原件版本、页码和原文位置，人工批准后生效。研究设定的准则保留录入者与适用工况。冲突要求并列展示并记录采用依据，不静默覆盖。
- 每条自动校核要求绑定一个确定的插件能力及规则版本，注明输入来自哪个方案 / 工况。没有匹配能力时显示“未接入”；明确采用人工判定时显示“人工确认”，记录确认人、依据和结论。二者都不能由宿主临时补写阈值或判定公式。
- **校核项**汇总到工作区底部，展示要求、关联对象、实际值、余量、判定、来源和所用运行；数值、余量与工程判定来自能力结果。来源 / 接入 / 执行状态与“满足 / 不满足 / 无法判断”的判据状态分开显示。
- §6.1 的负荷、导体温限与目标电流作为研究目标随领域输入及研究保存，由所选计算插件返回带稳定目标标识、规则版本、来源、实际值、余量和判定的运行工件。界面和报告仅展示工件，不另写阈值判定；这些研究目标不替代产品标准要求或签审结论。
- 不满足项可定位到对象与字段。组成解释、反算和方案建议需要对应能力或真实结果支持；修改以提案或工程师编辑保存，重查后进入方案对比。记录偏离时保留原要求、理由及批准证据，不能把原来的不满足结果改成满足；客户要求的偏离须有客户确认。

#### 外径与用料推导

- 外径、分层体积和单位长度用料由声明支持范围的结构 / 几何插件推导；标准限值及判定由标准插件提供。简单同心结构可按径向层厚推导，三芯、异形、绕包等结构按插件声明的几何规则处理，不将单芯层厚累加通用于所有结构。
- 用料推导还需材料密度及适用的绞合 / 绕包等参数；结果写明是理论单位长度用料及采用的假设。缺少必需参数或结构不支持时返回不可用及原因，不由宿主补默认值。
- 推导结果标“推导”，关联输入结构 / 方案修订、材料库版本、方法 / 插件版本和运行。输入或材料引用变化后显示历史，待重新推导；用户录入的厂家外径与插件推导值分别保留来源，不互相冒充。

### 3.4 结合真实情况

- 界面上的每个数值都来自真实来源：领域文档、库、插件运行结果、资料导入（带页码）。原型可以用演示数据，但必须标“演示”，字段、单位、状态与真实接口一致。
- 模块内的计算操作是否可用按 `/api/methods` 实际返回及所需接口决定；未接入的能力明确标注，不画假结果，不放示意曲线。模块中已接入的编辑、来源查看等操作仍可使用。
- 标准要求与判定依 §3.3 由标准插件提供；系统库保存原文与来源引用，界面不写死限值或计算公式。
- `design/reference/` 里样张的数值都是演示，不能当参考值使用。

### 3.5 建模编辑器（高精度）

模型对象需要 CAD 式的精确编辑，而不是“表单旁配示意图”：

- **电缆结构编辑器**：层堆叠表（材料来自库、名义厚度与公差），旁边按真实比例绘制截面；编号气泡标注各层；三维剥切只读。外径与用料读取 §3.3 的插件推导结果；结构编辑、显示与可推导范围分别说明。
- **CAD 查看与导出**：左键绕电缆轴线转台旋转，竖直方向锁定；中键 / 右键平移、鼠标中心缩放，平移与缩放限制在模型可见范围。双击空白或 F 适应窗口；视图立方体切换端面 / 侧视 / 等轴，300 ms 过渡可被拖动打断，减少动态设置下立即切换。视口保留立方体、剥切 / 剖面 / 透明切换和测量提示；标题、选择模式、导出、尺寸与用料放在页签栏、属性栏、状态栏。剥切只改变各层可见长度；轴向剖面可拖动，封口用材料色；选中层实色、其余淡化。端面标注本层内径 / 外径 / 厚度，成品外径单独显示，尺寸统一到 0.1 mm。
- **几何与用料范围**：`cablesim.cable-geometry` 0.3 的单芯同心结构用同源 B-Rep 显示与 STEP 导出。完整圆绞层按 1+6+12…单丝螺旋生成，屏蔽与铠装按根数 / 丝径 / 节距 / 绞向生成，扎带可反向绕包；不支持重叠带。紧压采用截面面积等效圆实体，标“紧压近似”；不模拟接触形变、制造公差。OCCT 显示复用单丝母体细分，绝对弦差 0.08 mm、角度 0.35 rad，STEP 保留原始理想实体。体积按原始实体积分；已提供密度时才换算质量。未知构造仅作包络，体积用料与质量保持缺项。显示预览由参数修改自动更新，不创建工程运行或审批；历史计算仍保持原始快照。合成 CAD 示例中的密度与制造参数明确标演示来源。
- **截面编辑器**：画布上放置、移动、对齐电缆与排管、回填区；坐标、尺寸标注、捕捉；默认缩放到对象，附全图缩略窗；画布与精确数值表双向同步。
- 编辑的是领域文档 `cablesim.domain/1`（SI、Z 向上），不是 v0 单回路 `Scenario`。

### 3.6 几何维度

工程师录入参数，不录入几何；各维度由同一份参数派生，插件声明所需维度：

| 维度 | 来源 | 典型用途 |
| --- | --- | --- |
| 径向一维 | 电缆结构 | 热阻、交流电阻、电气参数 |
| 截面二维 `(x, z)` | 敷设截面 + 电缆位置 | IEC 60287 互热、二维有限元、电磁场 |
| 三维 | 截面沿长度拉伸 + 局部对象 | 交叉、接头、外部热源；只读查看与校核 |
| 线路一维（里程 `y`，后置） | 线路分段 + 接地 + 各段截面 | 感应电压、最不利段 |

真正的三维情况（交叉、接头、外部热源）以局部对象表达，不开放自由三维建模；三维视图只用于查看，修改回到参数。

### 3.7 计算

- 一项计算保存：方法（插件、能力、版本、发布摘要）、输入来源、参数、驱动（单次 / 参数扫描 / 选型 / 交叉校核）。专用输入（如 IEC 60287 单芯）独立录入 SI 值，不从几何推断。
- 运行前预检并由工程师确认适用范围；缺少必需输入（如导体 R₂₀）时不能运行并说明原因。结果为不可变快照；输入变化后标为历史，不自动重算。
- 结果按结果类型渲染：数值表通用；已知工件（载流量评级、温度场、曲线、径向分布）有专用图。宿主不为某种计算写死页面。
- 同一物理量的不同方法互为交叉校核；仿真（有限元等）是可选方法，不是载流量的固定步骤。

载流量模块的目标是：**引用电缆结构、敷设和工况，计算允许电流与运行温度，并展示有依据的限制原因。** 输入编辑、运行历史和交付分别遵循 §3.2 对应模块及 §2.1 的公共入口；计算书由交付模块生成。任务入口分为温限求允许电流、给定电流求温度、目标电流校核；按所选方法实际能力开放。额定工况与运行工况的温度、损耗、热阻及诊断分别展示，运行点不可用时保留独立有效的额定结果，不能拿额定值补空。限制判断先指出对象、准则及裕量；因果解释引用真实分项或同基准对照，不由界面推测。

首期原型沿用本节边界，新建研究先选计算任务，再引用系统演示型号的明确版本；引用内容锁定，敷设和工况仍可编辑。表单契约来自已安装插件的实际输入模型并绑定发行摘要，方法专用参数和共享对象分开录入；缺项及范围错误在运行入口说明并定位所属模块。直埋单回、双回、排管、隧道与桥架模板保存真实领域对象；回填与土壤分层可以保存和绘制，但当前稳态适配器不支持分区计算，会明确拒算。扫描逐点保存状态、单位、来源和插件判定，临界值仅定位在已计算的采样区间；同输入方法对比同时执行 IEC 与热网络并保存各自假设。计算书只纳入一个选中的当前有效运行，历史结果不能混入。系统演示库不等于厂家认证或正式发布的型号库；复杂环境计算、三芯铠装、暂态、接头与 J 型管仍需各自的方法契约与验证证据。

同输入方法对比默认展示允许电流工况下的交流电阻、λ₁/λ₂、T₁–T₄、金属层热阻及介质损耗温升。中间量与分项贡献由插件保存，宿主只传递固定基准工件及其来源摘要、展示数值；当前贡献采用最终系数固定的 Shapley 分解，平均各分项替换顺序并检查总差值闭合，不能解释成重新迭代的混合方法或唯一物理因果。差异贡献按绝对值由大到小显示，历史运行缺少分项证据时提示明确换版重算，不补写旧结果。

### 3.8 给实现 Agent 的对齐说明

> 实现对象是型号或研究工作区中的指定模块，页面按 §3.1 / §3.2 对应行搭建；“电缆方案设计与校核”不另建成模块。先核对 §8 的真实插件、契约与负责人，再接入数据；未具备能力时实现真实的未接入 / 人工确认状态。版本、方案、要求和推导统一按 §3.3，输入归属、方法、记录与交付按 §2.1。右栏只跟随选中对象，工程算法与判定交给插件；不复制样张的演示结果。完成后按 §6 核对所实现模块的页面边界和状态，再扩展其他模块。

## 4. 库与建模起点

### 4.1 层次

| 层 | 内容 | 写入 |
| --- | --- | --- |
| 系统库 | 标准材料常数、典型结构、标准题录 | 随产品发布，只读 |
| 组织库 | 型号库、材料、截面模板、工况模板、计算方案、交付模板 | 草稿 → 审核 → 发布；已发布版本不可改 |
| 研究本地 | 只属于当前研究的对象（如临时定义的电缆、截面） | 直接编辑，形成修订 |

### 4.2 新建型号或电缆的四个起点

1. **从型号库复制**：基于明确的已发布版本建立新型号草稿；修改同一型号时按 §3.3 创建候选方案。
2. **按标准生成**：由已接入的标准 / 结构插件根据电压等级、导体与截面提出结构；保留标准版本与条款，人工批准后采用。只有直接来自标准的参数标“标准值”，计算得到的量标“推导”；插件未接入时该入口不可执行。
3. **从资料导入**：Agent / OCR 从厂家资料或客户技术规范书抽取为提案，人工批准；参数来源标为资料页码。
4. **空白**。

研究里的电缆另有一种：**引用型号**——引用型号库某一版本并锁定，不复制。

### 4.3 引用与来源

- 引用记录 `资源 id + 版本 + 摘要`；库出新版本只提示，替换需确认，替换后既有运行变为历史。
- 脱离：复制为研究本地对象并记录“派生自 资源@版本”；发布：本地对象经审核发布为组织库新版本。
- 每个参数保留来源标记：库、标准、资料、用户、推导、锁定。

### 5.4 Agent 界面

- 基于 [assistant-ui](https://www.assistant-ui.com)（MIT，构建于 Radix / shadcn）改装：消息、输入框、工具调用、重试与分支；图标换成自研图标，颜色、圆角、字号全部取本节变量。
- 位置：型号、研究工作区与资源详情内的右侧抽屉（2 级层级，宽 400–480）；不做独立聊天页面。
- 消息：用户消息为填充色、16 圆角的气泡，右对齐；Agent 消息无气泡，正文 14；工具调用是一行次要文字加图标（如“已读取 敷设截面”“已运行 预检”），可展开查看输入输出。
- 生成内容只能渲染已有组件：参数表、方案对比表、提案块（通过 assistant-ui 的工具界面映射到本项目组件），Agent 不生成任意界面。
- 所有修改以提案出现（青色虚线框），经人批准；同一提案也出现在对应的模块里。不采用 CopilotKit 的直接写入应用状态——与“Agent 只提提案”冲突；如使用其 action 机制，action 只能创建提案。
- 输入框与首页搜索同为 48 高胶囊；使用云端模型需逐次同意（§6 第 9 条）。
- 动效：流式内容逐段出现，不闪烁光标；工具调用进行中用“执行中”状态点。

## 6. 行为验收清单

1. 未保存编辑与已保存修订分开；未保存编辑不能用于运行。方案及新版本草稿的保存 / 运行 / 发布语义按 §3.3；保存带基准修订，基准过期则明确失败、编辑保留、不覆盖他人修改。
2. 字段错误定位到具体字段；整体校验失败不部分保存；锁定字段不可编辑，提案也不能绕过。
3. 撤销 / 重做只作用于已保存修订，版本号不倒退；离开页面前提醒未保存修改。
4. 浏览器本地存储只保存导航与偏好，不保存型号、研究数据和结果；URL 不形成第二份状态。
5. 运行结果标明型号或研究的修订、方法与插件版本、各摘要与运行环境；输入变化后旧结果显示为历史。
6. 比较两次运行先显示输入差异，再显示结果差异（绝对差）。
7. 计算书只从指定运行生成，不重新计算。
8. 导出型号或研究只含已保存数据；导入经服务端校验后新建独立对象（≤ 120 KB），不按名称覆盖。
9. 设计依据、Agent 修改、资料导入都经提案审核；过期修订上的提案不能批准；云端请求需明确同意。
10. 逐模块核对 §3 页面模板：几何画布、选中对象属性、主区表格、主操作与校核项一致；空选择不显示全量表单，运行记录与交付使用公共入口。
11. 基于同一版本保留多个方案；采纳仅生成新版本草稿，保存不发布。各方案的全部适用要求均出现在比较矩阵中，未覆盖项、人工确认和偏离记录可见。
12. 校核结果能定位到独立要求、来源页码 / 条款和具体插件规则；缺少能力时显示 §3.3 规定状态。外径 / 用料结果可追溯至结构、相关材料版本和推导方法，输入变化后不得保持“当前”。

### 6.1 场景验收

界面以能否顺利完成下面三件真实工作来验收，而不是以页面和组件是否齐全来验收。每个场景用真实插件运行，从首页开始走到底，逐步截图。

| 场景 | 用户 | 从头到尾要做的事 | 通过标准 |
| --- | --- | --- | --- |
| 客户问询 | 电缆厂技术人员 | 新建研究 → 从型号库选一根电缆 → 用截面模板布置直埋品字形，改埋深与土壤热阻率 → 任务选“给定电流求温度”并填负荷 → 运行 → 看结论 → 生成计算书 | 3 分钟内完成；不需要说明就知道下一步；没有死路、没有灰掉却不说原因的按钮；结论第一眼回答“这个负荷行不行、最热多少度” |
| 参数敏感性 | 科研人员 | 打开上一个研究 → 参数扫描土壤热阻率 0.6–2.0 → 看曲线 → 方法对比 IEC 60287 与热网络 → 导出 CSV | 曲线、差异表都来自真实运行；能读出临界值；导出的数据带单位与来源 |
| 型号修改 | 电缆厂设计人员 | 打开型号 → 结构设计里改绝缘厚度 → 看外径与用料的变化 → 标准核对（未接入时如实显示）→ 生成规格书草稿 | 改一个数，所有受影响的结果立即标为历史并提示重算；未接入的能力不被伪装成通过 |

每一屏都按下面的清单自查：

- **3 秒测试**：不看说明，能说出这一屏是干什么的、结论是什么、下一步点哪里。
- **数值**：都有单位、合理精度和来源；界面上不出现修订号、哈希、契约名等内部标识。
- **状态**：空、加载中、出错、未接入都有设计好的样子，说明原因和下一步。
- **精致度**：按 §5 的间距、字号、圆角对齐；表格数值列右对齐且列宽贴合内容，不留大片无意义空白；1366×768 与 1920×1080、浅色与深色都检查。
- **数据像真的**：演示数据取自库中典型型号与常见敷设条件并标“演示”，名称写工程问题，不用“合成演示”“结构实体”之类的占位名。

## 7. 已否定的做法（重建时避免）

| 做法 | 问题 |
| --- | --- |
| 以载流量六 / 七步流程组织工程 | 其他计算无处可放；页面多而内容少 |
| “工程”作为一份从上往下读的长文档，所有对象和计算挤在里面 | 工程师看不出这个软件是做什么的；厂家和科研的任务被同一个骨架绑死 |
| 工程主页做成结论仪表盘 | 不像专业软件，打开后不知道从哪里动手 |
| 卡片式仪表盘、超大数字、营销留白 | 不像工程软件 |
| 求解器后处理式多窗格（结果树 + 绘图窗 + 停靠表 + 属性栏）配 11–12 px 小字 | 乱、廉价、看不出在做什么 |
| 逐页重写并各自新增样式 | 各页互相矛盾（曾实测 12 种圆角、12 种控件高、17 种按钮写法） |
| 表单旁配示意图的“建模” | 不满足高精度建模 |
| 温度场捆绑在载流量计算里 | 仿真应是可选方法 |
| 把“电缆方案设计与校核”做成大模块，再嵌套结构、要求、计算与交付子页面 | 混淆工作区与模块，绕过 §3 的逐模块模板 |
| 在每个计算模块重复输入、方法、记录、导出页面，右栏展示全部参数 | 同一数据多处编辑、职责混杂；归属按 §2.1 与 §3 |

## 10. 重建顺序

1. 规则与组件：按 §5 建立唯一的规则文件与组件集，附样式自动检查与组件陈列页；图标、品牌与动效按 [视觉素材](./VISUAL_ASSETS.md) 并行制作。
2. 导航、首页与工作区骨架（§2）；计算与交付走新内核。
3. 型号：按 §3.1 固定结构设计、要求与标准、标准核对、方案对比、规格书 / 校核报告的页面边界；真实计算和发布分别依赖 §8 的插件、要求与多方案能力，缺失时保留明确状态。
4. 研究：电缆引用、敷设截面、工况、载流量、温度场、计算书（§3.2）。
5. 库与型号发布（§4），依赖 §8 资源库与引用；随后参数扫描、方法对比、电气参数、载流量表。
6. 后置：短路容量、电场 / 磁场界面、线路与感应电压，待插件与领域模型就绪。

每一步先用截图与使用者确认方向，再铺开。
