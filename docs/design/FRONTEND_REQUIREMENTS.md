# 前端需求

状态：界面待重建。2026-10 已删除全部旧前端代码（WorkflowApp、Ant Design 版、shadcn 版），本文是重建时唯一的需求依据。宿主当前只提供 API（`/docs`）。

相关文档：[产品需求](../product/PRD.md) · [视觉素材](./VISUAL_ASSETS.md) · [系统架构](./SYSTEM_ARCHITECTURE.md) · [领域模型](./DOMAIN_MODEL.md) · [结果类型](./RESULT_TYPES.md) · [模块细则 §8 前端状态](./MODULE_DESIGN.md#8-前端状态与页面责任)

## 0. 结论

- 面向电缆行业的工程软件，不是载流量计算器。载流量只是计算的一种；短路、感应电压、电气参数、温度场、选型等同样是计算。
- 三个名词：**库**（带版本、可审核的资源）、**工程**（一份工程文档）、**计算**（某个插件能力的一次研究，结果为不可变运行）。一套机制：**提案**（任何非工程师直接编辑的修改，审核后才生效）。
- 专业优先：精确建模与直接编辑是主干；Agent 只提出变更提案，不替代工程界面，不自行批准。
- 工程是**垂向**的：一个工程从上往下读完——对象 → 计算 → 交付，而不是很多内容稀少的分步页面。
- 风格由一套全局规则约束，所有页面只用同一组组件；不按页面单独打补丁。

## 1. 用户与环境

- 主用户：电缆厂家设计 / 技术人员，设计院电缆专业工程师，仿真研究人员。长时间桌面使用，频繁精确录入带单位的数值，反复比较方案，交付计算书 / 规格书。
- 界面首要任务是让人看清数据和它的状态（来源、是否当前、是否满足准则、验证等级），其次才是美观。不做营销式首页、大面积插画、装饰渐变；演示数据必须标注“演示”，不出现编造的“已验证”声明。
- 1920×1080 为主要目标，1366×768 必须可用；Windows 100 / 125 / 150% 缩放；离线可用（不加载远程字体、图片、脚本）；手机端暂不验收。
- 可访问性：WCAG 2.1 AA（正文对比度 ≥ 4.5:1，控件与图形 ≥ 3:1），浅色和深色都达标；键盘可完成主要流程；状态不只靠颜色。

## 2. 导航

全局只有：**工程、库、插件、设置**，外加最近工程。工程内导航与全局导航分开：

```
全局侧栏                         工程内
├ 工程   列表、新建、导入          左：文档目录（对象 / 计算 / 交付，每项带状态）
├ 库     资源、版本、引用者        中：工程文档，垂直连续，目录点击即定位
├ 插件   方法插件与其计算能力      顶：工程名、修订、草稿、保存、撤销 / 重做、Agent
└ 设置
```

- 每个页面、工程内每一节、每次运行都有可分享的 URL；浏览器后退可用。
- 不设“空间”。厂家型号设计使用同一工程骨架（§3.5）。

### 2.1 页面分配

全部页面只有下表这些；新增页面先改本表。工程内只有两种模式：**文档模式**（从上往下读）和**编辑模式**（目录不动，正文换成编辑器）。表单类内容（概况、工况与判据、计算参数）在文档里原位编辑；需要画布的对象（电缆结构、敷设截面、线路）进入编辑模式。

| 页面 | 路径 | 模式 | 内容（从上往下） | 主操作 |
| --- | --- | --- | --- | --- |
| 工程列表 | `/projects` | 全局 | 搜索与筛选（全部 / 我参与的 / 型号设计）；工程表：名称与对象摘要、计算状态计数、交付状态、修订、更新时间 | 新建工程 |
| 库 | `/library` | 全局 | 层（系统库 / 组织库）与种类筛选；资源表：资源、种类、当前版本、状态、引用者；“待审核”筛选 | 新建资源 |
| 资源详情 | `/library/<kind>/<id>` | 文档 | 版本线 → 内容（按种类：型号用电缆结构只读视图，其他用参数表）→ 引用者 → 提案 | 发布新版本（审核后） |
| 插件 | `/plugins` | 全局 | 已安装插件：名称、版本、能力、验证等级；未接入的计算 | 安装插件 |
| 插件详情 | `/plugins/<id>` | 文档 | 能力与参数模式 → 所需几何维度 → 验证证据 → 发布摘要与运行环境 | — |
| 设置 | `/settings` | 全局 | 外观、数值显示、Agent、数据目录、关于与许可 | — |
| 工程文档 | `/p/<id>` | 文档 | §3.1 全部节；每节可锚点定位 `/p/<id>#<节>`；计算节只显示结论行 | 保存修订（有草稿时） |
| 电缆结构编辑 | `/p/<id>/edit/cable/<cid>` | 编辑 | 截面按真实比例绘制 + 分层表（双向同步）；三维只读 | 保存修订 |
| 敷设截面编辑 | `/p/<id>/edit/section/<sid>` | 编辑 | 画布（坐标标尺、捕捉、标注）+ 对象坐标表 + 介质分区表 | 保存修订 |
| 线路编辑 | `/p/<id>/edit/route` | 编辑 | 里程轴（K0+000）与纵断面 + 分段表 + 局部对象表 | 保存修订 |
| 计算 | `/p/<id>/study/<sid>` | 文档 | 方法 → 输入与参数 → 预检 → 结论 → 图表 → 各相 / 各点 → 依据 → 运行历史与比较 | 运行（铜色） |
| 运行 | `/p/<id>/study/<sid>/run/<rid>` | 文档 | 单次运行的完整快照，只读；与当前输入的差异 | — |
| 交付 | `/p/<id>/delivery/<did>` | 文档 | 纳入的运行（只能选当前运行）→ 模板 → 预览 | 生成 |

不是页面、以对话框或抽屉出现的：新建工程、添加对象（§4.2 四个起点）、添加计算（按物理问题分组）、预检确认、版本冲突、离开前未保存提醒、云端请求同意、导入工程、发布到库。Agent 是工程与资源详情内的右侧抽屉，只产出提案。

## 3. 工程文档

### 3.1 结构

```
工程
├ 概况         名称、说明、设计依据、方案来源（另存为 / 派生自）
├ 对象         所有计算共用，只录入一次；每个参数只在一处编辑
│ ├ 电缆       结构分层、材料、额定参数（多芯、铠装、公差）
│ ├ 敷设截面   二维布置 (x, z)、介质分区、排管、回填
│ ├ 线路       里程分段、接地方式、局部对象（交叉、接头、外部热源）
│ └ 工况与判据 负荷曲线、短路、环境条件、温度与电压限值
├ 计算         每项 = 一个研究；按需添加，可多项
│ └ <计算名>   方法 → 输入与参数 → 预检 → 结论 → 图表 → 各相 / 各点结果 → 依据
└ 交付         计算书 / 规格书：勾选纳入的运行，生成并导出
```

每节标题行写明对象来源（§4.3）；每节内部同样从上往下读，不设侧边属性栏、不堆零散小字。

### 3.2 建模编辑器（高精度）

工程对象需要 CAD 式的精确编辑，而不是“表单旁配示意图”：

- **截面编辑器**：画布上放置、移动、对齐电缆与排管、回填区；坐标、尺寸标注、捕捉；画布与精确数值表双向同步。
- **电缆结构编辑器**：任意层堆叠表（材料来自库、名义厚度与公差、外径自动累加），旁边按真实比例绘制截面；三维只读查看、剖切。
- **线路编辑器**：里程表（分段、长度、敷设方式、所用截面、局部对象）配平面 / 纵断面示意。
- 编辑的是领域文档 `cablesim.domain/1`（SI、Z 向上），不是 v0 单回路 `Scenario`。

### 3.3 几何维度

工程师录入参数，不录入几何；各维度由同一份参数派生，插件声明所需维度：

| 维度 | 来源 | 典型用途 |
| --- | --- | --- |
| 径向一维 | 电缆类型 | 热阻、交流电阻、电气参数 |
| 截面二维 `(x, z)` | 敷设截面 + 电缆实例位置 | IEC 60287 互热、二维 FEM、电磁场 |
| 线路一维（里程 `y`） | 线路分段 + 接地 + 各段截面 | 感应电压、电压降、最不利段 |
| 三维 | 截面沿里程扫掠 + 局部对象 | 交叉、接头井、隧道、CAD 导出 |

真正的三维情况（交叉、接头、外部热源、截面变化点）以挂在里程上的局部对象表达，不开放自由三维建模；三维视图只用于查看与校核，修改回到参数。

### 3.4 计算

- “添加计算”列出宿主发现的全部方法能力（`/api/methods`），按物理问题分组。没有插件或参数未声明的能力显示“未接入”，不给猜测的表单。
- 一项计算保存：方法（插件、能力、版本、发布摘要）、输入来源、参数、驱动（单次 / 参数扫描 / 选型 / 交叉校核）。专用输入（如 IEC 60287 单芯）独立录入 SI 值，不从工程几何推断。
- 运行前预检并由工程师确认适用范围；缺少必需输入（如导体 R₂₀）时不能运行并说明原因。结果为不可变快照；修订变化后标为历史，不自动重算。
- 结果按结果类型渲染：数值表通用；已知工件（载流量评级、温度场、曲线、径向分布）有专用图。宿主不为某种计算写死页面。
- 同一物理量的不同方法互为交叉校核；仿真（有限元等）是可选方法，不是载流量的固定步骤。

### 3.5 型号设计

同一骨架：对象为电缆型号（结构、材料、执行标准），计算为电气参数、载流量表（多工况扫描）、短路容量，交付为规格书；审核后发布到库成为新版本。

## 4. 库与建模起点

### 4.1 层次

| 层 | 内容 | 写入 |
| --- | --- | --- |
| 系统库 | 标准材料常数、典型结构、标准题录 | 随产品发布，只读 |
| 组织库 | 公司型号、截面模板、工况模板、计算方案、交付模板 | 草稿 → 审核 → 发布；已发布版本不可改 |
| 工程本地 | 只属于当前工程的对象 | 直接编辑，形成修订 |

资源种类：材料、电缆型号、截面模板、线路模板、工况与判据、计算方案、交付模板。

### 4.2 统一的“添加对象”入口

工程内每一处新建都打开同一个选择器，四个起点：

1. **从库选用**：引用某一版本并锁定。
2. **按标准生成**：给电压等级、导体与截面，按典型结构生成；参数来源标为“标准值”。
3. **从资料导入**：Agent / OCR 抽取为提案，人工批准；参数来源标为资料页码。
4. **空白或复制**：从空白，或从另一工程的某一修订复制。

### 4.3 引用与来源

- 引用记录 `资源 id + 版本 + 摘要`；库出新版本只提示，替换需确认，替换后既有运行变为历史。
- 脱离：复制为工程本地对象并记录“派生自 资源@版本”；发布：本地对象经审核发布为组织库新版本。
- 每个参数保留来源标记：库、标准、资料、用户、推导、锁定。

## 5. 视觉规则

基调：**白纸、灰阶、柔和圆角；数字精确，颜色只表达含义。** 界面本身几乎无色：灰色底色上放一整块白色工作面板，面板内用细线分隔；颜色只在含义需要时出现；电缆特有的表达只出现在电缆内容里（§5.3）。

规则只定义一次，全部页面遵守，并由自动化测试在渲染结果上检查（超出即失败）：

| 项 | 规则 |
| --- | --- |
| 字号 | 13 说明 · 14 正文 · 16 小节标题 · 20 节标题 · 28 关键数值与首页标题；正文不小于 13 |
| 字重 | 400 / 600 |
| 控件高度 | 32 紧凑（工具栏、列表、表格内）· 36 标准（表单、主要操作）· 48 首页搜索（只此一处） |
| 圆角 | 8 输入框与表格内控件 · 10 导航项与菜单项 · 12 卡片、浮层、画布框 · 16 工作面板与对话框 · 全圆 按钮、搜索框、分段选择、状态点 |
| 间距 | 4 的倍数：4 8 12 16 24 32 48 |
| 布局 | 导航直接放在底色上，无边框；工作区是一整块 16 圆角的白色面板，四周留 8；面板内只用 1 px 细线，不再层层套卡片 |
| 层级 | 平面不用阴影；浮层 1 级（菜单、下拉、提示、通知、首页搜索）；对话框与抽屉 2 级，背后 40 % 遮罩 |
| 颜色 | 零色偏灰阶构成界面；含义色：铜 = 运行与当前结论数值，青 = Agent 与提案，绿 / 琥珀 / 红 = 满足 / 需注意 / 错误；不用蓝、紫作通用强调色 |
| 按钮 | 全圆胶囊：线框（普通）· 实心文字色（主要，每屏最多一个）· 实心铜（运行计算）· 青色线框（Agent）· 文字按钮（取消、撤销） |
| 交互状态 | 悬停 = 悬停灰底；当前位置（导航、目录）= 当前位置灰底；选中对象（表格行、画布对象）= 1 px 文字色墨线框；焦点 = 2 px 文字色外框；不可用 = 45 % 透明度；每种只有一种表现 |
| 输入 | 草稿 = 需注意色虚线边框 + 浅底；错误 = 错误色边框 + 下方一行原因；推导 / 锁定 = 填充底、无边框、不可编辑 |
| 表格 | 只有行间细线，无竖线、无斑马纹；数值列右对齐、等宽；来源单独一列 |
| 状态表达 | 同心点 + 文字：实心带环 = 当前 / 已保存，空心 = 历史，虚线 = 草稿，斜线 = 失败，转动虚线 = 执行中，青色虚线 = 提案待审核；判据用小方块（满足 / 不满足 / 无法判断）；不用胶囊、徽章、带底色结论框堆叠 |
| 数值 | 等宽数字；五位及以上用空格分组；单位紧随数值且较小；按物理量规则显示精度，不显示虚假精度；温度显示 °C，存储 SI |
| 数据可视化 | 三相固定分类色并同时标相别文字；温度场用感知均匀顺序色图，差值用发散色图；材料识别色只用于辨认 |

浅色为主，深色同等完成。组件用 shadcn/ui 改装，Agent 界面用 assistant-ui 改装（§5.4），动效用 Motion 与 CSS 实现；页面不手写控件样式。图标、品牌标记与动效设计自研，要求见 [视觉素材](./VISUAL_ASSETS.md)。

常规界面朴素：列表、设置、表单、对话框、目录只用标题、细线和上表规则，不加标尺、印字标签或材料色等主题装饰。验证等级用 1–5 层同心环表达，配等级文字。

### 5.1 必须区分的状态

| 类别 | 状态 |
| --- | --- |
| 编辑 | 已保存、草稿、校验错误、版本冲突、已锁定 |
| 来源 | 演示、用户录入、厂家资料、标准值、推导值、库引用 |
| 运行 | 排队、执行中、成功、部分成功、失败、中断 |
| 结果时效 | 当前、历史（输入已变化）、完整性校验失败 |
| 判据 | 满足、不满足、无法判断 |
| 验证等级 | 未验证、接口测试、解析基准、参考基准、交叉验证 |

### 5.3 图纸风格（电缆内容）

电缆线路设计历来用图纸表达：路径平面图、纵断面图（平纵断面以里程桩号 K0+000 标注）、敷设断面（排列）图、接头与工井布置图、接地（交叉互联）系统图。界面中的电缆内容沿用这些图纸习惯，让工程师按熟悉的方式读图；但只出现在图框内，图框外仍是常规界面。

| 项 | 规则 |
| --- | --- |
| 图框 | 12 圆角画布框，工作面板色底；图内可有网格、坐标标尺、比例；图框外不出现标尺与网格 |
| 线型 | 轮廓与地表线 1.5；尺寸线、引线 0.75；网格 0.5（细线色）；规划 / 待定对象虚线；地表线上方加 45° 短斜线 |
| 尺寸标注 | 尺寸界线 + 尺寸线 + 等宽数字；单位在图名中统一给出（m 或 mm），不在每个数字后重复 |
| 敷设截面 | 电缆按真实比例与材料色绘制；三相用黄 / 绿 / 红并写相别；介质分区用浅灰层次与虚线边界 |
| 详图 | 按真实比例看不清的部分（如埋深 1 m 处的品字形电缆）用局部放大详图：主图上虚线圈出，引线连到图内的放大框，框内写“详图 A · 放大 n 倍” |
| 线路 | 自上而下：里程轴（每 50 m 小刻度，每 500 m 标注 K 桩号）→ 分段带（按敷设方式用灰阶层次区分）→ 接地小段 → 纵断面（埋深折线用文字色）；局部对象（接头井、交叉、外部热源）为竖向引线 + 圆点 + 标签 |
| 图内文字 | 12–13，数字等宽，中文用界面字体；标签避让，不与线条重叠 |
| 颜色 | 图内同样不用铜色装饰；Agent 提出的对象用青色虚线；温度只用温度色图 |
| 交互 | 图中选中与表格选中同步，表现相同（墨线框）；捕捉参考线即时出现 |
| 计算书 | 纸面固定浅色，版式含图纸式标题栏（工程、图号、修订、设计 / 校核 / 审核、运行与摘要、日期） |

### 5.4 Agent 界面

- 基于 [assistant-ui](https://www.assistant-ui.com)（MIT，构建于 Radix / shadcn）改装：消息、输入框、工具调用、重试与分支；图标换成自研图标，颜色、圆角、字号全部取本节变量。
- 位置：工程与资源详情内的右侧抽屉（2 级层级，宽 400–480）；不做独立聊天页面。
- 消息：用户消息为填充色、16 圆角的气泡，右对齐；Agent 消息无气泡，正文 14；工具调用是一行次要文字加图标（如“已读取 敷设截面”“已运行 预检”），可展开查看输入输出。
- 生成内容只能渲染已有组件：参数表、方案对比表、提案块（通过 assistant-ui 的工具界面映射到本项目组件），Agent 不生成任意界面。
- 所有修改以提案出现（青色虚线框），经人批准；同一提案也出现在对应的工程节里。不采用 CopilotKit 的直接写入应用状态——与“Agent 只提提案”冲突；如使用其 action 机制，action 只能创建提案。
- 输入框与首页搜索同为 48 高胶囊；使用云端模型需逐次同意（§6 第 9 条）。
- 动效：流式内容逐段出现，不闪烁光标；工具调用进行中用“执行中”状态点。

## 6. 行为验收清单

1. 草稿与已保存修订分开；草稿不能用于运行；保存带基准修订，基准过期则明确失败、草稿保留、不覆盖他人修改。
2. 字段错误定位到具体字段；整体校验失败不部分保存；锁定字段不可编辑，提案也不能绕过。
3. 撤销 / 重做只作用于已保存修订，版本号不倒退；离开页面前提醒未保存修改。
4. 浏览器本地存储只保存导航与偏好，不保存工程数据和结果；URL 不形成第二份状态。
5. 运行结果标明工程修订、研究修订、方法与插件版本、各摘要与运行环境；输入变化后旧结果显示为历史。
6. 比较两次运行先显示输入差异，再显示结果差异（绝对差）。
7. 计算书只从指定运行生成，不重新计算。
8. 导出工程只含已保存数据；导入经服务端校验后新建独立工程（≤ 120 KB），不按名称覆盖。
9. 设计依据、Agent 修改、资料导入都经提案审核；过期修订上的提案不能批准；云端请求需明确同意。

## 7. 已否定的做法（重建时避免）

| 做法 | 问题 |
| --- | --- |
| 以载流量六 / 七步流程组织工程 | 其他计算无处可放；页面多而内容少 |
| 卡片式仪表盘、超大数字、营销留白 | 不像工程软件 |
| 求解器后处理式多窗格（结果树 + 绘图窗 + 停靠表 + 属性栏）配 11–12 px 小字 | 乱、廉价、看不出在做什么 |
| 逐页重写并各自新增样式 | 各页互相矛盾（曾实测 12 种圆角、12 种控件高、17 种按钮写法） |
| 表单旁配示意图的“建模” | 不满足高精度建模 |
| 温度场捆绑在载流量计算里 | 仿真应是可选方法 |

## 10. 重建顺序

1. 规则与组件：按 §5 建立唯一的规则文件与组件集，附样式自动检查与组件陈列页；图标、品牌与动效按 [视觉素材](./VISUAL_ASSETS.md) 并行制作。
