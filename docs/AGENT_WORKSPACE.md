# CableSimPro 0.2 — Agent-first 工程工作空间

## 产品原则

不是“在计算器旁边加一个聊天框”。入口是工程任务，持久对象是工程模型，交付物是可复核的计算研究。

- OpenAI 风格参考：克制的排版、留白、对话主入口；不使用其标志、专有字体或暗示合作。
- COMSOL 工作流参考：模型树、节点属性、图形视图、研究与结果分离；不复制其商标或宣称求解能力等价。
- 不用 KPI 卡片、渐变、发光、装饰性英文标签制造专业感。颜色主要表达材料、选择状态与场值。
- GUI 与 Agent 共享 `Scenario` 和确定性内核。无 FEM 网格的版本不展示伪造的网格、收敛曲线或求解进度。

## 任务工作流

用户任务 → 操作方案 → 参数差异与假设 → 用户确认 → 校验 → 确定性工具执行 → 结果与操作记录。

允许的工具动作仅三项：当前模型求解、四类敷设参数扫描、检查模型假设。模型参数只能通过白名单路径更改；不能写文件、运行 shell、读取密钥或自动保存工程。

每个方案包含当前输入指纹、服务端签名与十分钟有效期。工程变更、过期或签名篡改会阻止执行。客户端还使旧方案按钮失效。撤销恢复上一次 Agent 操作前的参数和结果；之后发生手动编辑时，不能借撤销覆盖新修改。

方案不执行求解，不保存到 SQLite。只有点击确认才运行计算。输出中的数值总结由后端根据实际求解结果生成，不让 LLM 编造数值。

## 两种模式，明确区分

### 本地命令

默认运行，无密钥、无云端费用。**有限语法解析器，不是大模型 Agent，也不支持任意自然语言。** 未识别的剩余文本会导致拒绝整条命令，不会只执行识别成功的半句话。

可用示例：

```text
运行电流设为 350 A，计算载流量
截面积改为 400 mm²，重新计算
埋深设为 1.2 m，计算
改为三角排列，计算
比较土壤热阻率 0.8、1.2、1.6、2.0 下的载流量
解释当前模型的假设
```

完整单位与所有保留参数可在方案中展开检查；预设不是厂家数据。

### OpenAI 规划器

使用 Responses API 的严格函数调用 `propose_study`。模型只负责规划，应用验证其参数并产生有签名的待执行方案；这不是任意代码执行或无限循环自主 Agent。

在启动服务器的终端设置：

```bash
export OPENAI_API_KEY='your-key'
export CABLESIM_AGENT_MODEL='a-model-in-your-account-that-supports-responses-function-calling'
python scripts/run_demo.py
```

PowerShell 用 `$env:OPENAI_API_KEY` 和 `$env:CABLESIM_AGENT_MODEL`。不要将真实密钥提交进 Git、粘贴到聊天、写入工程 JSON 或前端构建变量。

在界面选择 OpenAI 并同意发送工程参数后，任务、当前工程名称/说明和全部参数发往 `https://api.openai.com/v1/responses`。请求设置 `store:false`；这不表示服务商绝无保留或适用于全部账户的数据保留政策。自行确认账户策略与数据权限。每次提交都会产生可能计费的 API 请求。配置状态不代表已验证服务连接。

**当前测试仅覆盖模拟提供商的接口契约，未使用真实 API 密钥做端到端大模型验收。** 无密钥时不会伪称已经连上 OpenAI。

## 工程对象与会话状态

工程参数可保存、导入导出；原有计算书、CSV、参数扫描仍保留。对话、操作日志和对比快照只保留当前页面会话，不属于持久化工程模型。没有全套版本管理、多人协作或身份隔离。

底部结果区域只显示与当前输入一致的解。三维图是参数化展示；土壤场是解析叠加。计算内核未升级为完整 IEC 60287、FEM 或 COMSOL 等价求解器。详见 METHOD.md。

## 后续竞争路线

先把电缆垂直场景做深：正式算例基准库、厂家材料溯源、单位系统、操作历史持久化、可中断的求解任务。再把二维场求解做成独立 Solver Adapter，并加入网格收敛和误差评估。不要让 Agent 承担物理数值求解的可信性。

## 安全和验收

本地单用户服务，不直接暴露公网。上线前需要认证、授权、CSRF/请求来源防护、速率与费用限制、云端请求审计、密钥管理及多进程票据存储。

本轮测试覆盖：签名/过期/陈旧方案、确认前无副作用、白名单与几何检查、未知命令拒绝、模拟工具调用、GUI/Agent 参数一致、撤销、旧结果失效、文件导出与项目持久化。模拟提供商测试不是实际大模型成功率基准。
