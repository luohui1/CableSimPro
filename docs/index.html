文档总览与体系树

按「入门部署 → 业务指南 → 算法依据 → 插件扩展 → 工程边界」四层树状结构组织的完整文档地图。

CableSimPro 采用宿主底座与封签插件完全解耦的架构：宿主只管理工程版本、运行前预检、不可变快照、来源追溯与签审交付，全部电热计算与标准核对均由独立封签插件执行；缺数据明确终止，AI 提案须经工程师单步确认。

一、平台四层工程架构

cablesimpro — system-architecture (四层解耦与可追溯架构)

L1 · 交付与签审层

人工复核签发（不重新计算）

研究计算书（PDF / HTML）
产品规格书（客户版 / 内部版）
多工况载流量表（PDF / CSV / Excel）
四级签栏 + 独立逐值追溯页

L2 · 四大业务工作流

工作台可视化交互 + Agent 受控提案协同

型号库与结构表导入（五步向导）
型号设计（结构 / 电气 / 短路 / 核对）
载流量研究（稳态 / 扫描 / 选型 / 对比）
Agent 边车（只读查询 · 待审提案卡）

L3 · 封签计算插件层

12 个独立子进程插件（cablesim.plugin/2 · SHA-256 逐文件封签）

IEC 60287 / GB 50217 / 热网络（本机代数）
GB/T 12706 & 3956 标准核对 + 依据库
OCCT 实体几何建模 + 电气/短路计算
Slurm 超算有限元热场 / 电热耦合 / 混合模型

L4 · 宿主工程底座

FastAPI Kernel + SQLite 工程库（宿主不内置任何计算公式）

SI 国际单位制领域事实与引用校验
运行前预检（缺项与超范围明确拒算）
不可变运行快照（冻结输入、方法与封签）
在线快照备份与独占校验恢复
