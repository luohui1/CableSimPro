型号库与结构表导入

分步说明型号库：浏览电缆型号版本，导入厂家结构表（XLS / XLSX / CSV 五步向导），提取厂家 PDF 并逐项核对，管理系列与规格，复用部件与研究模板，以及各状态与报错的处理。

型号库保存电缆型号的固定版本，研究按版本引用它们。数据可以来自厂家结构表、厂家资料（PDF 原件）、工程师给定或型号设计。每个数值都保留来源和可信分档：原表实测、标准限值和工程补充互相区分，不会混在一起。

电缆型号版本

打开哪里：侧栏 资源 → 电缆型号版本。页头显示“N 项 · 研究按版本引用”，右侧有 提取厂家 PDF 和 导入厂家结构表 两个入口。

怎么查：“检索型号版本”按型号、厂家或规格查找；“来源”按厂家资料、标准、推导、工程师给定、资源库或演示筛选。表格按型号系列分组，列出型号、规格、内容、主要来源、版本和状态。

看到什么：点一行，右侧显示版本、状态、内容、规格和制造商，以及按类别统计的来源（“N 项 · 已核对 M”）。

  • 用于载流量研究：以这个固定版本新建工程和研究。版本缺少研究所需的完整结构时不可用，提示“此版本尚未提供研究所需的完整结构；请先在型号设计中补齐结构与工程参数。”
  • 建立型号草稿：以这个版本建立独立的型号设计草稿。版本不在可复制清单中时不可用。

“系统教学示例”区的型号用于演示结构与规格书，不是厂家实测，不能作为工程型号引用。

导入厂家结构表

结构表是厂家目录里“每行一个规格”的表格，例如 YJV22-8.7/15 kV 各截面的导体外径、绝缘厚度、内衬、钢带、护套厚度、外径和重量。

打开哪里：“电缆型号版本”页的 导入厂家结构表，进入“结构表导入与系列”页的“导入结构表”页签。进度条分五步，随时可以 重新开始。完整演示见快速上手：电缆厂。

第 1 步：选择文件

点 选择结构表文件，或把文件拖入页面。支持 .xlsx、.xls、.csv，不超过 10 MiB，每行一个规格。页面提供人民电缆和 Bahra 的公开示例结构表下载。

上传后自动选择带表格标记的工作表（否则取第一张）和数据起始行；系列名称默认取文件名。

第 2 步：选择工作表

在“工作表”中选择（显示为“工作表名 · 行数”）。“工作表原始列”表列出原表列、列名和示例值（原表单位），用来确认选对了表。没有识别到表头时，检查原文件是否以列名和数值行组织。点 确认工作表，设置列映射。

点 逐行校验并预览。

第 5 步：核对入库预览

看到什么：摘要“系列名 · 可入库 N 行 · 其中缺项 N 行 · 错误 N 行”，以及“逐行入库预览”表，每行有原表行号、规格与数值、状态（可入库、资料缺项、不可入库）、问题列与原因。点数值可以查看换算和来源。

怎么判读：

  • 资料缺项的规格可以保存为草稿，但缺少必需数据的规格不能计算。
  • 不可入库的错误行须回原表更正，或勾选“明确跳过 N 个错误行，仅保存其余 N 个规格”。
  • 选择采用 GB/T 3956 标准上限时，页面注明“不是厂家实测值”，每个数保留标准出处。

点什么：勾选“我已核对原始资料、列映射、系列声明与执行标准来源，确认将本次预览保存为未发布草稿。”，点 确认入库 N 个规格。入库被拒绝时，原因显示在按钮旁；前面各步的报错显示在页面顶部。

结果：“已保存 N 个规格草稿”，状态为“草稿 · 待人工核对”。可以 继续导入其他工作表，或 打开系列，核对与计算。原表没有的数值只按有出处的规则补充，并标明出处和可信分档。

提取厂家 PDF

打开哪里：“电缆型号版本”页的 提取厂家 PDF，进入资料目录。点 上传 PDF（不超过 64 MiB、500 页；同一文件重复上传返回原记录），进入该资料的工作区。厂家原件不随软件分发，需要自行导入。

1. 设定提取范围

展开“提取范围与方法”：

字段含义示例要求
型号系列要提取的型号YJLW03最多 80 字
规格行／列要提取的规格800、3×300最多 40 字
识别方法规则优先 · 自动离线识别（默认）、离线文字识别、规则与云端补充规则优先云端方式需要确认外发
厂家、电压、导体与护套分支帮助定位的说明—最多 300 字
原文页码、加入整页选择提取的页或片段，也可以在原文上框选—最多 4 个页或片段

点什么：开始离线提取。选择云端方式时按钮为 查看外发说明：对话框“确认外发所选内容”列出服务、模型、发送内容和范围，勾选“我已核对目的地址、模型与范围，同意外发所选内容”后才开始；服务没有配置时不能外发。

识别方式：规则方式优先读取 PDF 的文字层、表格和字形位置；没有文字层的图像页自动使用本机离线文字识别（OCR）。识别结果独立保存，原件文字层保持原样；识别置信度低于 0.95 的候选标为待消歧。本机没有识别模型或运行库时明确报错，不会联网下载，也不会假装识别。

2. 逐项核对候选值

看到什么：“候选参数”表（有歧义的在“待消歧”中），列出参数、原始值和核对状态（待核对、已接受、已修改、已拒绝）。每一项可以展开原始值、国际单位值、数值语义（厂家最大值或厂家公开值）、表头原文和证据位置。

点什么：对每一项选择接受、修改或拒绝；修改时填写修订值和修订单位；填写核对人（最多 100 字）和核对理由（最多 500 字），点 保存此项核对。快捷键：J、K 切换，Enter 接受，X 拒绝。

无歧义、原件文字与候选一致的项目可以用 确认本规格 N 项 一次确认；识别（OCR）得到的项目和重复字段仍需逐项核对。没有找到候选时，检查型号、规格行、单位及选定范围后重新提取。

3. 生成提案并批准

  1. 全部核对后点 准备提案，在“生成型号草稿提案”中选择目标型号：新建型号时填写型号名称、厂家、相对地电压和额定电压（kV）、芯数、每芯截面（mm²）、导体材料，以及“身份信息原文依据”（这些信息所在的页和原文）；填写新版本名称（最多 32 字）。点 生成提案；多个规格可以 加入多规格批量。
  2. “核对变更提案”列出参数、原值和提案值，状态为“等待人工批准”；可以 下载完整提案。
  3. 点 核对并批准，填写批准人，勾选“我已核对本提案的逐项变更，批准生成新版本草稿”，点 批准并生成草稿。
  4. 结果为“型号草稿已生成”，状态“草稿 · 尚未发布”。可以 新建型号设计 继续编辑，或 下载型号草稿。

批准只生成新版本草稿，不发布，不自动补全物性，也不把候选值升级为工程认证。核对人与批准人是操作记录，不是身份认证。

状态或提示处理
提取失败识别成功但字段提取失败，已收到的证据保留；查看“提取诊断”后重新提取
提取已中断网络中断、限流或重启；原件保留，重新发起提取才会再次调用
未找到有依据的候选值检查型号、规格行、单位及选定范围后重新提取
当前结构没有对应位置，请返回核对并拒绝此项，或新建公开规格草稿。拒绝该项，或改为新建型号
上传未完成检查文件大小与页数后重新上传

系列与规格

“结构表导入与系列”页的“系列与规格”页签列出全部型号系列。打开一个系列可以看到每个规格的状态、缺项和下一步，点规格名查看每个数的原表来源，点 打开型号设计 进入该规格的型号设计。

勾选规格后可以批量操作，每个操作都要勾选“确认所选规格与版本”才会执行。结果显示在工具栏下方，逐个规格列出：

操作做什么
批量核对对每个规格运行产品标准尺寸核对，保存真实运行，列出满足、待补数据和未覆盖的项目。
批量计算按一套统一工况（埋深、土壤热阻率、环境温度、接地方式等，须写明来源）对每个规格计算载流量；超出方法范围的规格会被拒算并说明原因。
批量审核对已提交审核的版本做人工批准或退回；尚未提交审核的草稿会整批拒绝批准。

需要修改已入库的规格时，在规格的来源对话框里选择“将当前设计保存为新版本”，填写改版说明并确认，建立独立的新版本草稿。旧版本和它的运行记录保持不变。

其他页签

  • 公开样本对照：把软件计算的外径、重量、导体直流电阻和载流量与厂家公开样本逐项对照，并标明哪些是厂家声明、哪些是研究参考情景。各规格共用的说明（如拒算原因和缺项）按原表分组写在表格上方，只有个别规格独有的说明留在行内。
  • 材料与环境：查看厂家手册里与材料、敷设环境有关的原始资料。这些资料只供查阅，不会自动变成计算输入。
  • 部件与研究模板：把已保存型号的部件或成功运行的研究定义冻结为参考草稿，供其他工程采用，见下文。
  • 数据交换：把资料和工程导出为 JSON 或 Excel 交换文件，或导入其他实例导出的交换文件。

部件与研究模板

“部件与研究模板”页签用于在工程之间复用经过核对的输入，分为两类：

类别来源采用后的结果
部件已保存型号中的导体、线芯层或公共层，连同材料和逐项出处写入目标型号中指定的同类位置，可沿原撤销路径恢复
研究模板一次成功运行的研究定义，连同固定的方法版本、参数和出处在目标工程中新建一项独立研究，不自动运行

使用流程：

  1. 创建参考草稿：选择实际保存的结构或成功的研究运行，预览逐项来源、方法版本和缺项，人工确认后保存为参考草稿。
  2. 发布参考版本：核对固定输入、来源和限制后发布。发布后仍为“参考”分档，不代表制造实测或工程批准。
  3. 采用到另一个工程：指定目标位置（部件）或逐项映射对象（研究模板），预览完整变化，人工确认后写入。

需要注意：

  • 冻结的是创建时保存的完整输入与出处；来源工程之后的修改不会带入已冻结的版本。
  • 部件字段在证据表中按工程单位显示（如 mm²、mm、Ω/km），研究参数保留原 SI 单位；数值保留全部保存位数。
  • 没有明确出处的非空工程字段不能创建为参考部件。结构表导入生成的型号，其结构层用途等字段尚无逐项出处，目前不能创建参考部件。
  • 实测值（实测 R₂₀、实测厚度等）不作为参考部件复制。
  • 研究模板目前支持 IEC 60287 稳态载流量的单工况研究。
  • 采用研究模板只新建研究，不修改目标工程的输入，也不发起计算；计算仍按研究的预检和运行流程由人确认。
  • 创建、发布和采用都须人工确认；Agent 只能查看和预览。
