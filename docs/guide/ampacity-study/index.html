载流量研究

分步说明载流量研究：新建研究、设置敷设截面与工况、填写方法参数、预检运行、读结论与口径，以及运行记录、方法对比、参数扫描、问询选型、计算书与正式交付。

载流量研究回答两类问题：给定敷设和环境时电缆能带多大电流（额定载流量），或给定电流时导体有多热（运行温度）。一项研究固定引用一个电缆型号版本和一个方法版本，每次运行保存当时的输入快照、方法版本和结果。完整演示见快速上手：研究院。

4. 填写方法参数

打开哪里：右栏 方法 页签，或结果区底部的 方法参数 页签。

填什么：参数由所选方法的插件声明，字段旁标明单位和范围。IEC 60287 稳态载流量的主要参数：

参数含义常见取值要求
集肤效应构造系数、邻近效应构造系数由导体结构决定的 ks、kp按 IEC 60287-1-1 对应导体结构的数值必填，在“参数来源”中写明出处
外部热阻公式T₄ 的计算式精确式IEC 60287-2-1:2023 已停用 ln(2u) 近似
计算依据IEC 2023 工程计算，或 TB 880 历史参考口径IEC 2023（默认）参考口径的结果只作参考复现
计算任务同时求允许电流和给定电流下的温度，或只求给定电流下的温度两者（默认）—
额定工况口径多回路时允许电流的口径：逐回路、全部回路同时，或两者都算逐回路（默认）见下文“结果口径”
校核目标电流判断是否满足的目标电流—单位 A；多回路时须指定目标回路
交叉热源与电缆交叉的其他电缆或热管道—每条给出名称、轴线埋深、外径、交叉角、单位长度发热量和出处；表面温度不能代替发热量
参数来源本组参数的出处说明—必填

排管热阻常数、逐缆电损耗、皱纹护套间隙等其余参数按敷设情况填写，含义与范围见IEC 60287 稳态载流量。方法要求的参数没有给出时，预检会指出缺哪一项，软件不会自动套用默认值。

5. 试算、预检并运行

试算：命令栏 试算 用当前输入（包括尚未保存的修改）快速算一次，结果标为“未保存”，并显示与已保存结果的差值；试算不生成运行记录，也不能用于交付。勾选 实时 后，每次修改输入都会自动试算。只有插件声明支持试算、且在本机运行的方法才提供这两个按钮。

点什么：命令栏 预检并运行，打开“运行前预检”对话框（标题下显示方法名和版本）。

看到什么：

预检结果含义下一步
你的工况在适用范围内 ✓输入完整，且在方法的适用范围内勾选“已知悉上述限制，仅运行通过预检的工况”，点 确认并运行
有 N 项需要修正缺项或输入错误，逐条给出字段和原因点每一条旁的“修正……后重新预检”跳到对应字段，修正后重新预检
有 N 项超出范围工况超出方法的适用范围不能运行。展开“查看方法适用范围”，调整输入或改用覆盖该工况的方法
当前没有可运行工况没有可以运行的工况检查工况设置

预检请求本身失败时，对话框标题为“预检失败”，并给出“前往方法参数”等按钮跳到需要补录的位置。预检同时说明求解位置（本机或超算）。运行完成后结果保存为一次新的运行，之前的运行保留为历史结果。

6. 读结论

结果区顶部的“载流量结论”给出结论，例如：

允许电流 944.8 A，受限于 回路 1 · 电缆 运行 350.0 A 时最热导体 33.5 °C，距 90.0 °C 温限 56.5 K

运行温度任务显示“负荷校核结论”，例如“350 A 负荷满足温限，最热 …”或“不满足温限”。有交叉热源时另列降额前允许电流、交叉降额系数和降额后允许电流。

怎么判读：

看什么判读
允许电流导体温度刚好达到温限时的电流；按结论写明的口径使用
受限于最先达到温限的电缆；改善散热应从它入手
最热导体、温限余量给定电流下最热导体的温度，以及与温限之差（温差，单位 K）；余量为负表示超温
“在其他回路当前负荷下没有正允许电流”其他回路的保存负荷已使该回路在零电流时超温
当前 / 已过期“当前”表示结果对应现在保存的输入、型号版本和方法；“已过期”表示其中之一已经变化，原结果保留为历史结果
当前 · 部分成功部分工况成功、部分失败；失败工况的原因在运行记录中

“结果详情”按“温度与电流”“损耗”等分组列出全部数值，列为物理量、对象、输出条件、数值和单位；“验证与范围”列出方法的适用范围和本次运行的核验证据。鼠标悬停在数值上可以看到完整精度。

结果口径

多回路时，允许电流有三种口径，结论里写明是哪一种，不能混用：

口径含义
单回路能力只有一个回路，回路内三相互热仍计入，按该回路各电缆的温限求上限。
全回路共同能力所有回路同时通过相同的平衡电流，任一电缆先达到温限即限制共同电流。
其他回路固定负荷下的条件上限只调节目标回路，其余电缆保持保存的负荷；各回路的条件上限不能同时使用。

详见载流量口径与热网络参考。

8. 运行记录与两次运行对比

打开哪里：结果区右侧的 运行记录。

看到什么：对话框“运行记录”列出这个研究的全部运行，每行有时间、状态和方法，可以打开任一次的输入和结果。还没有运行时显示“尚无运行记录”。

对比两次运行：在“对比两次运行”中勾选两次运行，点 对比所选运行（恰好选两次时可用）。对比表分三组：“结论量值”“限制对象”和“输入差异（SI）”，列为“运行 A”“运行 B”和“差值 B − A”；两次输入完全相同时显示“输入相同”。

全部研究的运行也汇总在侧栏“记录 → 运行与作业”。

9. 方法对比

用于比较多次运行，例如同一输入下 IEC 60287 与 GB 50217 校正的结果，或不同参数下的结果。

  1. 在命令栏的分析下拉中选择 方法对比，页签为“结果”“输入差异”“证据”。
  2. 在“可比较运行”表中先勾选一个基准运行，再勾选一至四个对照运行（最多五个），点 比较所选运行。
  3. “输入差异”页签的“对比输入差异”表列出改动的条件和对象，以及基准值和对照值（SI）。
  4. “结果”页签的“方法结果差异”表列出各物理量的基准值、对照值和差值；导出对比 CSV 的列为物理量、对象、输出条件、基准 / SI、对照 / SI、差值 / SI、单位和来源。
  5. “证据”页签 下载未配对量与固定记录，得到没有配对的物理量和运行的固定记录（JSON）。

只有通过完整性核验的成功运行可以比较。完整性不通过时显示“对比运行完整性未通过，拒绝显示数值”。GB 50217 校正与 IEC 比较时，只与“全回路共同能力”口径配对。

10. 参数扫描

把一个输入按给定范围逐点计算，得到结果随该参数变化的曲线。

  1. 在命令栏的分析下拉中选择 参数扫描，页签为“曲线”“扫描点”“设置”“验证与范围”。

  2. 在“设置”页签填写：

    字段含义要求
    扫描变量当前输入中的一个变量，例如土壤热阻率、埋深必须是当前输入中真实存在的变量
    起点、终点、步长扫描范围，单位见字段非负下限、更大的上限和正步长；采样点 2–100 个
    范围出处为什么扫这个范围必填

  3. 点 应用扫描设置，保存后预检并运行。

看到什么：每个采样点都是真实计算，失败的点保留为缺口，不做插值。结论句为以下之一：

  • “插件判定改变的临界区间：…（仅采样区间）”：临界值在这个区间内，没有在区间内再插值；
  • “所有已采样点均满足；临界值不在已采样点中”；
  • “所有已采样点均不满足；请调整负荷或扩展扫描范围”。

导出逐点 CSV 导出每个采样点的数值，“完整精度与追溯”保留完整精度和来源。

11. 问询选型

用于“目标电流下选哪个型号”：对一组候选型号逐一计算，按判定排序给出推荐。

新建：研究任务选“客户问询选型”，填写 目标电流（A，大于 0），从型号库选择候选型号，并为每个候选填写来源和出处。系统结构演示型号不能作为工程候选。

看到什么：“候选结果”页签的“真实选型候选”表：

列含义
候选型号、截面 mm²候选的型号与截面
允许电流 A该候选在研究条件下的允许电流
余量 A（%）允许电流与目标电流之差
判定满足、不满足、不适用或计算失败
限制原因不满足或不适用的原因

表格上方给出“推荐：<型号>”，推荐按已保存的判定排序，结论依赖工程师给定的参数。没有满足的候选时显示“当前条件下没有合格型号”，并给出目标电流与候选中最高的允许电流，需要调整型号范围、敷设或负荷后重算。

查看一个候选：所选候选与它的运行、工况一起固定，结果、布置图和模型都对应同一候选；敷设输入显示为“固定运行敷设输入 · 只读”，右侧当前草稿与撤销保持独立。点“返回候选结果”回到候选表。保存的候选输入无法核对时显示“保存候选无法核对”，此时返回候选结果重新选择。历史运行的候选只供追溯，不能用于当前计算书。

12. 计算书与正式交付

打开哪里：命令栏 生成计算书，页签为“内容”“来源”“预览”。

点什么：生成客户计算书。生成过程中依次显示读取保存运行、导出敷设截面、核验收敛与来源、绘制保存场图等步骤，可以 取消生成，取消不影响保存的运行。

看到什么：生成后，在“PDF 版本”中选择客户版或内部审核版，再 下载 PDF，也可以保存 HTML 存档。计算书只引用所选的一次当前运行，不重新计算；敷设截面超过三个时，须按工况分别生成。

生成计算书不可用时的提示处理
先运行研究，取得保存结果预检并运行
先保存修改并重新运行保存后重新运行
旧结果保持为历史，请先重算重新运行取得当前结果
等待运行成功后生成等运行完成

需要单位名称、文件编号、版次和签栏的正式文件时，点 正式交付（PDF / Excel），步骤见正式交付文件。正式交付文件同样只读取已保存的运行，导出不等于审核或发布。
