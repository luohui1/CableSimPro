仿真研究

分步说明有限元仿真：超算设置、新建仿真研究、IEC 与有限元对比和有限元热场的参数、检查输入与预检、提交与进度、收敛判据、读温度场与 IEC 对照、超算作业列表，以及各状态与报错的处理。

仿真研究用有限元等数值方法计算电缆和敷设区域的温度场与损耗，用来检查 IEC 60287 解析假设之外的影响，例如有限区域、非均匀土壤、暂态过程和电热耦合。方法原理、收敛判据和验证算例见有限元对照。

研究用途打开后的模块与页签
IEC 与有限元对比同一保存工况下逐回路反求允许电流，与 IEC 结果并列载流量：结果、结果详情、验证与范围、方法参数
电缆有限元热场（IEC 损耗反馈）给定负荷下的稳态温度场，损耗按 IEC 公式随温度迭代温度场：结果与 IEC 对照、场图、取样、方法参数、诊断、收敛
暂态温升负荷阶跃、周期或应急负荷下导体温度随时间的变化暂态温度：结果、时间序列、场图、取样、诊断、收敛、方法参数
护套损耗按相序与接地拓扑计算金属护套中的感应损耗护套损耗：结果、损耗系数、方法参数
电热耦合损耗与温度相互影响（电阻随温度变化）的稳态解电热耦合：结果、场图、取样等
混合载流量参考研究有限元标签与数据驱动模型的对照研究，只作参考混合载流量：预测结果、模型验证、来源

1. 准备：配置超算

有限元求解、批量仿真和模型训练在 Slurm 超算集群上运行。每个方法在哪里运行以方法清单的声明为准；只在超算运行的方法遇到超算未配置时会提示配置，不会改到本机计算。

打开哪里：设置 → 计算位置，“超算连接”区域。

填什么：

字段含义要求
SSH 别名本机 SSH 配置中的主机别名从列表中选择
分区提交作业使用的 Slurm 分区必填
远程工作目录超算上存放作业文件的目录完整路径，须可写
环境、环境目录超算上的 Python 环境及其根目录必填
单批核时预算一次提交允许占用的核时上限大于 0，最多 2000
累计核时预算全部作业累计的核时上限不小于单批预算，最多 20000

点什么：保存连接，再点 测试连接。测试依次检查主机可达、分区存在、目录可写和环境可用，失败项分别显示“无法连接”“不存在”“不存在或不可写”“不可执行”。

看到什么：状态为“已配置”。管理员用外部配置文件指定超算时，本页只读。完整说明见仿真计算环境。

2. 新建仿真研究

打开哪里：在工程中点 新建研究，工程模型自动带入。

填什么：

字段含义要求
研究名称最多 120 字—
要回答的问题按已安装的插件列出，例如 IEC 与有限元对比、暂态温升、护套损耗、电热耦合—
计算方法同一问题有多个可选方法时出现—
方法参数来源“插件声明的默认值（缺项需填写）”、沿用最近同版本研究；IEC 与有限元对比还可以沿用本工程已保存的 IEC 研究参数选择沿用时，来源记为所沿用的研究

对话框下方列出所选方法的适用范围（“先核对基准与敷设条件”）和需要填写的方法参数。

点什么：建立研究，进入上表所列的模块。

3. 填写有限元参数

参数由插件声明，字段旁标明单位和范围。容差和门槛都是温差，以 K 显示和输入；初始温度、环境温度等绝对温度以 °C 显示。材料的热导率、体积热容、电导率及其有效温区必须有来源，没有默认热容。

4. 检查输入与预检

点什么：温度场、暂态、护套损耗和电热耦合模块有 检查输入（超算未配置时也可以先做）和提交按钮；IEC 与有限元对比在命令栏点 预检并运行。

看到什么：“预检步骤”区域分两行：

  • 输入完整性与范围：“已通过输入检查”，或“请修正下列缺项”并逐条列出；
  • 原生环境：“已通过超算原生预检”，或“未通过，请核对下列说明”。

“超算核时预算”区域显示“提交 <分区> · 本次核时预算上限 X 核时”和每个工况的节点（自由度）与单元数。实际核时以 Slurm 记账为准。全部通过后，勾选确认并点 确认并运行。

5. 提交与进度

看到什么：“超算运行记录”显示状态（准备、已提交、后处理、连接中断、正在取消）、作业号（尚未分配时为“等待 Slurm 回执”）、已用核时与预算以及排队位置。

可以做什么：停止 当前作业；连接中断后 恢复原作业 继续读取原作业，不重新提交；重新读取进度。读取失败不会改变已保存的运行。

6. 收敛研究

有限元结果必须有合格的收敛证据，才显示为正式值并允许正式导出。两类研究的判据不同。

IEC 与有限元对比

收敛检查在一次运行内完成：按“多档网格比例”逐档求解，再把计算域放大后求解一次。最后两档网格之间、以及最细网格与放大计算域之间，最高温度变化都不超过“温度迭代容差”（默认 0.1 K）、允许电流变化都不超过“载流量校核容差”（默认 0.5 A），才算通过；两项都通过后才输出与 IEC 的偏差结论。

电缆有限元热场：自动加密与扩域

打开哪里：温度场模块的 收敛 页签，“自动加密与扩域”。

点什么：设置收敛预算，在“确认收敛研究预算”中填写累计核时预算（大于 0，不超过 2000），点 确认预算并开始。

看到什么：

  • 逐级提交：每级网格减半或计算域加倍，最多 12 级；完整计算网格上限 400 万节点；达到门槛即停，资源不足或预算耗尽时保留已有结果。
  • 收敛判据：“网格与扩域各连续两级变化均小于 X K”（默认 0.1 K）。达到后显示“保存核验已达到门槛 · 门槛 0.1 K”，并在最终网格上反求允许电流。
  • “自动收敛保存记录”表逐级列出级别、网格（m）、域深（m）、自由度、热点温度（°C）、变化（K）、核时、墙钟时间（s）和保存运行；图中给出逐级网格与扩域的热点温差。
  • 边界说明：“Kennelly 镜像远场”或“环境定温截断”，以及“地表等温”。

可以做什么：停止后续级别、恢复原作业、回收原作业结果、完成载流量封存、用当前版本继续、重试。

提示处理
尚未收敛：网格与扩域未达到连续两级门槛增加预算继续，或检查网格与计算域设置
温度收敛已达标；最终允许电流运行失败：…按失败原因处理后重试最终一级
累计核时预算须大于 0 且不超过 2000。修正预算

7. 读结果

页签内容怎么判读
结果、结果与 IEC 对照导体温度、允许电流及与 IEC 结果的对照两者模型假设不同（有限计算域与半无限土壤、集总温度与层内梯度等），差异本身不是误差证明；报告写明差异来源
场图温度分布、等温线和最热点，按物理尺度绘制没有有效结果时显示“无数据”，不绘制替代的场
取样指定位置的温度—
时间序列暂态研究中导体温度随时间的变化温限时刻由实际时间步线性插值，不外推
损耗系数护套损耗研究得到的损耗系数用作 IEC 外部系数时须在声明范围内
诊断、收敛求解器、网格、能量平衡和逐级收敛记录没有达到门槛的结果不能正式导出

对照类结果标为“仅供参考，未经工程批准”，不自动批准，也不代替 IEC 载流量。

9. 没有配置超算时

  • “求解位置”显示超算方法“未配置”，预检提示“超算未配置，请前往设置 → 计算位置。输入已保存。”，确认并运行 不可用。
  • 检查输入 仍可在本机完成；IEC 60287 等解析计算、参数扫描、标准核对、正式交付和备份恢复照常可用；已保存并通过校验的仿真结果仍可查看。
