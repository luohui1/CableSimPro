正式交付文件

规格书、计算书、载流量表和研究报告：从哪里导出、文件由哪些部分组成、四个签栏、修约规则与显示单位，以及导出与审核发布的区别。

正式交付文件只读取已经保存的运行和型号生成，不重新计算，也不会自动提交审核、批准或签字。每个数值都能追溯到所用运行的输入快照、方法版本、插件封签和原始数值。

下载了 PDF 不等于已审核或已发布

导出正式文件只是把已保存的结果按规定格式呈现。型号的审核、批准和发布在型号设计的“审核与发布”中由人完成，并单独记录；导出、下载或由 Agent 生成文件都不会改变审核或发布状态。对外签发前，须由工程师复核并完成签署。

四类文件

文件依据导出位置
规格书一个型号的结构、电气参数、载流量、短路容量和标准核对五个部分的保存结果型号设计 → 规格书
计算书一项研究中选定的一次完整运行研究 → 计算书内容
载流量表一次载流量表运行，保留每个工况的条件、回路、单位、口径和缺项研究 → 计算书内容（选择“载流量表”类型）
研究报告同一工程中明确选择的 1–16 次运行，按运行逐一呈现方法、条件、结果和已有比较研究 → 计算书内容（选择“研究报告”类型）

每类文件都可以导出 PDF 和 Excel。普通单次研究不能冒充载流量表；研究报告不生成运行中不存在的结论。

导出步骤

  1. 打开导出对话框：在研究的“计算书内容”页，或型号设计的“规格书”页，点 正式交付（PDF / Excel），打开“正式交付文件”对话框。

  2. 选择类型：在“正式交付类型”中选择计算书、载流量表、研究报告或规格书。必须先有已保存且可核验的来源，否则提示“请先选择已保存且可核验的来源”。

  3. 填写单位信息：

    字段是否必填说明
    单位名称必填实际交付单位的名称，最多 120 个字符
    文件编号必填本次正式交付的编号，最多 80 个字符
    版次必填例如 A 或 1.0，最多 32 个字符
    页眉 / 页脚可选每页显示的自定义文字，各最多 160 个字符
    签发日期可选文件签发日期，格式 YYYY-MM-DD；不是签字日期，不填时不自动写入当天日期

  4. 核对来源并预览：平台核验来源后生成预览，并固定预览内容的摘要。来源在此期间发生变化时，预览失败，需要重新预览。

  5. 核对章节与签栏：逐项查看预览中的章节、数值和签栏，确认后勾选“已核对正式交付来源和签栏”。

  6. 下载：点“下载正式 PDF”或“下载 Excel”。导出前平台再次核验来源；预览与下载使用同一份文件内容。

文件的组成

封面

单位名称、标志（如有）、文件编号、版次、签发日期和四个签栏。PDF 每页都有单位、编号、版次和自定义页眉页脚；Excel 的工作表页眉页脚也包含这些内容及页码。

正文

正文只放与结论直接相关的工程前提和结果，例如允许电流、导体温度、限制对象、敷设条件。内部工况编号（如 case-1）和布置键以中文工况名称呈现。

  • 规格书共八章：封面、标准、结构、电气、载流、短路、核对、修订。正文“结构尺寸与用料”只列外径、内径等结构尺寸和每公里用料。
  • 载流量表按“规格 / 导体标称截面 × 敷设条件”组成二维矩阵。条件列分别记录埋深、土壤热阻率、环境温度、导体最高允许温度、敷设方式、回路数、频率、屏蔽接地和负荷模型；空气敷设和排管单独成组。没有计算的交叉项显示“未计算”，不补零；同一条件出现重复来源时报错，不覆盖、不平均。
  • 计算书呈现所选运行的方法、条件和结论；研究报告按运行逐一呈现，并保留运行之间已有的比较。

追溯章节

开发说明、原始公式、详细边界和完整来源放在追溯章节，不放在正文：

  • 每个正文数值的原始数值文本、单位和来源位置；
  • 显示数值的换算系数、偏移量和修约间隔；
  • 规格书中三维模型的建模长度、模型材料体积和材料密度（“三维模型的建模长度、体积与密度”表）；
  • 签栏所依据的签核记录索引。

Excel 中，“文件信息”工作表包含单位、标志、编号、版次与四个签栏；正文和追溯章节分别成表；“追溯数值”工作表同时保留数值副本和原始数值文本，避免 Excel 显示或另存时的精度损失。

四个签栏

封面上的四个签栏是设计、校核、审核、批准。

  • 导出对话框中不能填写签字人；签栏只读取真实的已保存签核记录，没有记录的栏位留空，显示为“空白（无真实签核）”，由人工签署。
  • 目前只有型号规格书的批准记录可以填入“批准”栏，且须与本次规格书的提交、工程修订、内容摘要、输入、来源和发布范围一致；失效或范围不符的记录不会采用。
  • 修订作者、操作人、评审要求、来源核对和 Agent 提案都不充当签名。
  • 单独导出的计算书或载流量表不会继承型号规格书的批准。

规格书的状态

型号规格书的审核状态依次为草稿、待人工审核、已批准、已发布，文件中的标示如下：

情况文件中的标示
草稿、待人工审核或已批准但尚未发布客户版封面注明“客户版编制草稿 · 未批准发布”
已批准、已发布批准栏可填入与本次内容一致的真实批准记录
有不在本次发布范围内的项目封面列出“本次发布不含项”及原因、声明人，并注明这些项目没有取得本次发布的计算结论
引用的运行已成为历史结果封面注明“历史结果 · ……；请重算后生成当前规格书”；正式交付按钮不可用，提示“当前规格书来源已过期，请先重新生成并保存”

通过 Agent 生成规格书时，用户未说明用途则按内部审阅稿输出，缺项随文列出；客户稿须补齐缺项，或由人声明发布范围。

修约规则

正文和 Excel 工程主表使用统一的显示政策 cablesim.engineering-display/2：

  • 依据 GB/T 8170-2008 第 3.2、3.3 条，从保存的原始数值出发，只做一次单位换算，再按“四舍六入五成双”（半偶修约）修约到下表的显示精度。
  • 不先修约 SI 数值再换算，也不把修约后的数值写回运行记录。修约只作用于显示，不改变完整来源、求解结果、合格判定和签审记录。
  • 正文只用普通小数，不用 E 记数法。例如电容 2.198E-10 F/m 显示为 0.2198 μF/km，0.0004 不写成 4.000E-4。
  • 修约进位到更高一位数量级时，按新的数量级保留有效数字，例如 9.99995 Ω/km 显示为 10.00，而不是 10.000。
  • 未修约的数值（小数位 7 位以上且有效数字 5 位以上）和单独出现的开尔文温度 K，会被生成端和校验程序拒绝。

交付存档

侧栏“记录 → 交付”列出所有已生成的交付文件，可按工程或型号筛选并重新下载。存档就是当时生成的文件，不会按新数据重新生成。

按工程或系列批量导出

可以按工程或按系列成员批量导出整包交付文件。每个条目仍遵守单个文件的来源、单位、签栏与修约规则，并随整包附带清单。接口说明见正式交付文件契约和接口参考。

在 Agent 对话中生成计算书与规格书

计算书和规格书也可以在 Agent 对话中生成。Agent 先提交固定了预览内容与来源的提案，人工接受后由同一套正式交付服务导出 PDF。单位名称、文件编号和版次须由用户明确提供，没有真实签核记录的签栏保持空白。

计算书与规格书的追溯

  • 计算书的“来源”页列出所用运行、宿主对输入与结果一致性的校验和方法版本。
  • 运行必须属于所选工程、已完成并通过输入 / 输出完整性校验；只完成一部分的运行保留缺项原状。
  • 历史运行按其历史状态呈现，不会借当前方法版本或默认参数替换。
  • 有限元温度场必须有合格的收敛证据才能正式导出。
  • 安装包附带独立的校验程序，按原始数值重新换算并比对正式文件中的每个显示数值，不依赖导出端自己写出的显示信息。
