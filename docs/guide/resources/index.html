资源库

分步说明资源库：浏览与筛选、新建和导入资源草稿、参数与来源的填写、核对来源、发布、退回、停用、派生新版本、批量操作、标准与规则的依据浏览，以及各状态与报错的处理。

资源库保存计算会引用的基础资料。每条资源都有版本和状态，研究与型号引用的是某个固定版本：资源更新后，已有的研究和型号不会被悄悄改变，需要工程师主动更换引用并重新计算。

侧栏“资源”分组内容
电缆型号版本型号库中的全部版本，见型号库与结构表导入
材料与部件材料、部件和结构，例如导体、绝缘、屏蔽、护套、铠装、填充和土壤的物性
模板与计算方案敷设模板和计算方案
标准与规则规则，以及标准依据库的“依据浏览”

浏览与筛选

打开哪里：侧栏“资源”下的分组。页头显示“N 项 · 固定资源版本”。

怎么筛选：工具栏“检索”按资源名称或标识查找；“类别”（分组内有多个类别时出现）和“状态”筛选；清除筛选 恢复全部。列表列出名称、类别、版本、状态和更新日期，每个类别最多显示 50 项，可以翻页。

看到什么：点一行，右侧显示“所选对象属性”：参数、来源、版本历史和可用的操作。标准规则的版本列显示标准版次，悬停可以看到资源版本号。

导入资源草稿

点什么：页头 导入资源草稿，选择 JSON 文件 或把定义粘贴到“定义内容”，点 校验并导入。

每次导入一个资源草稿，文件不超过 120 KB，类别须属于当前分组。批量导出包需要拆成单项文件后逐个导入。从其他实例交换整套资料用“电缆型号库 · 数据交换”。

核对、发布与版本

资源的状态和可用操作：

状态可用操作说明
草稿编辑资源草稿、核对来源、导出资源定义草稿可以修改；核对定义及来源后，再单独确认发布
已审核发布、退回草稿、导出资源定义内容已核对；修改前须退回草稿
已发布停用、派生新版本、导出资源定义版本内容固定，可以被新的研究和型号引用
已停用派生新版本、导出资源定义不再允许新的引用，已有引用和历史记录保留

核对来源（草稿 → 已审核）：在详情中点 核对来源，展开“参数、来源与固定版本依据”逐项查看，填写“资源操作说明”（4–1000 字，记入资源历史），勾选“已核对这份定义及来源，理解原始资料的适用范围与缺项”，点 确认核对来源 1 项。核对只记录操作者的检查，不改变原始来源的类别，也不提升原始资料的可信度。

发布（已审核 → 已发布）：点 发布，填写操作说明后确认。只能发布已核对且依赖完整的版本；发布记录不等于工程认证。材料与规则发布后才能在型号设计中绑定。

退回草稿（已审核 → 草稿）：需要修改已核对的内容时使用，修改后重新核对。

停用（已发布 → 已停用）：停用后不能再被新引用，既有研究的固定版本记录仍保留。

派生新版本（已发布或已停用）：点 派生新版本，填写新版本号（三段数字，不能与原版本或已有版本相同），点 建立新版本草稿。派生草稿需要单独编辑、核对和发布，不会自动升级研究中的旧引用。

批量操作

  1. 勾选资源（或“选择本页”），每批最多 50 项。
  2. 在 批量操作 中选择导出固定版本定义、核对来源、发布、退回草稿或停用，点 预检批量操作。平台逐项读取真实版本并判断能否执行，每项显示可操作、条件不足、待核实等状态和原因。
  3. 填写资源操作说明（核对和发布都需要）；核对需要逐项勾选。
  4. 点 确认<操作> N 项；导出时为 下载 N 项定义，下载的固定版本 JSON 保留来源与版本摘要。

执行中关闭窗口会停止剩余项；已经发送的请求保留原记录，之后可以核实实际结果。

标准与规则：依据浏览

打开哪里：侧栏 标准与规则，默认为“依据浏览”页签（另一个页签“资源版本”是规则资源列表）。

怎么查：

  1. 在“标准版本”中选择标准，例如 GB/T 12706.2—2020。
  2. 在“按量或条款检索”中输入，例如“绝缘标称厚度”“最大直流电阻”，或在“表或条款”中直接选表。
  3. 需要按条件查时点 条件检索，选择量并填写条件，点 查依据。

看到什么：“标准完整表格”。选中一个格子打开“选中格详情”，显示原值、单位、适用条件、页码和核验方式；核验一致时可以 复制引用（方向键选格，Enter 复制）。“本次会话查询记录”保留本次的查询，历史查询显示为固定依据快照。底部的“未覆盖条款”列出依据库尚未收录的条款，这些条款在标准核对中判为“未覆盖”。

依据浏览只读，不需要保存。标准依据库作为插件 cablesim.standards-basis 发行，标准核对、GB 50217 校正等方法通过它查询条款和系数，并在结果中记录所用依据库的发行摘要；更换依据库版本不会自动改变已有工程的绑定。见标准核对。
