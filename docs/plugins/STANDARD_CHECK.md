# 产品标准尺寸核对

`cablesim.standard-check / dimensions` 接收 `cablesim.domain/1` 的保存输入，输出 `x-cablesim.standard-check` 工件。宿主保存不可变输入、方法发行摘要、运行与工件摘要；所有限值、公式、修约和判定在插件中执行。不会使用 IEC 60287 的热计算替代产品标准核对。

## 原文与边界

已按实现条款核验用户提供的 GB/T 12706.1/.2/.3—2020、GB/T 11017.2—2024、GB/T 3956—2008 PDF。包内 `sources.json` 记录文件名、SHA-256 及正文 / PDF 页码偏移；不分发整份标准原文。

已实现：XLPE 表内标称绝缘厚度；低压绝缘平均厚度与最薄点、中压最薄点与厚度偏差；中压内衬层、铅套、隔离套和外护套的受支持假定直径链；铜带厚度与搭盖率；110 kV 铜丝径与平均间隙、铅 / 皱纹铝 / 平铝护套与外护套标称表；第 2 类裸铜、镀层铜、铝导体 R₂₀ 表 2。

以下要求始终保留为“未覆盖”，不以其他标准或版本替代：

- GB/T 11017.1—2024 缺少原文：110 kV 绝缘、金属护套和外护套的最薄点要求。
- GB/T 11017.2—2014 缺少原文：12706 系列引用该版的铜丝平均间隙定义与算法。
- 金属屏蔽 / 护套的短路容量与截面下限：需故障电流、持续时间与适用的短路方法，几何截面不代表满足短路要求。
- 第 1 部分内衬层的省略 / 应用条件、三芯省略内衬层、公共屏蔽或线芯附加护层、异截面成缆、双带铠装附加包带垫层、绕包内衬层的制造检验、其他未核验构造；未覆盖的直径分支使依赖它的护套公式停止判定。
- 非 XLPE 绝缘、第 1/5/6 类导体电阻、表外尺寸、供需协议变更及未核验的制造试验要求。

数值缺项与规则未覆盖分开记录。层标称厚度、单带标称厚度、最薄点、最大 / 平均实测厚度互不替代。最薄点公式使用规定标称厚度；采用更厚的设计标称值时随之提高，低于已知标准标称要求的设计不能反过来降低测量下限。标称最低要求与测量要求分别判定。公式中间值同时记录设计标称、标准标称最低要求和采用值。R₂₀ 还需明确导体类别、镀层和数据性质；厂家声明上限不作为实测值。没有近似尺寸或默认电阻兜底。

附录 A 的直径只用于护层限值，不能用厂家近似成品外径替代。每步按附录 B.1 修约至 0.1 mm；最薄点按表 B.1 修约至 0.01 mm 后比较。12706.1 的绝缘平均值修约至 0.1 mm。

## 页面与异常

型号的“要求与标准”展示原文绑定及全部要求；“标准核对”展示要求、实际值、余量与判定。行按线芯 ID、层角色定位到当前结构；已删层保持历史快照并明确无法定位。右侧“依据”读取该次运行的条款、输入来源、公式中间值及摘要。

型号输入或方法发行变化即显示历史结果，原表不被草稿替换。保存、范围确认与运行沿用宿主流程。重复点击受运行状态保护；连接中断在同一浏览器会话中保存已确认请求标识，刷新后继续查询 / 重试同一请求，不创建重复运行。确定的失败重新预检；不覆盖已保存输入和既有快照。

“要求与标准”提供要求清单、执行标准与待批准导入页签。条目由已验证的标准核对工件提出；人工选择完整定义的要求，填写审批人并明确确认后才写入批准记录。来源缺失、限值未定义或判定能力未覆盖的条目保留，但不能批准。范围确认不代表要求批准。

宿主 `backend/kernel/requirements.py` 只存要求定义、对象 ID、来源版本、条款、方法发行绑定和不可变审批回执，不计算限值或判定。审批版本独立于型号输入修订；批准不会改型号或旧运行。请求标识防止断网重试产生重复记录，型号与审批版本分别执行并发校验。新目录与原批准定义不同时显示冲突；仅修改测量值或调整线芯数组顺序不会替换同一对象的要求批准。

再次执行核对时，当前目录里已批准的要求集及审批回执摘要写入研究输入来源，随运行快照保存。初步核对可以用于准备要求目录，页面明确显示该次运行是否绑定人工批准要求。型号发布和完整产品认证仍需单独人工流程。原生 CAD 仍按其方法范围拒绝多芯或其他不支持结构。
