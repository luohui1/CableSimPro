# 型号载流量表

型号模块 `rating-table` 把独立型号的典型工况保存为一个研究。每行可编辑、增删；当前型号事实、各行完整领域输入、方法参数、工况来源和插件版本进入同一不可变运行。使用 `cablesim.iec60287/steady-rating`；宿主与页面不复制计算公式，不以产品标准限值补造实际 R20。

`backend/kernel/rating_conditions.py` 仅转换工况模板。直埋品字、水平留间隔、每根电缆一管及空气模板均显式保存中心埋深、土壤热阻率、环境温度、中心距、管径和接地条件；模板值是设计假设，不是现场测量。型号的实测 R20 可投影到本次计算输入，设计记录保持原值。系数、管内经验常数及来源须明确；求解器设置是数值收敛条件。

研究驱动 `batch` 接收已保存的完整工况列表及可选 `selected_case_ids`（null为全部）。运行命令只传研究身份、输入修订、插件锁摘要、范围确认和幂等请求标识。默认全选，可只运行勾选行；预检仍检查每行范围，只执行勾选且通过检查的行。未勾选的可用行标为“未运行”，拒算行保留具体原因。即使全部所选行拒算，也保存拒算记录，不能生成近似允许电流。编辑并保存后，旧运行继续保持历史，重复请求不重复执行；全局保存也保存已编辑的工况配置。

当前所选稳态能力支持地下单芯同心圆、明确光滑管状金属护套，以及其声明范围内的直埋/排管热路。空气、多芯、铜丝屏蔽、波纹护套等不符合此能力的工况逐行显示“超出范围”或“待补数据”及原始原因；其他插件已提供的能力不代表本模块自动切换到该方法。江南 YJV22 8.7/15 kV 3×240 与起帆 CU/XLPE/CAS/PVC 64/110 kV 1×800 的公开资料按既有来源验证；构造不在范围或缺少厂家数据时保留缺项。

依据由所选插件工件记录：IEC 60287-1-1:2023 4.2.1、5.1.2及适用电损耗分支；IEC 60287-2-1:2023 4.2.4、4.2.6及适用热阻分支。`tb880_reference` 保留旧版验证口径，页面和规格书明确标为验证复现，不能当作 IEC 2023 工程结论。

规格书内容页可纳入一个当前载流量表运行，并与一个当前几何运行合并；没有几何运行时可生成含载流量章节的草稿，外径与用料明确未纳入。章节只读取指定快照，包含各行实际条件、允许电流、拒算原因、完整精度与版本来源；输入或研究变化后禁止用历史运行生成当前草稿。草稿不代表型号审核或发布。

`tests/test_type_rating.py` 验证实际 IEC 执行、冻结工作点的独立热平衡手算、两款真实型号的缺项/拒算、单位范围、历史与幂等运行。受控 `.data/tb880/fixtures/tb880-case-0-1.json` 只把 `inputSi` 作为输入；参考值 `821.7763334392 A` 来自 CIGRE TB 880:2022 case 0-1，62–75页，完整源摘要见受控摘录。浏览器合成验收工况算得约 `821.776330 A`，电流绝对差小于 `0.001 A`；水平与排管为修改条件演示，不宣称与该品字形参考工况一致。

正式前端的 `frontend/src/features/type/tests/verify-rating.mjs`、`verify-analysis.mjs` 和 `verify-specification.mjs` 覆盖保存、参数编辑、键盘、页面状态、完整精度与规格书章节。`frontend/scripts/verify-type-resilience.mjs` 在隔离数据库中验证重复点击、网络中断/重载后同一请求重试及错误保留；执行故障仅注入传输响应，不启动求解器。实际进程故障由宿主执行器测试覆盖。运行方式见 `frontend/README.md` 与型号模块 README，产物只写入 `.data/`。
