# 电缆插件生态安排与迁移路线

## 产品边界

平台卖的是“定义电缆 → 安装工况 → 选择研究 → 复核 → 交付”的工程能力，
不是一组外部科学计算库的名称。库留在插件内部，宿主只认识稳定对象/命令/工件。
先模块化单体 + 显式进程适配；不在未验证之前拆成十几家微服务或插件仓库。

首页只需最近工程、新建/打开和插件中心入口。项目内固定专业工作区；插件按任务
贡献上下文检查器、画布与结果，不永久扩张导航。当前新增独立 `/?plugins=1`，
不会重构或覆盖其他会话的 R3 前端。

## 当前发行目录

| 组 | 本批登记 | 运行范围 |
|---|---|---|
| 内建兼容插件 | ampacity-core / model-core / report-core | 复用原热网络、待审批建模提案、快照 HTML 计算书 |
| 设计 | cadquery | 六层同心参数化 STEP；不替代 CableModelKit |
| 网格 | gmsh | 六域 P1 二维电缆本体网格 |
| 交换 | meshio | 本项目网格转 VTU |
| FEM | thermal2d | 固定缆表温度 + 显式导体热源的真实二维基准 |
| 后处理 | pyvista | 已有温度场统计和等温线 |
| 待接入 | CableModelKit / ReportEngine / IEC60287 / DOLFINx / Elmer / FEMM / MFEM / vtk.js | 无安装按钮，不宣称已具备求解/渲染 |

这是 3 个宿主封装 + 5 个第一方有限范围适配器 + 8 个规划条目。
安装登记不安装第三方包。运行环境在专用测试环境中按 `plugins/requirements-native.txt` 准备，
并在实际运行中记录完整已安装包版本；这份 requirements 不是所有传递依赖的锁文件。
宿主启动或市场浏览不导入 CAD/FEM/VTK，也不因为缺其中某一库而不能打开已有项目。

## 推荐套件而不是强绑定全部依赖

- 日常载流量：原热网络 + 原模型 + 原报告，不下载 CAD/FEM。
- 电缆设计：CableModelKit（后续桥接）+ CadQuery 原生工件适配。
- 热研究试验：Gmsh + meshio + scikit-fem；PyVista 按需。
- 企业交付：ReportEngine、人工审查记录与原始结果快照，不重算后混用新版本。
- 高级求解：DOLFINx / Elmer / FEMM / MFEM 按平台及授权/许可独立配置。

目录推荐套件与必须执行依赖不同。当前精确依赖仅反映有限适配器所需的上游工件链。
公共市场上依赖关系不能用于强制安装不相干广告或遥测插件。

## 其他会话的接入安排

### CableModelKit

保持独立代码和版本；先制作只读导出 adapter，将其领域结构映射为 R2 资产/几何配方。
uid、材料来源、尺寸单位、展示/分析几何、误差和失配必须可追溯。
不能把当前圆形 STEP adapter 标为完整 CableModelKit 已移入宿主。
下一批以其真实源码包/接口与单独基准为输入建立兼容测试。

### ReportEngine

保留 ingress → immutable snapshot → preflight → contributors → Report IR → renderer。
报告适配器消费结果工件与文件哈希，不自行修改参数或偷偷求解。
缺关键图时明确标缺；受控报告 renderer，禁任意 HTML/script/网络字体和远程图访问。
ReportLab/Typst 原生运行与布局专项单独验收；当前 report-core 仍只是旧 HTML 渲染。

### 现有能力迁移

V1 增加 façade，不批量重写 `/api/runtime` 或删除 legacy API。新 command ownership
表防止插件调用其他插件命令。逐次迁移现有场研究/选型/标准/资料工具后，才讨论
把核心权限管理接入所有兼容 API；当前不宣称卸载核心即能封禁旧入口。

## 下一批研发次序与通过条件

1. 锁定/签署 Plugin Spec 0.1；给建模和报告项目发布独立兼容夹具。
2. 当前本体 FEM 基准通过后扩展安装域：土壤/回填/管道、明确远场/地表边界和域映射。
3. 标准损耗源 + 二维热场的载流量反求；区分电阻来源、解析边界截断、网格误差、能量残差。
4. 与独立解析问题和工程数据交叉验证，不用同一算法自己证明自己。
5. 任务队列、取消/恢复、平台限定原生 worker 包与依赖锁；先 Windows/Linux，再更多平台。
6. 安全分发与企业私有市场，再开放公共上传；签名/撤回/许可/资源隔离先行。

不承诺日历式交付时间；以上逐项以对应测试和真实工件为验收。

## 研发门槛

功能测试/回归、原生库导入、几何有效性/体积、分域网格、解析最大温升误差、
离散能量平衡、三档网格趋势、跨版本源工件拒绝、跨项目下载拒绝。
本批径向问题不是直埋载流量验证，不能用来宣传完整电缆 CAE 或 IEC 认证。
