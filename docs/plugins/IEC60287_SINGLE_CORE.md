# IEC 60287 单芯直埋稳态载流量（cablesim.iec60287）

方法 ID `cablesim.iec60287.single-core-trefoil-buried`，版本 0.1.0。代码在 `plugins/cablesim.iec60287/`，是一个仓库内第一方方法包（架构 D2）。目前**只作为计算库和测试存在，尚未接入宿主研究流程或界面**，接入在 D3 插件化时完成；宿主现有的 `MV-THERMAL-0.1.0` 热网络不受影响。

## 适用范围

| 项 | 支持 | 不支持（明确拒算） |
| --- | --- | --- |
| 电缆 | 单芯、圆形绞合导体、三层绝缘结构、光滑管状金属护套、无铠装 | 分割（Milliken）导体、铜丝屏蔽、皱纹 / 复合护套、铠装、三芯 |
| 排列 | 三根等负荷电缆接触品字形 | 平排、间隔排列、多回路 |
| 敷设 | 均匀土壤直埋；每根一管、管道相切的品字形排管 | 混凝土排管、空气、槽盒、隧道、土壤干燥、外部热源 |
| 接地 | 两端接地（环流，可选计入涡流）；单点接地（涡流） | 交叉互联 |
| 负荷 | 100 % 负荷率稳态 | 周期、应急、暂态 |
| 集肤 / 邻近 | x_s、x_p ≤ 2.8 | x > 2.8 |

使用者必须给出全部物理数据（R20、α、ks、kp、各层热阻率、护套电阻率、管道常数 U/V/Y 等）；本方法没有物理量默认值，也不内置标准表格。

## 计算内容

依据 IEC 60287-1-1:2023 与 60287-2-1:2023（Ed.3.0）：

- 导体在允许温度下的直流电阻、集肤效应 y_s、邻近效应 y_p、交流电阻
- 电容、介质损耗（使用相电压 U0）
- 护套 20 °C 电阻（按平均直径计算的管状截面）、护套电抗、两端接地环流损耗因子 λ1′
- 品字形涡流损耗因子 λ1″（5.3.7.1）；两端接地计入涡流时乘 5.3.6 的系数 F，并按 CIGRE TB 880 Guidance Point 31 推广到非分割导体
- T1（三层同心圆柱之和）；T3（直埋接触品字形乘 1.6，管内电缆乘 1.0）
- T4：直埋可选简化式 ln(2u) 或精确根式 ln(u+√(u²−1))；排管为管内空气、管壁、管外土壤三段之和，管内空气项随平均空气温度迭代
- 载流量：以护套温度（排管时还有管内空气温度）做不动点迭代，直到相邻两次电流差小于容差

每个中间量和每一轮迭代都会输出，同时附带所采用的决策和局限说明。

## 验证证据

| 证据 | 性质 | 结果 | 位置 |
| --- | --- | --- | --- |
| CIGRE TB 880（2022）六个算例：Case 0-1、0-1 精确根式、0-1 单点接地、0-1 GP31 涡流、Case 0-2 排管、0-2 GP31 涡流 | 外部参考算例 | 全部公布的中间量相对误差 ≤ 1e-6（0-2 GP31 中四个只公布到 4 位的量为 2e-4）；载流量误差 ≤ 0.001 A；收敛次数与 TB 880 一致；1e-10 A 高精度重放与公布的十位结果之差 ≤ 1e-9 A（单点接地为 2e-6 A） | `tests/test_iec60287_tb880.py` |
| 合成电缆物理一致性 | 内部一致性 | 收敛后的热阻梯度精确闭合到温度限值；损耗处理、T4 形式、环境参数的变化趋势正确；各类拒算门生效 | `tests/test_iec60287_method.py` |

TB 880 算例数据取自受控 PDF 的逐页转录，存放在仓库外（`reviewStatus=staging`，采购与授权凭据尚未登记）。本仓库是公开仓库，不包含这些数据。本机运行时设置环境变量：

```sh
CABLESIM_TB880_FIXTURES=<含 tb880-case-*.json 的目录> python -m pytest plugins/cablesim.iec60287/tests
```

没有设置时，这些用例在 pytest 中显示为 **skipped**，CI 里也一样。所以 CI 全绿不代表跑过 TB 880 对拍。

以上证据只覆盖所列的六个算例和范围内的分支，不构成标准合规认证，也不是厂家数据验证。TB 880 其余 21 行（混凝土排管、空气、槽盒、铜丝屏蔽、皱纹 / 复合护套、平排、交叉互联、三芯、海缆、直流、暂态等）仍在本方法范围之外。
