# IEC 60287 地下稳态温度与载流量（cablesim.iec60287）

插件的精确包版本与各能力方法版本以 `plugins/cablesim.iec60287/plugin.json` 为准。steady-rating 主契约为 cablesim.domain/1；显式 single-core/1 验证输入改由 reference-rating 能力使用原接触品字形算法（数值版本 0.1.0）。工作台分别提供领域 schema 和 standalone_schema，不将旧三根等负荷模型当作 N 电缆契约。

所有物理计算在插件中执行；宿主只保存和呈现。每个电缆结果保留实体、工况与 SI 单位。目标判定逐回路 / 逐电缆保存，避免相同结果键覆盖其他对象。

## steady-rating 适用范围

| 项目 | 已实现 | 拒算或需补充输入 |
| --- | --- | --- |
| 地下热源 | 任意 N 个不接触圆形电缆 / 管道，各源独立损耗、位置与外径 | 任意接触组合；单回路接触品字形另用标准等效组 |
| 电缆 | 同心单芯圆绞线、光滑管套、无铠装；圆导体独立金属屏蔽三芯SL热路，见下节 | 分割、扇形、铜丝屏蔽、皱纹/复合护套；三芯非磁性铠装与未验证接地分支 |
| 自动电损耗 | 完整平衡三相单回路、等间距品字形或水平 | 多回路、任意排列或不平衡相电流需逐根 ac_extra_factor、lambda1 和 loss_input_source |
| 回路之间 | 耦合全部实际热损耗，以有来源的外部电损耗系数求热平衡 | 未实现通用跨回路电磁求解器；不再套用单回路公式，缺系数时预检拒绝 |
| 排管 | 每根一管、同心、电缆外径 25–100 mm | 多缆共管、偏心、空气经验式范围外、共腔 |
| 土壤 | 恒温地表、均匀原土，或包含全部热源的单个完整地下矩形回填 / 包封区 | 分层、多材料分区、干燥区、外部热源：改用数值热传导 / 有限元 |
| 接地 | 两端接地；品字形和未换位水平单点接地涡流；水平定期换位环流 | 交叉互联；换位水平涡流分支 |
| 数值边界 | 稳态、埋深≤10 m、集肤按5.1.2分段原语；邻近参数 xp≤2.8 | 时变、暂态、超出公式范围：采用专门方法 |

逐电缆电流保存在 load_cases[].currents[cable_id]，优先于回路默认电流。简化热网络遇到逐电缆覆盖会拒算，避免静默忽略。显式损耗模式必须填齐所有电缆及来源，缺失值不视为零。

## 标准依据与逐项测试

采用 IEC 60287-1-1:2023、IEC 60287-2-1:2023（Ed.3.0）：[电损耗标准](https://webstore.iec.ch/en/publication/68118)、[热阻标准](https://webstore.iec.ch/en/publication/68134)。公式核对采用本机受控原文；公开仓库不包含 PDF 或页面扫描。

| 项目 | 条款 | 验证 |
| --- | --- | --- |
| Rdc、集肤、邻近、Rac | 1-1 5.1.2、5.1.5.1 | 原单回路 TB880 中间量；组算法温度 / 电阻迭代 |
| 电容、介质损耗 | 1-1 5.2 | 领域算法 2πε₀ε/ln(Di/dc)，相电压 U₀；历史算法保留原基准常数 |
| 品字形环流 | 1-1 5.3.2 | TB880 0-1 分支 |
| 水平换位 / 未换位环流 | 1-1 5.3.3、5.3.4 式 (8)–(10) | TB880 0-3 三相首轮 λ₁；按相序识别外侧领先 / 滞后，式 (10) 没有系数 2 |
| 未换位水平护套涡流 | 1-1 5.3.7.1(2) | TB880 0-3 单点接地、GP31 变体；逐相涡流与两端接地 F 系数 |
| 介质损耗内部热路 | 1-1 4.2.1 式 (1) | Wd 经过 0.5·T1，T1 包括两侧半导电层；零电流介质发热回归 |
| 自热 / 镜像互热 | 2-1 4.2.2、4.2.3.2 | 两根等深闭式、不等深 / 不等损耗 N 源、互易性 |
| 排管三段 | 2-1 4.2.6.3–4.2.6.5、Table 5 | 独立空气式、管壁对数式、各壁温升闭合 |
| 回填 / 包封 | 2-1 4.2.7、Table 2 | 表节点、双线性内插、共同修正乘总损耗、区域包含边界 |
| 接触品字形 | 2-1 4.2.4.3.2、4.2.6.5 | 标准等效组；直埋 T₃×1.6、管内×1.0；旧显式算法 TB880 回归 |

地表 z=0，电缆深度 L=-z，自热 Rii=rho/(2π)·acosh(Li/ri)，互热 Rij=rho/(2π)·ln(d_image/d_actual)。接收电缆 i 的管外温升为 Σj Rij·Wj；Wj 是源 j 的实际导体、护套与介质总损耗 W/m，不使用平均组负荷。

矩形回填使用 **2023** Table 2，轴为 hb/wb、LG/hb；仅在表内双线性内插。rb=LG/exp(Gb)，C=(rho_earth-rho_fill)/(2π)·acosh(LG/rb)，各矩阵元素为按回填 rho 的基础值加 C。不等负荷修正温升为 C·ΣW，等负荷退化为标准 N·C 热阻修正。这是标准近似的线性叠加延伸，不能视作材料界面的数值场解。

全部电缆 / 管道必须在同一矩形内。表范围外、无法核实的节点、无效等效半径或负修正热阻均拒算，不外推或钳制。受控原文 (hb/wb=3.0, LG/hb=3.0) 节点末位缺损；(0.3,17) 节点有印刷疑点，使用这些节点的插值拒算。

T4′=U/[1+0.1(V+Y·theta_mean)·De_mm]，T4″=rho_duct/(2π)·ln(Douter/Dinner)；T4‴ 使用管外径的土壤矩阵。theta_mean 为电缆表面与管内壁温度均值。算例显式保存 Table 5 的 PVC 系数 U=1.87、V=0.312、Y=0.0037；管材 rho=6.0 K·m/W 来自 Table 1。

导体电阻、各护套电阻、管内空气热阻随温度迭代并返回热平衡残差。逐回路求允许电流时，其他回路保持保存负荷；不平衡显式损耗模式保持相电流比例，返回最大相电流和每相电流。**各回路的独立上限不可同时使用。** 其他回路负荷令本回路零电流时仍超温，则允许电流不可用并给原因，保留真实运行超温结果。多回路目标电流校核须明确 target_circuit_id。

## 工程算例与核对表

“新建研究 → 敷设算例”提供九种输入：单回接触品字形、单回水平、双回品字形、双回水平、品字形排管、2×3 排管、3×3 排管、矩形回填、3×3 包封排管。唯一输入定义位于 design/workbench/scenarios.py；创建独立研究，插件实际运行后才有结果。

110 kV 使用 YJQ02 800 mm² 校核模型：型号系列与导体包络参考厂家资料，其余尺寸及物性为明示假设。10 kV 使用 6/10 kV 240 mm² 校核模型：[Tratos 官方表](https://tratosgroup.com/wp-content/uploads/2020/06/XLPE-Medium-Tension-Cable-mod2.pdf)提供导体参考直径 18.2 mm、绝缘 3.4 mm、R20 0.0754 Ω/km。原产品是铜丝屏蔽，本模型声明采用光滑铝管套，**不是厂家该产品**。现场条件、负荷与导热回填料为设计假设，未冒充测量。混凝土包封算例采用 Table 1 的 1.0 K·m/W 参考值，实际配比需核实。

每次领域运行保存 verification 工件：不读取求解器土壤矩阵，以独立对数式重建自热 / 镜像热阻和内部热路；代入最终损耗核对逐根温度（1e-4 K）；分别核对管内空气与管壁；以最终 Rac、λ₁、空气均温做固定参数二次式允许电流手算（0.001 A）。核对失败则拒绝生成可用结果。

研究“诊断”和计算书列出插件值、手算值、差值、单位、容差及条款。此检查验证热路与最终状态闭合，**不构成独立电磁复算、完整标准认证或现场试验**。

公开测试位于 plugins/cablesim.iec60287/tests/test_iec60287_group.py；真实宿主 / 报告回归位于 tests/test_design_studies.py。受控 TB880 夹具默认从 .data/tb880/fixtures 读取，也可用 CABLESIM_TB880_FIXTURES 指定；不存在时明确 skip。14 项历史测试及领域算法 9 个工况均由同一物理输入运行；参考数值只用于断言，不输入求解器。

载流量分母为 Rc[T1+3(1+λ1)T2+3(1+λ1+λ2)(T3+T4)]；介质温升为Wd[½T1+3(T2+T3+T4)]。T1/Rc/C/Wd按每芯，公开量值中的各项损耗为整缆W/m，trace另存每芯明细。各回路反求时其他回路保持问询目标负荷；同时满足由全部回路的保存工作点与目标判定核对，各独立上限不能同时使用。

验证位于 test_three_core.py：无铠装/钢带/钢丝各有直埋和排管手算二次式，另外覆盖不等回路损耗及缺项门禁。TB880受控摘录 tb880-three-core.json 不入库：Case2 PDF165、175–178核对CLL、T1/T2/T3/T4，钢丝λ2工作点见PDF174；Case10 PDF319–320核对钢带等效厚度与λ2两个分量。已有armoured-sl参考能力继续核对Case2允许电流838.3399739336A。

Case2的630mm²完整链采用旧版TB880的钢丝导体损耗1.5扩展及GP31护套涡流；它超出此IEC2023圆导体钢丝≤400mm²领域分支，不能宣称完整Case2领域链逐项通过。Case10为扇形PILC公共铅套，只有本轮钢带损耗组件对应，不宣称完整PILC热路已支持。公开仓库不包含受控表格或原页。

厂家样本的层厚与外径不能补出铜带纵向电阻、钢带实际间隙、成缆绞距、芯位置及填料牌号。本地华远35–400mm²的20个公开规格仍是缺项资料，尚未转换成完整工程型号；不能据此报推荐截面或客户计算书。新建入口读取study-cable-models中的完整候选版本，保持draft/reviewed状态和内容摘要；三芯模板提供单回、三回水平、三回排管、2×3六回和3×3九回。

TB880:2022 Cases 0-1、0-2、0-3 的 9 个变体覆盖直埋精确 / 简化根式、排管、回填排管、单点接地和涡流。reference_basis=tb880_reference 明示使用原算例的旧版电容常数、矩形半径及 N·C 回填约定；trace 保存基准与结果范围。默认 iec2023 仍使用当前电容常数、2023 Table 2 及 C·ΣW。二者分别验证，不把旧版算例当作 2023 全部公式的数值基准。

IEC 60287-1-1:2023 5.3.1 将单芯金属套环流公式限定为单回路。1-3:2023 处理电气并联的多根电缆，要求共享端电压与总相电流；1-2:2023 只覆盖三相双回水平布置的涡流。当前独立回路输入缺相角、端接和接地拓扑，不能自动满足这些条件。外部损耗系数必须适用于保存负荷与求允许电流所经过的范围；否则应使用专门电磁方法。
