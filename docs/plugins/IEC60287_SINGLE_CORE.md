# IEC 60287 地下稳态温度与载流量（cablesim.iec60287）

插件的精确包版本与各能力方法版本以 `plugins/cablesim.iec60287/plugin.json` 为准。steady-rating 主契约为 cablesim.domain/1；显式 single-core/1 验证输入改由 reference-rating 能力使用原接触品字形算法（数值版本 0.1.0）。工作台分别提供领域 schema 和 standalone_schema，不将旧三根等负荷模型当作 N 电缆契约。

所有物理计算在插件中执行；宿主只保存和呈现。每个电缆结果保留实体、工况与 SI 单位。目标判定逐回路 / 逐电缆保存，避免相同结果键覆盖其他对象。

## steady-rating 适用范围

| 项目 | 已实现 | 拒算或需补充输入 |
| --- | --- | --- |
| 地下热源 | 任意 N 个不接触圆形电缆 / 管道，各源独立损耗、位置与外径 | 任意接触组合；单回路接触品字形另用标准等效组 |
| 电缆 | 同心单芯圆绞线、光滑或明确缓冲/间隙参数的皱纹管套、无铠装；圆导体独立金属屏蔽三芯SL热路，见下节 | 分割、扇形、铜丝屏蔽、复合护套；三芯非磁性铠装与未验证接地分支 |
| 自动电损耗 | 完整平衡三相单回路、等间距品字形或水平 | 多回路、任意排列或不平衡相电流需逐根 ac_extra_factor、lambda1 和 loss_input_source |

| 排管 | 每根一管、同心、电缆外径 25–100 mm | 多缆共管、偏心、空气经验式范围外、共腔 |
| 土壤 | 恒温地表、均匀原土，或包含全部热源的单个完整地下矩形回填 / 包封区 | 分层、多材料分区、干燥区、外部热源：改用数值热传导 / 有限元 |
| 接地 | 两端接地；品字形和未换位水平单点接地涡流；水平定期换位环流 | 交叉互联；换位水平涡流分支 |

逐电缆电流保存在 load_cases[].currents[cable_id]，优先于回路默认电流。简化热网络遇到逐电缆覆盖会拒算，避免静默忽略。显式损耗模式必须填齐所有电缆及来源，缺失值不视为零。

## 皱纹铝护套与缓冲层

领域层 `form=corrugated` 的 `thickness` 为金属壁厚，新增 `corrugation_depth` 为波峰到波谷的径向深度（不含壁厚），`corrugation_pitch` 为轴向节距，两者单位 m。径向包络计入壁厚与波深；单回路模板调用统一的 `CableType.radius()`，同时计入芯内层、公共层和波纹，不再只累加公共层。缺波深/节距时定位到该层具体字段；不能根据简化型号外径猜值。

| 参数/热路 | 依据与受控原文位置 | 实现 |
| --- | --- | --- |
| 平均金属直径 d | IEC60287-1-1:2023 §5.3.2，CMV PDF24/印刷22 | `d=(Doc+Dit)/2`，Doc 为波峰外径，Dit 为波谷内径；平均直径薄壁等效 `Rs20=ρ20/(π d ts)`，温度修正见§5.3.1，铝套ρ20=2.84e-8 Ω·m、α20=0.00403 K⁻¹取表1/PDF40 |
| 环流/涡流 | 1-1 §5.3.2–5.3.7.1，PDF24–29 | 电抗/环流采用 d，涡流的外径采用 `d+ts`（§5.3.7.1注）；不增加无依据的节距电阻修正 |
| T1 | 2-1:2023 §4.1.2.1/4.1.3，PDF14/18 | 各实体环形层相加；缓冲层从绝缘屏蔽到 Dit，间隙等效到平均内径 `d-ts`；材料/有效热阻率必须显式有来源 |
| T3 | 2-1 §4.1.5.1，PDF19–20 | 外覆盖层由平均外径 `d+ts` 积分至实际外径；多种涂敷/护套材料分别按§4.1.3相加；接触品字形的1.6修正保持原条款 |
| 介质发热位置 | 1-1 §4.2.1及串联热平衡 | 原绝缘与半导电热路按½T1；绝缘以外新增缓冲/间隙通过全部Wd，工件另记 `dielectric_path_k_m_w`，不把外部缓冲再取一半 |

`parameters.corrugated_gap[cable_type_id]` 要求 `rho_k_m_w`（K·m/W）、`source`、`geometry_source`。它描述平均直径热路中的有效间隙属性；不自动用实心缓冲带或空气填缺项。支持的层序为导体屏蔽/绝缘/绝缘屏蔽/一个或多个缓冲层/皱纹金属套/可选涂敷层/外护套，缓冲与涂敷使用 `bedding/separator/binder`。`trace.corrugated_sheaths` 保存 Dit、Doc、d、节距、Rs20、缓冲/间隙热阻、介质热路及来源。节距作为几何来源记录；标准平均直径表达式不提供节距经验修正。局部波谷接触、脱离间隙、放电和烧蚀仍需数值插件，不能从本模型推断热点。

起帆公开表 [ZC-YJLW03-Z 64/110 kV 1×800](https://www.qifandl.com/products_detail/c-_detailId=1266420897496969216.html) No.3–11给出导体34mm、屏蔽后36.7mm、绝缘后69.1mm、绝缘屏蔽后71.1mm、缓冲后79.1mm、金属套后91.1mm、成品100.6±3mm和R20≤0.0221Ω/km。计算重建采用各层近似外径之差，区别于名义厚度；缓冲带未压缩的3×2mm不能直接当安装径向6mm。原演示仅列绝缘16mm/铝套2mm/外套4mm、外径78mm，缺屏蔽、缓冲及波纹包络，不能作为原型号完整结构。

城南校核采用声明的工程条件：波谷接触79.1mm缓冲外径，因此波深4mm；节距25mm来自王航等2020附表1的800mm²参考结构，非起帆实测；缓冲带k=0.17、等效均匀间隙采用空气k=0.023 W/(m·K)，引自刘黎等2021表2/PDF3，非起帆有效接触热阻试验。其余材料取上述IEC表值，XLPE ε=2.5/tanδ=0.001。地表25°C、土壤1K·m/W、中心埋深0.8m、两端接地、600A，按100.6mm外径重排接触品字形；原工作区/型号资料不覆盖。

该参考条件下超算作业785281（运行5f5d7354-48b2-4242-9926-6c9fcb8c38da）求得单回路能力748.321974A；d=85.1mm、Rs20=5.311398806e-5Ω/m、T1=0.835430732K·m/W、T3（含接触修正）=0.160496881K·m/W，固定收敛电参数的热平衡手算最大电流差6.61e-6A。不是厂家载流量声明，结论依赖上述工程参考参数，计算书逐项列出。

外部参数验证：王航等《波纹金属护套高压单芯电缆线芯护层互感的解析解》，电工技术学报2020，DOI10.19595/j.cnki.1000-6753.tces.190928，附表1/表1的800mm²波谷内半径37.95mm、波峰外半径45.95mm、壁厚2mm。独立等效圆筒积分 `2e-7 ln((d+ts)/(d-ts))` 得9.537nH/m，与文献近似解末位容差0.0005nH/m一致；这不是完整回路电抗或载流量实测验证。来源原件登记在标准资料目录，原件不入库。测试 `test_corrugated.py` 同时核对起帆各层外径、T1/T3分层对数式、缺项定位以及不伪造节距修正。

矩形回填使用 **2023** Table 2，轴为 hb/wb、LG/hb；仅在表内双线性内插。rb=LG/exp(Gb)，C=(rho_earth-rho_fill)/(2π)·acosh(LG/rb)，各矩阵元素为按回填 rho 的基础值加 C。不等负荷修正温升为 C·ΣW，等负荷退化为标准 N·C 热阻修正。这是标准近似的线性叠加延伸，不能视作材料界面的数值场解。

全部电缆 / 管道必须在同一矩形内。表范围外、无法核实的节点、无效等效半径或负修正热阻均拒算，不外推或钳制。受控原文 (hb/wb=3.0, LG/hb=3.0) 节点末位缺损；(0.3,17) 节点有印刷疑点，使用这些节点的插值拒算。

T4′=U/[1+0.1(V+Y·theta_mean)·De_mm]，T4″=rho_duct/(2π)·ln(Douter/Dinner)；T4‴ 使用管外径的土壤矩阵。theta_mean 为电缆表面与管内壁温度均值。算例显式保存 Table 5 的 PVC 系数 U=1.87、V=0.312、Y=0.0037；管材 rho=6.0 K·m/W 来自 Table 1。

导体电阻、各护套电阻、管内空气热阻随温度迭代并返回热平衡残差。逐回路求允许电流时，其他回路保持保存负荷；不平衡显式损耗模式保持相电流比例，返回最大相电流和每相电流。**各回路的独立上限不可同时使用。** 其他回路负荷令本回路零电流时仍超温，则允许电流不可用并给原因，保留真实运行超温结果。多回路目标电流校核须明确 target_circuit_id。

## 工程算例与核对表

“新建研究 → 敷设算例”提供九种输入：单回接触品字形、单回水平、双回品字形、双回水平、品字形排管、2×3 排管、3×3 排管、矩形回填、3×3 包封排管。唯一输入定义位于 backend/kernel/scenarios.py；创建独立研究，插件实际运行后才有结果。

110 kV 使用 YJQ02 800 mm² 校核模型：型号系列与导体包络参考厂家资料，其余尺寸及物性为明示假设。10 kV 使用 6/10 kV 240 mm² 校核模型：[Tratos 官方表](https://tratosgroup.com/wp-content/uploads/2020/06/XLPE-Medium-Tension-Cable-mod2.pdf)提供导体参考直径 18.2 mm、绝缘 3.4 mm、R20 0.0754 Ω/km。原产品是铜丝屏蔽，本模型声明采用光滑铝管套，**不是厂家该产品**。现场条件、负荷与导热回填料为设计假设，未冒充测量。混凝土包封算例采用 Table 1 的 1.0 K·m/W 参考值，实际配比需核实。

每次领域运行保存 verification 工件：不读取求解器土壤矩阵，以独立对数式重建自热 / 镜像热阻和内部热路；代入最终损耗核对逐根温度（1e-4 K）；分别核对管内空气与管壁；以最终 Rac、λ₁、空气均温做固定参数二次式允许电流手算（0.001 A）。核对失败则拒绝生成可用结果。

研究“诊断”和计算书列出插件值、手算值、差值、单位、容差及条款。此检查验证热路与最终状态闭合，**不构成独立电磁复算、完整标准认证或现场试验**。

公开测试位于 plugins/cablesim.iec60287/tests/test_iec60287_group.py；真实宿主 / 报告回归位于 tests/test_design_studies.py。受控 TB880 夹具默认从 .data/tb880/fixtures 读取，也可用 CABLESIM_TB880_FIXTURES 指定；不存在时明确 skip。14 项历史测试及领域算法 9 个工况均由同一物理输入运行；参考数值只用于断言，不输入求解器。

## 三芯独立铜带屏蔽与磁性铠装

## 交叉热源降额

插件 1.1.0 / steady-rating 方法 1.1.0 增加 IEC 60287-3-3:2007 的固定热源降额。工况参数 `crossing_heat_sources` 可保存多条热源，每条必须给名称、轴线埋深 `depth_m`（m）、外径 `diameter_m`（m）、锐交叉角 `angle_rad`（rad）、整条热源单位长度发热 `heat_w_m`（W/m）与参数出处 `source`。净距由两轴线深度差减两半径推导，接触时拒算；表面温度不能直接替代 W/m。导体材料优先取型号的 `standard_kind`，缺项时要求工程师明确给 `crossing_conductor_material`，不按型号名字推测。

| 条款 | 实现和中间量 | 原文定位 |
| --- | --- | --- |
| §1、§4.1 式（1） | 均匀土壤、等温地表、叠加原理；DF = √[1 − Δθ₀/(Δθmax − Δθd)]，I = I₀ × DF | 印刷 pp.6、8 / PDF pp.8、10 |
| §4.2 式（2）–（9） | 沿电缆纵向的指数衰减热核积分；TL = ρcr/A，Tr = T1+n(T2+T3+T4)，T = T1+n[(1+λ1)T2+(1+λ1+λ2)(T3+T4)]；迭代温升依赖的 γ 与 ΔW | 印刷 pp.8–9 / PDF pp.10–11 |
| §4.2 式（10）–（13） | 自适应区间保证 γΔz < 0.01；终点的未衰减温升 < 0.01 K；同时记录指数尾项温升上界，迭代变化 < 10⁻⁹ K | 印刷 p.9 / PDF p.11 |
| §4.3 式（14）–（16） | 仅交叉位置重合的多个固定热源叠加；未实现纵向错开的最热点搜索 | 印刷 pp.10–11 / PDF pp.12–13 |

领域接入目前限定一根三芯直埋电缆、无回填和土壤分层；固定热源水平、交叉位置重合且不接触。其他几何明确返回 `CROSSING_SCOPE` 与字段路径。§4.4 两条电缆联合重定额、错开交叉点、表面温升反推热量及给定负荷三维温度尚未覆盖。降额分支不生成未校正的二维场图，不把降额前导体温度作为交叉后的温度。降额前电阻、热阻、损耗和核验保存在 `baseline_evidence`，与降额后的能力区分。

工件 `crossing_derating` 保存降额前后 A、无量纲 DF、交叉温升 K、TL/Tr/T、介质温升、迭代行、热源输入、净距、分段和尾项上界及标准条款；结果另提供三个可比较的量 `x-cablesim.iec60287.crossing.baseline_ampacity`、`.derating_factor`、`.temperature_rise`，带显示名称与单位。研究结论、结果对照和计算书均引用保存工件，不在渲染时重算。
