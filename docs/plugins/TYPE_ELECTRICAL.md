# 型号电气参数与短路容量

插件 `cablesim.type-electrical`，两个能力分别保存为宿主研究和不可变运行：`electrical` 与 `short-circuit`。`cablesim.standard-check` 0.1.1 读取独立出厂数据记录；设计参数不会被实测值覆盖。算法只在插件内，页面只展示计算工件。

## 原文与数据口径

- IEC 60287-1-1:2023：交流电阻 §5.1.1–5.1.5（正文16–18 / CMV合订PDF64–66）；电容、介质损耗 §5.2（19 / 67）；温度系数表1（35 / 83）；ks、kp表2（36 / 84）；三芯长度修正附录A（38 / 86）。
- IEC 60287-1-3:2023：导体几何感抗从 §4.2 式(9)及表1的等距平衡回路导出（10 / 36）。这只是导体几何项，不包含护套环流、大地返回或完整序阻抗。
- IEC 60949:1988：第2、3章（9 / 摘录PDF3），第5章（11、13 / 4、5），第6章（13、15 / 5、6），材料表I、II（17 / 7），导体非绝热表III（19 / 8）。铜 `K=226 A√s/mm²`、`β=234.5 K`；铝148/228；铅41/230。XLPE导体的表III铜X/Y为0.41/0.12，铝为0.57/0.16。
- AMD1:2008第4章补充：并联屏蔽、护套、铠装的电流分配与初始温度分别确定，不能累加单个组件最大容量。

60949来源是公开可读的原始英文页图摘录，按原貌封装；不是完整双语出版物。官方预览、英文摘录和修订文本三份均登记在标准库的《标准题录与数据用途.md》，并附入Zotero；SHA256见插件 `sources.json`。全文仅保留受控资料库及`.data`，不提交Git。

运行参数用SI：温度K、时间s、中心距m、相电压V。界面显示°C、mm、kV。每个方法参数都带条款、报告或明确的计算条件；空来源保持缺项。运行相电压不从型号U₀推断。R20的数据性质与每米成品电缆/直线线芯的长度基准分别明确，避免三芯绞入系数重复计入。

## 短路容量手工核对

结果页先展示结论与保存的计算条件。输入、出厂数据或方法变更后标为历史；三芯结构、实测记录和输出完全相同时合并为“芯 1–3（相同）”，不同芯分别显示。电流显示三位有效数字、修正因数三位小数，完整精度保留在右侧依据栏与运行工件。

短路工件包含 `cablesim.short-circuit-curve/1`：0.1–5 s 对数采样、当前计算时间及最多20个用户关注时间点。每个曲线点由插件的同一个绝热/非绝热分支计算；页面不按时间缩放已有电流。缺少输入的组件保留空采样，不插值补造结果；图域外的当前计算时间单独说明。0.25 s、4 s 曲线点同时与独立45位 Decimal 手算对拍。

以下三例取共同的**手算条件**：铜导体90°C初始、250°C最终、1s；不是厂家短路试验，也不证明厂家批准该最终温度。`I_AD=226 S√ln[(250+234.5)/(90+234.5)]`；XLPE非绝热`ε=√[1+0.41√(1/S)+0.12/S]`；`I=εI_AD`，S以mm²计。独立45位Decimal算术与插件双精度对拍。

| 型号 | 公开标称导体截面 / mm² | 绝热 I_AD / kA | 非绝热 ε | 非绝热 I / kA | 金属组件 |
| --- | ---: | ---: | ---: | ---: | --- |
| 江南10kV 3×240 | 每芯240 | 每芯34.34004160 | 1.0133930068 | 每芯34.79995801 | 缺截面、构造及初末温度；待补 |
| 江南35kV 3×240 | 每芯240 | 每芯34.34004160 | 1.0133930068 | 每芯34.79995801 | 缺截面、构造及初末温度；待补 |
| 起帆110kV 1×800 | 800 | 114.46680533 | 1.0072962270 | 115.30198113 | 缺铝套厚度/截面及初末温度；待补 |

导体容量不按芯数相加。金属组件§6.1修正需要各侧介质的热阻率、体积热容和热接触因数；隔离丝§5.3.1按**单丝面积**算ε，容量再乘丝数，只在明确完全嵌入且间隙至少一个丝径时开放。其他铜丝接触分支、纵包搭盖不明确的铜带，以及多个并联金属组件的总容量保留未覆盖。

## 出厂数据与拓扑

领域文档 `measurements[]` 存放稳定ID、型号/线芯/层角色、量、SI值与单位、实测或厂家声明性质、报告/样品编号。相同对象同一量只留一个当前记录；旧记录保留在工程修订和运行快照。最薄点和最大厚度只有同一报告/样品出处才计算均匀性。设计R20与记录R20分开展示；标准上限仍由标准插件确定。屏蔽截面有数据也不自动生成不存在的故障电流要求或合格判定。

复用[接地拓扑契约](../architecture/electrical-topology.md)的 `circuits[].electrical_topology`、`bonding`及来源，在工件和快照中追溯；方法页只选回路，不建另一套相序/接地字段。完整金属回路阻抗及大地返回的求解尚未实现，对应行保留未覆盖。

## 验证与范围

`tests/test_type_electrical.py`覆盖TB880中间量、电容/充电电流/介质损耗与导体几何电感的独立手算、三个真实型号的缺项与短路手算、时间曲线、长度基准、适用范围拒算、来源/单位、出厂数据判定、隔离执行、快照与重复请求。`tests/browser/type-rating.cjs`覆盖新的合并结果、完整精度、关注时间点及键盘交互，并验证[型号载流量表](TYPE_RATING_TABLE.md)。浏览器流程调用实际API；超时、崩溃与环境缺失的页面检查采用注入响应，实际进程故障和超时由宿主测试核验。
