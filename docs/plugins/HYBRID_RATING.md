# 混合载流量与物理对比

插件输入为 SI 领域文档 `cablesim.domain/1`。宿主保存研究、方法发行锁、不可变输入、运行和工件；计算与修正模型均由插件提供。项目书用于研究参考，不把旧阶段指标、企业样本数量或结构数量当作当前产品验收结论。全部结果为 `reference_only`，不自动批准工程使用。

## 能力

|能力|用途|执行位置|
|---|---|---|
|`physics-comparison`|同一保存工况的 IEC、FEM 和分层解析参照；电流、温度、损耗及三网格证据|Slurm dg83|
|`training-sample`|带输入、网格、能量及方法来源的 FEM 标签|Slurm dg83|
|`train-model`|XGBoost、MLP、GP 比较、独立划分与区间校准|Slurm dg83 CPU|
|`steady-rating`|已登记模型的 IEC 基线加修正，含适用域拒绝|宿主 CPU 常驻工作进程|

原生求解、训练和数值性能测量均在超算执行。本机仅准备输入、开发、轻量测试及浏览器验证；缺少远端环境时不回退求解。

当前模型冻结为 `reference_only`；不继续扩充训练集或追逐页面 1 秒指标。研究中的通用截面对比使用仿真插件 `iec-fem-comparison`，见 [仿真插件](SIMULATION.md)，不受这里的双回特征域约束。

## 标签物理与数值门禁

热场模式为二维常热物性 FEM，含线性 R(T)。交流/护套损耗因子和排管空气热阻冻结在 IEC 额定点。双回给定损耗系数场景是独立热路子模型，不能宣称为电磁计算。

电磁热模式显式选择 `physics=electromagnetic_thermal`，由 GetDP A-u 与 P1 热场重算点态 σ(T)、导体集肤/邻近效应及护套感应/环流损耗。当前限定均匀土壤直埋圆形单芯研究结构、已声明相序和接地。绞合导体明确均质化为保持原 R20 的实心圆柱：ρ20=R20·πd²/4，不能以标称截面替代几何面积。材料设为非磁性，电阻率温度有效域253.15–423.15 K；不覆盖三维绞线、接地极阻抗和土壤回流。

返回温度、磁场和热源属于同一个收敛迭代状态；固定介质热源另计并保留总能量平衡。埋地标签禁止全局原点径向增长场覆盖局部网格：`electromagnetic_mesh.exterior_growth_start_m` 必须省略或为 null。页面的电磁热默认网格为局部0.5 mm、远场0.3 m、过渡距离2 m、圆周最少128段；仍逐工况执行三档收敛检查，不把默认参数当作收敛保证。

分层土壤保留实际分层 FEM。均匀土壤 IEC 是明确标记的反事实对照与残差学习基线，不是实际分层标准结果。另附两层半空间解析研究参照：IEC 内部热阻/电损耗模型，加自行推导的傅里叶界面反射 Green 矩阵。公开方法背景为 [Slaninka & Morgan, 1992](https://doi.org/10.1049/ip-a-3.1992.0021) 和 [Morgan & Slaninka, 1994](https://doi.org/10.1016/0378-7796(94)90046-9)。级数为独立推导，并用直接傅里叶积分校验，不声称逐式摘录论文。

解析参照限定两水平土层、地表等温、同一层内同埋深线源，满足温度与热流连续。电缆跨界面、叠加回填/管道或级数未收敛时明确未覆盖，FEM 工件仍保留。均匀极限与半空间热阻手算对拍；非均匀上下层分别与独立积分对拍。

每条有效新标签需三档网格，末两档最大温度变化≤0.1 K、载流量变化≤0.5 A，能量相对残差≤10⁻⁶。自适应电流括根受显式最大电流约束；不稳定试探不能成为额定值。旧失败输入以新计划修复并保留原失败行/输入摘要。`domain_status=not_assessed` 表示尚未逐工况验证外域边界。

## 数据、训练与预测

现有采样范围为埋深0.6–2.0 m、土壤热阻率0.5–2.5 K·m/W、地温−10至40°C；分层另采样界面深度与下层热阻率。独立外推埋深2.6–3.0 m。240/400 mm²是两种研究结构，不代表企业产品覆盖率。

`cablesim.hybrid-features/2` 含24个特征。模型学习 `I_FEM/I_IEC` 及运行温度残差。按结构分开划分60%拟合、10%调优、10%校准、20%验证；外推集独立。结构、相序/接地、未采样参数、方法系数或域外输入变化均拒绝。旧特征版本模型保留来源，不能由新契约直接执行。

XGBoost仅用调优集早停，MLP在拟合子集内部早停，GP用确定性最多800条拟合样本。有限数值 JSON 导出与原库预测对拍，不使用 pickle。Split conformal 给出两量各自的95%边际预测区间，不表示联合95%或现场覆盖保证。温度误差用 K 解释。

模型按字节 SHA256 登记在 `.data/method-models/`。训练包保留划分、数据/输入/工件摘要、环境、Slurm 作业、误差、覆盖率与实测验证状态。失败或未配对标签不训练，相同物理输入和重试副本不跨集合泄漏。

```sh
python plugins/cablesim.hybrid-rating/validation/prepare_batches.py --family layered_soil --samples 40
python -m backend.kernel.batch_cli submit <数据集目录>
python plugins/cablesim.hybrid-rating/validation/train_model.py <域内目录> <外推目录> --profile .data/hpc/hybrid-training-profile.json --model-version <版本> --output <证据目录>
```

批次按[批量数据集契约](../architecture/BATCH_DATASETS.md)封存及记账。训练输出目录绑定同一数据/参数，恢复复用原操作身份。训练库只需装在超算环境，预测宿主不依赖机器学习运行库。

`plugins/cablesim.hybrid-rating/validation/training_input.py` 是 `train_model.py` 调用的输入组装模块：核验逐条批量工件、来源哈希和训练划分。`plugins/cablesim.hybrid-rating/validation/register_model.py` 是训练完成后的登记模块：校验 Slurm 产物并以哈希保存至模型目录；两者不是独立 CLI，均不批准工程使用。

## 页面与执行

混合载流量页编辑训练覆盖的工况、选择准确模型版本、显示 IEC 对照、修正值及区间；分层页另有界面深度和下层热阻率。方法对比页的“输入差异”可采用热传导/分层或 GetDP 电磁热配置，保存后提交超算。结果、运行损耗、三网格、条款和固定摘要来自保存工件。连接中断可恢复原超算运行。

预测 POST 执行权威预检并复核保存研究返回的发行锁，界面无需再提前执行一次相同预检。成功 POST 返回校验后的保存结果，直接更新查询。常驻进程按入口字节和发行摘要隔离；模型每次仍读取并校验完整字节哈希，只缓存两个解析包。依赖校验仅缓存相同源码字节的导入语法，每次重新发现文件绑定并核对字节摘要。

页面耗时与 Slurm 已加载模型 CPU 耗时分别报告。界面继承现有 tokens 和表格；概念图在 `.data/hybrid/physics/`，采用 `concept-comparison-table.png` 的单表结构。生图只用于方向，不作为计算证据或界面底图。

```sh
npm --prefix frontend run test:hybrid
npm --prefix frontend run test:physics-comparison
```

浏览器脚本需先构建、已有真实模型及可用超算；使用独立临时数据库并清理自建浏览器和服务。分层预测可设置 `HYBRID_FAMILY=layered_soil`。覆盖空、加载、错误、成功、历史、重复点击、键盘、保存、域外拒绝与1366×768/1920×1080布局。

## 公开实测与交换

公开来源：[Verschaffel-Drefke 等，2021，真实尺度地下电缆散热试验附属数据](https://doi.org/10.48328/tudatalib-665)，许可 CC-BY-NC-4.0。XLSX、来源记录、标准资料副本与 Zotero 附件按哈希登记；项目工作副本在 `.data/hybrid/field-data/`，不入库，也未用于上述训练。

`GET /api/measurement-input-contract` 提供 `cablesim.field-measurements/1`：时间s、电流A、温度K、原文件SHA256、许可、工作表/列映射、原始行号、传感器位置、结构和可选领域输入。时间严格递增，通道身份唯一；缺电流、结构或传感器对应关系不能生成验证误差。护套、管道和环境温度不能当作导体峰值。

参考稳态筛选为电流变化<5%、温度趋势<1 K/h、持续≥7200 s，筛选及剔除原因随数据保存。导入契约及公开文件可用，不等于已完成独立实测精度验证。

CableLab交换数字模型包、SI特征、模型/数据/输入/结果摘要、校准报告和独立权限状态。其 GB_TABLE 正式标准表是另一条链，不能仅按截面或载流量映射为 IEC；当前未改写其正式模型库。工程发布仍需独立验证和人工批准。
