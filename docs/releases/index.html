发布说明

当前版本包含的功能，以及最近一轮更新的内容。

当前为开发中的版本，宿主版本号 0.1.0 系列，工程输入格式第 1 版（cablesim.domain/1）。在软件“设置 → 关于”中可以看到宿主版本、输入格式，发行包的 /api/release-info 还会返回构建编号和源码提交。各计算插件的版本见方法清单。

最近一轮更新

离线安装包自带 Agent 对话（#68）

  • 安装包带有固定版本的官方 Node.js 24.22.3 和 Agent 对话服务，安装和运行都不需要联网，也不需要系统中预装 Node.js 或 npm。
  • release.toml 新增 [agent] 一节：enabled（默认 true）、port（默认 8111）。
  • 对话服务只监听本机，拿不到任何模型密钥；没有启动成功时，工作台其余功能照常可用。
  • 模型只需配置一处，优先顺序为“设置 → AI 模型” > release.toml [model] / CABLESIM_LLM_* > CABLE_STUDIO_MODEL_*。
  • 回退到不含 Agent 的旧版本前，须先从 release.toml 删除 [agent] 一节。

详见 Agent 对话服务。

Agent 对话接入工作台（#63）

  • 工作台内的 Agent 对话：读取工程、研究、型号与运行结果；每一次建立、修改、运行和导出都是固定内容的提案，须由人在对话中接受后执行。
  • 对话中建立研究、重算与对比、编制载流量表、核对型号并生成计算书和规格书；计算书与规格书经正式交付服务输出，含四个签栏和追溯页。
  • 对话中导入厂家结构表：上传原件、保存预览、草稿入库、标准核对四步，逐步人工接受。
  • 长对话自动压缩；上下文窗口与最大输出在“设置 → AI 模型”中设置。

工作台四条主线（#67）

  • 载流量研究、型号设计、资源库、仿真四条主线可以完整地用鼠标和键盘操作。
  • 研究页直接导出正式交付文件（PDF / Excel）：固定保存来源，人工填写文件编号与版次，保留四个签栏。
  • 查看已保存的选型运行时，所选候选与其运行、工况一起固定，结果、布置图、模型和返回操作都对应同一候选；保存的结构只读，右侧当前草稿与撤销保持独立。
  • “电缆型号版本”页新增“导入厂家结构表”（XLS / XLSX / CSV，五步向导）和“提取厂家 PDF”两个入口。
  • 型号设计中标准核对运行失败时，显示该次运行的实际错误和缺失字段的位置。
  • 资源编辑器支持“文献资料”来源；宿主新增密度、电阻率、体积热容和无量纲四类物理量。

温度收敛容差按温差显示（#65）

迭代计算的温度收敛容差是温差，现在以 K 显示和输入（此前误按绝对温度显示为带 −273.15 偏移的 °C）。初始温度、环境温度等绝对温度仍以 °C 显示。计算本身不受影响。涉及的插件发行：

插件新发行
电缆有限元仿真（cablesim.simulation）1.7.2
IEC 60287 载流量（cablesim.iec60287）1.2.1
混合载流量研究（cablesim.hybrid-rating）1.1.1
COMSOL 参考对照（cablesim.comsol-bridge）1.0.4

正式交付文件的显示规则（#66）

显示政策升级为 cablesim.engineering-display/2：

  • 热阻率、热阻等含温差的复合单位按 IEC 60287 写 K：K·m/W、W/(m·K)、J/(kg·K)、J/(m³·K)；绝对温度（°C）和温度系数（1/°C）不变。
  • 正文不用 E 记数法：电容写 μF/km，电感写 mH/km，电阻率写 Ω·mm²/m，其余数值写普通小数。
  • 规格书正文只列结构尺寸和每公里用料；建模长度、模型体积和材料密度移到追溯章节。

详见正式交付文件。

收尾修正（#70）

  • 标准依据库尚未收录的条款统一显示“本库暂未收录”。标准核对插件发行 1.8.7，方法版本 1.8.5 不变，判定不变。
  • 插件发行只改参数的显示单位、换算比例或偏移（SI 单位不变）时，属于展示变化，不再使已保存的结果变为历史结果；#65 改正温度容差显示后，已保存的有限元与电热耦合运行仍为当前结果。见升级后已保存的结果是否仍然有效。
  • 修约进位到更高一位数量级时，按新的数量级保留四位有效数字，例如 9.99995 Ω/km 显示为 10.00；安装包附带的校验程序按同一规则核对。
  • 资源编辑器可以录入长度、面积、温度、温差、线电阻、热阻率、热导率、电流、频率、密度、电阻率、体积热容和无量纲参数。

本版本包含

安装与运行

  • Windows 10 / 11 x64 与 Linux x86_64 离线安装包：自带 Python 3.12 运行时、Node.js 运行时和全部依赖，安装与计算全程离线，不需要管理员权限。
  • 升级前自动快照工程库，健康检查失败自动恢复；支持回退到上一版本。
  • 工程库备份与恢复（界面、命令行与接口）。

电缆型号

  • 厂家结构表导入：XLS / XLSX / CSV，工作表选择、列映射保存与复用、系列声明、逐行预览与逐项来源，人工确认后入库。填写系列声明时即检查同名系列，入库报错显示在对应按钮旁。
  • 厂家 PDF 资料提取：逐页识别参数，保留页码与原文位置，候选值经人工逐项核对。
  • 型号系列：批量标准核对、批量载流量计算、批量审核和独立改版；批量操作的结果显示在工具栏下方。
  • 公开样本对照：各规格共用的说明在表格上方只写一次。
  • 部件与研究模板：把已保存型号的部件或成功运行的研究定义冻结为参考草稿，人工确认后采用到另一个工程；冻结证据按工程单位显示。
  • 型号设计：结构、执行标准、标准尺寸核对、电气参数、短路容量、载流量表、规格书的生成、评审与发布。

载流量与仿真

  • IEC 60287 稳态载流量：多回路直埋、排管与矩形回填，单芯与独立屏蔽三芯，护套与铠装损耗，交叉热源降额。
  • GB 50217 附录 D 载流量校正；简化热网络交叉校核。
  • 有限元温度场、暂态、护套损耗与电热耦合（Slurm 超算），与 IEC 的对照及收敛证据。
  • 运行记录、两次运行对比、参数扫描、问询选型。

交付

  • 计算书、规格书、载流量表和研究报告的正式交付文件：固定来源预览，PDF / Excel 导出，四个签栏与追溯章节，支持按工程或系列批量导出。
  • 研究页和型号设计页直接导出，也可以经正式交付接口集成。

Agent

  • 工作台内的 Agent 对话，接入 OpenAI 兼容接口的模型，包括内网私有化部署的模型。
  • 离线安装包自带 Agent 对话服务。
