# 目标电流问询选型

J4复用研究的领域截面、负荷和方法配置，在`StudyDefinition.modules.selection`中保存候选范围。宿主只展开完整候选输入和整理插件输出，不按截面积外推。界面入口为研究的“问询选型”；新建研究也可以直接选择“客户问询选型”。

## 型号版本

`GET/POST /api/domain-cable-models`保存不可变的`name/version/cable_type/materials/sources/confirmed`。结构和材料采用`cablesim.domain/1`的SI类型；电压为V、截面为m²、尺寸为m、R20为Ω/m、温度为K。型号引用的全部材料必须存在，来源必须有出处。只有工程师明确确认且来源均已核对、没有演示来源、具备R20时，版本才标为`reviewed`。默认保存草稿；导入文件中的`confirmed`不会自动确认界面导入。相同内容摘要的重试返回同一版本ID，不重复入库。

公开样本未形成完整模型时，同一 API 接受 `specification`，此时 `cable_type=null`、材料可为空，状态固定为 `incomplete`。规格记录厂家、型号、U0/U（V）、芯数、截面（m²）、导体材料；每个公开值保存 `value/unit/basis/source`，`basis`区分厂家值、标准标称值和标准上限，`source`引用带网址、版本/表号/页码及原文SHA256的来源键；`missing`列出具体缺项。数值与单位验证，禁止布尔值、负数、越界值及不存在的来源键。资料版本可参加范围筛选，但预检只保存缺项拒绝，绝不沿用工程当前型号代替候选；补齐后需保存独立完整版本。不能将其确认为`reviewed`。

`DELETE /api/domain-cable-models/{id}?expected_digest=...`仅清理摘要准确且从未被任何研究版本或运行引用的草稿/资料版本，已核对版本和历史引用一律保留。型号页的结构编辑和发布流程保持由型号模块管理。

界面“导入型号版本”接受上述JSON，显示型号、版本、单位换算和出处后由工程师确认。版本保存在选型型号库，历史运行继续引用自己的原始候选快照和SHA256。它不批准研究方案，也不替代型号结构设计的发布流程。

## 完整输入与判定

`driver.minimum`为每回路目标电流A，必须为正数；`candidate_filters`按电压、导体材料及截面上下限筛选。默认仅列已核对型号；显式使用草稿演示时，页面和计算书禁止给出工程推荐。混合型号线路的替换范围尚未覆盖，明确拒绝。

预检前引用研究当前的稳态方法及完整参数，所有回路负荷改为保存的问询目标。每个候选替换完整`CableType`和所用材料，保留敷设、边界、工况及手动锁定；型号绑定产生的结构锁只对本次候选实验解除。每个候选独立调用插件，并保存准备输入摘要、方法清单及插件精确版本。

所有指定回路的允许电流均可用时，采用其最小值，余量为允许电流减目标电流。满足/不满足按余量符号判定；方法范围拒绝保存为`not_applicable`，求解失败保存为`failed`，均不进入合格列表。插件明确报告无正载流量时标不满足，不编造0 A结果。无适用候选时只保存拒绝记录，不调用数值执行阶段。

页面先显示“推荐型号，允许电流，余量百分比（满足的最小截面）”，紧邻生成客户计算书按钮。候选按满足、不满足、不适用分组，各组按截面升序；不适用默认折叠，求解失败单独保留。推荐限已核对且满足目标的最小截面，同截面按余量排序，显式草稿研究不生成工程推荐。超温原因引用插件已保存的运行温度和温限，不能从允许电流外推温度。报告结论在输入及依据之前，包含每个候选的状态、限制、余量、方法版本、来源和摘要。结论仍须工程师复核，不自动批准。

厂家的单回路参考载流量不代替多回路排管计算。IEC 领域映射现支持完整输入的圆形三芯、逐芯屏蔽、磁性钢带或钢丝铠装电缆；热路、电损耗和验证范围见[IEC 方法说明](../plugins/IEC60287_SINGLE_CORE.md)。铜带屏蔽必须提供成缆后纵向 R20 和芯绞节距，填充材料与钢带间隙必须有明确事实，不能用屏蔽带截面积或成品外径反推。现存公开 10 kV 规格缺少上述事实，继续保存具体缺项，不生成推荐。

新建问询直接保存每回路目标电流、候选版本摘要和敷设模板，不再要求先进入单回路页面改负荷。研究专用 `GET /api/design/study-cable-models` 包含可运行的完整版本；`incomplete` 规格只进入选型候选缺项列表，型号页接口保持独立。绑定只引用电缆实际使用的材料，土壤和排管材料由敷设条件管理。三芯模板为直埋单回、水平三回、水平三管、2×3 管群及 3×3 管群，每回路恰好一根三芯电缆、每管一缆；模板工况来源为演示，需工程师换成项目事实。

显式选择草稿候选只允许数值校核，不能把草稿批准为已核对型号。110 kV YJLW03 规格缺导体直径或成品外径时，型号 API 的 `display_status` 为“厂家尺寸缺”；该状态不改变不可变资料摘要。

浏览器场景脚本为 `tests/browser/three-core-inquiry.js`，通过 BrowserOS neo 的 snapshot/ref 与可信鼠标事件驱动新建、输入、预检、运行和实际下载；使用隔离数据库中的三份显式手算草稿，不能把这一流程耗时登记为真实厂家候选验收。脚本记录全部十次操作，下载完成才停止计时。计算书展示每芯 Rc/T1、整缆 T2/T3、λ1/λ2 与逐芯损耗，电缆整缆损耗为三个芯之和。

## 失败与历史

输入校验失败定位具体字段；后端资料校验返回文件内字段路径。运行请求使用UUID，运行期间屏蔽重复操作；连接中断时保留保存输入和请求ID，刷新后可重试同一请求读取服务端保存状态。超时、崩溃和环境缺失沿用通用插件执行状态，不将失败候选当作不满足或成功。历史快照只读，变更后的输入必须重算，当前计算书不能引用旧输入。

IEC多回路电磁边界、外部λ工件及拓扑见[接地拓扑](electrical-topology.md)；温度场报告还受[收敛门禁](temperature-field.md)约束。
