# 0.4.1 统一研究域与交付边界

本版从 `feat/cable-design-v04` 的 OCR/Agent、企业资料、选型和三类场分析出发，复用 `feat/design-ocr-v04` 的竖向有限体积模型。没有把两套企业资料或 API Key 系统重复集成。统一入口为顶部“场分析”和“反向选型”。

## 四类研究不冒充全耦合仿真

1. 直埋载流量：原稳态三相互热网络；限均匀土壤和单回路相同单芯电缆。
2. 土壤二维温度场：五点有限差分求解，损耗和边界来自既有解析/热网络；显示残差、净热流、网格对照。不反向修正载流量。
3. 绝缘电场和外部磁场：分别为均匀同轴介质静电解析与平衡三相无限长直导体相量解析。不是缺陷、屏蔽涡流、介质老化或电磁兼容校核。
4. 竖向电热：单根隔离电缆的轴向有限体积 + 四径向节点，求得沿高导体/屏蔽/护套温度、允许载流量、损耗、热点和能量平衡。

“垂向”作为电缆专业垂直领域不改变敷设物理；本版同时提供实际竖向空气模型，但不含井道气流或烟囱效应。不要把单根隔离结果用于紧密成束、封闭井道或未知通风条件。

## 竖向方程、单位和边界

每个轴向控制体宽度 dz=H/N。径向导热支路 G=1/T，T 单位 K·m/W；节点方程按单位长度热功率 W/m 建立。

导体轴向散热项：k_c A_c (2θ_i−θ_{i−1}−θ_{i+1})/dz²。两端采用零轴向热通量；只对真实存在的邻接面装配。只计导体轴向导热，未计金属屏蔽轴向热传导。

导体热源：I² R20 (1+交流附加系数) [1+α(θ_c−20)]。介质损耗放在绝缘中点等效节点，屏蔽损耗 λ I² R_ac(θ_c) 放在外金属节点。

外护套散热：πD {h(θ_s−θ_a)+εσ[(θ_s+273.15)^4−(θ_a+273.15)^4]}。外界辐射温度假设等于当地空气温度；θ_a 沿高线性插值，h、ε 是输入。k_c 暂按铜400、铝235 W/(m·K) 的工程假设，需厂家/实测校核。

Newton + 线搜索解非线性节点方程，稀疏线性求解；检查有限数值、残差、温度反馈稳定分支；高于200°C或无有效分支时不外推运行温度。对电流二分搜索直到温度极限，验证最热导体达到允许上限。热点高度是控制体中心，不是连续空间的精确极值。粗细网格对照显示载流量相对差异，但不构成外部工程认证。

数值回归含：零电流、均匀边界无辐射闭式退化解（包含屏蔽和介质热源）、非均匀轴向热平衡、20/80网格比较、对流单调性和过载拒绝。

## 反向选型的研究域

`domain=buried` 使用既有三相直埋求解；损耗是三相整段kW、采购估算是3×线路长度×单芯每米价。

`domain=vertical_air` 必须显式给出 Vertical 边界，不能默认从土壤猜测空气条件；每个候选完整电缆重新调用竖向模型。此域损耗是单根全高kW、采购估算是高度×单芯每米价。两个域的总量不能直接横比。

所有选型默认不使用演示条目。遵守目标/预留、导体、外径、声明U0、温度上限和锁条件。不提供价格的型号不参与成本排序。竖向单次最多40候选，不静默取前40。

竖向候选审批 `action=import` 只修改电缆定义并保留研究引用，绝不自动调用直埋F9。主工作区仍保存一个合法直埋底图，若其间距与新电缆重叠，送审会明确拒绝直接应用；竖向研究结果仍有效保存，不把底图几何限制用于拒绝独立空气研究。尚不是多研究域统一CAD数据模型。

改变选型表单中的目标、边界或研究域立即禁止应用旧候选。每份记录绑定工程版本、边界配置与SHA-256。资料来源采用页校对、准确原文引用与参数提案审批；识别并不等于厂家认证。
