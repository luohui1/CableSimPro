# 计算方法 · MV-THERMAL-0.1.0

## 1. 身份与范围

本内核是可审计的稳态热网络 Demo，而非完整 IEC 60287 实现。标准目录仅用于说明稳态损耗和热阻问题的范围，不表示本仓库包含标准全文、逐条实现或已通过合规验证。

范围参考：
- IEC 60287-1-1:2023，稳态载流量及损耗：https://webstore.iec.ch/en/publication/68118
- IEC 60287-2-1:2023，热阻：https://webstore.iec.ch/en/publication/68134

适用几何：单回路、三根相同单芯无铠装电缆；同心层；水平或等边三角排列。介质为无限横向延伸的均匀土壤，地表为恒定环境温度，轴向无限长近似。三相承受相同有效值电流，但因散热位置不同，温度及电阻逐相求解。

不支持排管、空气敷设、回填分区、干燥带、多回路、铠装、外热源、接头及端部、谐波、暂态、循环与应急负荷。U₀ 和绝缘尺寸的组合不进行电气强度或绝缘配合校核。

## 2. 输入与单位

| 量 | 接口单位 | 内核单位 / 含义 |
|---|---|---|
| 导体截面积 A | mm² | 金属面积，不是包络面积 |
| 层厚与半径 | mm | 进入内核时转为 m |
| 埋深、间距、线路长度 | m | 埋深为三相中心的平均深度 |
| 导体 R₂₀ | Ω/km | 除以 1000 后为 Ω/m |
| 热阻率 ρth | K·m/W | 材料热导率的倒数 |
| 每单位长度热阻 T、G、H | K·m/W | 乘以 W/m 得温升 K |
| 电压 U₀ | kV | 相对地 RMS，不是线间电压 |
| 电流 I | A | 三相平衡 RMS 电流 |
| 损耗 q | W/m | 每根电缆每单位轴向长度 |
| 温度 | °C | 温差数值等同 K |
| 线路损耗 | kW | 三相损耗总和乘以线路长度并除以 1000 |

导体填充系数 f 只用于包络几何：`r0 = sqrt(A / (π f))`，此式中半径单位为 mm。导体屏蔽、绝缘、绝缘屏蔽、金属屏蔽、外护套依次叠加得到 r1…r5。金属层为连续等效铜圆筒，并不重现实际铜丝间隙或接触热阻。

水平坐标为 (-s,h)、(0,h)、(s,h)。三角坐标为 (0,h-s/√3)、(-s/2,h+s/(2√3))、(s/2,h+s/(2√3))。界面与后端采用相同约定。

本近似要求每相中心到地表深度不小于外半径的 10 倍，并拒绝中心间距小于外径的重叠模型。输入不合格时返回错误，不静默修正为默认值。

## 3. 导体与介质损耗

未指定厂家 R₂₀ 时，按理想导体估计：

```text
R20 [Ω/m] = ρ20 [Ω·mm²/m] / A [mm²]
ρ20,Cu = 0.017241; ρ20,Al = 0.028264
αCu = 0.00393 /K; αAl = 0.00403 /K
R20,AC = R20 (1 + kAC)
RAC(θ) = R20,AC [1 + α(θ - 20)]
qc,i = I² RAC(θi)
qs,i = λ qc,i
```

这些数值是可审查的演示常数，不是所有合金、绞合形式和温区的认证材料模型。未计绞合增量。厂家 R₂₀ 非空时，以厂家输入为准；随后改变面积不会覆盖该电阻输入。

kAC 为用户输入的交流附加系数，λ 为用户输入的屏蔽损耗比。**没有自动集肤/邻近效应、屏蔽环流、接地方式或交叉互联求解**。实际值须由独立方法确定。

```text
C [F/m] = 2π ε0 εr / ln(r2/r1)
ε0 = 8.8541878128 × 10^-12 F/m
wd [W/m] = 2π f C U0² tanδ
```

C 的输出转换为 nF/km 时乘以 10^12。U₀ 在上述公式中使用 V。

## 4. 热阻与三相耦合

五个径向层热阻（内核从 0 开始索引）：

```text
Tk = ρth,k ln(rk+1/rk) / (2π)
```

半导电层、XLPE 和护套热阻率来自输入；金属等效层使用热导率 400 W/(m·K) 的演示假设。忽略导体内部径向温差，将导体视为等温节点。

均匀半空间土壤热阻矩阵 G：

```text
Gii = ρsoil acosh(hi/r5) / (2π)
Gij = ρsoil ln(Dimage,ij / Dij) / (2π), i != j
Dij = sqrt((xi-xj)² + (hi-hj)²)
Dimage,ij = sqrt((xi-xj)² + (hi+hj)²)
```

屏蔽损耗集中在金属屏蔽外侧节点，介质损耗在绝缘热阻中的温升贡献近似为半个绝缘层热阻。用 1 表示三维全 1 向量：

```text
H = (1 + λ) G + diag(sum(Tk) + λ T4)
d = wd [G 1 + (0.5 T1 + T2 + T3 + T4) 1]
u = H qc + d
```

u 为导体相对环境温升。d 是近似分布介质发热的贡献，并非严格的体积发热有限元解。

## 5. 电阻热反馈和载流量

令 b = I²R20,AC α，`qambient = I² R20,AC [1 + α(θambient-20)]`，则：

```text
[Identity - b H] u = H (qambient 1) + d
θ = θambient 1 + u
```

在 `b × max_eigenvalue(H) >= 1` 时，拒绝运行电流的解，提示已超出此线性热反馈模型的稳定范围。不得把该条件直接解释为真实电缆的精确热失控阈值：材料、边界和损伤机制未完整建模。

允许载流量由二分法寻找 `max(θA,θB,θC) = θlimit`，70 次迭代，搜索上界在奇异反馈阈值之下。若零电流的介质损耗已使温度达到上限，则该工况没有可用正载流量，返回错误。

给定运行电流单独求温度。运行无稳定解时，允许载流量仍可独立有效；运行温度、裕量和损耗返回 null。高于温度限值有明确警告；超过 150 °C 的运行温度额外警告材料线性外推失去工程可靠性。

## 6. 结果核算

```text
qtotal,i = qc,i + qs,i + wd
θsurface = θambient 1 + G qtotal
线路三相损耗 [kW] = sum(qtotal) × length / 1000
温度裕量 [°C] = θlimit - max(θoperating)
负载率 [%] = Ioperating / Iampacity × 100
```

每次求解输出温度方程最大残差。径向层节点温度逐层扣除相应损耗乘热阻；最外节点应与矩阵表面温度一致。线路长度只改变总损耗，不改变无限长截面模型的载流量。

## 7. 图形的物理含义

三维显示是参数化结构示意：径向尺寸随输入变化，轴向剖切、绞线根数、展开距离与长度不参与求解，不是 CAD 制造图或有限元网格。

土壤场采用每根电缆线热源及镜像的外部解析叠加：

```text
θ(x,y) = θambient + Σj ρsoil qtotal,j ln(Dimage,j/Dj)/(2π)
```

电缆内部圆盘被屏蔽为 null，不绘制伪造内部场。地表 y=0 恒为环境温度。图中横纵轴物理尺度一致，网格为 81×49。运行有稳定解时使用运行损耗；否则使用极限载流状态，图明确标注所用电流。

自热矩阵采用圆柱对平面 acosh 表达式，而外部图采用中心线源，因此靠近表面的云图值与矩阵表面温度存在近似差别；网格分辨率也有限。不得将该图宣称为有限元、多物理场或完整三维仿真。

## 8. 追溯与数据完整性

输入经 Pydantic 规范化后，将完整 JSON 按键排序、无多余空格、保留 UTF-8 编码，计算 SHA-256；输出模型版本和 UTC 时间。SHA-256 识别的是输入内容，并不是数字签名、计算认证或防篡改数据库。

前端以完整输入内容判断结果是否过期。改参数后隐藏旧数字，禁用过期报告和对比快照；导入先经服务端校验，失败不替换当前工程。CSV 和 HTML 报告包含模型版本及输入指纹。服务器报告会重新计算输入，不接受前端伪造结果。

## 9. 工程应用之前

必须针对目标电缆和敷设方式，用有使用授权的正式标准文本、厂家结构材料数据、独立实现或参考软件以及可用实测结果，分别验证电阻、损耗、热阻、温度与最终载流量。本仓库尚未完成此级别的外部验证；自动测试通过不能据此升级为设计用额定值。
