# CableSimPro 0.6.0 · 企业型号与设计任务

## 当前交付范围

默认工作台按工程设计、产品型号、企业资料、方法与验证组织。当前工程树保留结构、敷设、场计算、候选、历史和任务引用。任务输入按需展开，不默认占据侧栏或底部；模型和同屏结果不因规划或计算卸载。旧工作台迁移入口 `/?classic=1`、早期停靠入口 `/?legacy=1` 均保留并独立回归。

型号内容是不可变版本，核对和停用是独立生命周期记录。核对人是本机声明，不是认证身份或审批权限。核对要求有厂家保证 R20 及依据说明；试样实测/估算可存草稿，但不自动成为正式候选。软件不鉴定保证文件真实性，也未载入完整产品标准限值。

新版本保留旧内容，当前候选只用最新已核对且未停用版本。新版停用不自动复活旧版本。项目引用时复制结构快照，保留项目 U0、频率和较低温度上限。改变结构标记项目修改副本；不回写产品库。旧项目保留原版本并提示生命周期变化，不自动升级。审批事务再次检查产品生命周期，防止先生成提案后停用的竞态。

另存方案复制输入、锁、资料引用、型号关联及设计依据，不复制运行结果。新的方案独立编辑，保留来源工程及版本。

## 选型与报告

企业选型只枚举已核对型号，默认不采用演示数据。每个候选使用既有热模型重新求解，保存完整条件、产品版本、参数哈希、可行性与失败原因。允许2～4个候选并列比较；没有价格不能宣称经济最优。切换要求后禁用旧候选应用；报告始终由原研究快照生成，不混入新参数。

支持既有直埋/单根隔离竖向研究域；采购和损耗按各自总量口径，不把三相线路与单根竖向数字直接混排。候选仅在现有温度/几何/输入约束内可行，不表示通过压降、短路、保护、机械或产品全标准校核。企业研究每轮最多40个当前有效型号。

## AI执行与来源

共用执行层增加 products.list、products.propose、project.assessment、selection.reviewed、selection.report，合计17项类型化能力。UI走真实服务端版本/CAS与审批规则，不给Agent提供自行核对产品、解锁或自动审批工具。

当前云端自然语言规划适配器仍是有限任务接口，尚未实现让LLM自主多步调用全部17个能力。不能把能力登记等同于完成通用Design Agent。OCR/企业资料问答继续使用v0.4/v0.5已有的接入与授权规则，未用真实付费Key验证效果。

计算快照与报告增加产品绑定/版本原文。资料引用仍应逐项核对，型号保证电阻声明不等于电缆获认证。源码与CI只含明确的假设测试数据，不包含企业原件或标准全文。

## 三维资产

新增可重复生成的均匀土壤直埋三维场景。三相中心x/埋深由同一工程参数给定；支持水平和三角排列。轴向显示1.2m代表段，并在场景和GLB标注不是线路总长。导出18个同心层网格，三相父节点和位置/单位/原始输入。地表和网格仅为参考，不引入虚假回填区或沟壁热边界。

没有新增COMSOL、FEM、CFD或新的场方程；真实绞线工艺、夹具热桥、排管/成束仍未完成。外观模型与计算域保持区分。

## 测试与限制

新后端覆盖版本并发、生命周期、过期审批、项目副本、产品/场景分离、缺少价格、原报告和转义、请求去重、重启、来源冲突。新浏览器覆盖默认层级、按需任务/IME、型号草稿核对与修订、实际候选与报告、旧结果、三维GLB坐标、移动和自动无障碍规则；旧UI回归明确运行兼容入口。

最终数字以具体提交CI和JUnit为准，不预先宣称通过。本地容器浏览器HTTP导航被策略阻止，浏览器验收来自GitHub标准Linux/Windows runner。比例/IME/移动仍为模拟，不是系统DPI或真机人工验收。

依旧仅供可信本机研究，无企业多租户认证、细粒度授权、加密数据管理或合规签名。不能直接公网暴露。
