# v0.5.1 同屏工作与任务输入

本次为 v0.5 的交互修正；无新增图片生成、COMSOL 或有限元求解能力，不更改物理方程。

## 默认工作区

- 工程助手不是左/右固定聊天栏。输入区常驻主工作区下方，真实 textarea 可直接发送任务，Ctrl/Command+K 聚焦。
- 会话与审批向上展开，占独立布局空间，不覆盖画布和图例，也不挤窄模型宽度。Escape 收起并返回输入。
- 切换工程页面不卸载输入组件；草稿保留。切换工程则重建输入上下文，避免把旧项目草稿误发给新项目。
- 生成的变更仍由既有服务端审批、参数锁、版本校验处理。折叠会话不会丢弃待审批提案。
- IME composition、keyCode229、Shift+Enter 不发送；未提交参数、未授权云端发送、忙碌状态均不允许提交。

## 当前结果与历史记录

建模页与敷设页可以执行明确标识的三相直埋计算；已记录为竖向设计依据时不显示直埋按钮。原始物理范围未扩大。

求解完成不改变当前页面。模型组件保留，下面展开结果表、曲线、土壤解析温度和计算明细。结果内部页签只切视图，不切工程导航。原“计算结果”页保留供历史档案浏览。

主界面采用 stayInWorkspace 客户端策略；`/?legacy=1` 仍保持原行为，原功能测试继续运行。

参数、设计依据或未提交输入变化后，旧导体温度、曲线、报告不作为当前结果。扫描按输入版本失效；从历史记录打开扫描不宣称为当前工况。

## 字体与图标

参数使用正文无衬线和等宽数字特性，不整列使用终端代码字体。参数标签14px、数值15px，常用图标适度增加笔画；不添加生图素材或随包分发字体。
