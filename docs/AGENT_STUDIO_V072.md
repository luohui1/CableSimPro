# v0.7.2 电缆工程任务工作区

## 本次范围

以 Codex 的项目任务、产物和变更审查组织方式为交互参考，不复制其品牌，也没有把 Codex 引擎接入电缆软件。

官方参考（2026-09-08 核对）：
- https://openai.com/index/introducing-the-codex-app/
- https://developers.openai.com/codex/app/features
- https://developers.openai.com/codex/app/review

默认智能工程流重做为：左侧工程能力与真实执行记录、中间任务/变更/计算结果、右侧工程附件。主工作区不是一个表单和聊天框的拼接。桌面输入区仅在任务列底部，不遮挡电缆画布或审查按钮；小屏收起导航与附件，保留核心任务。

四类工程动作：载流量校核、敷设参数比较、企业型号选型、资料参数核对。前两类复用既有受约束任务规划；后两类打开实际工程模块，不伪装成语言模型已自主完成整个流程。设计依据使用现有范围检查。

## 工程事实与保护

- 两种模式仍共享 StudioProvider/服务端工程，未创建第二份模型或结果。
- 右侧预览在有效提案下显示候选，正式工程仍保留旧参数，人工批准后才写入并执行。过期或版本变化时预览回到当前工程，旧提案不能批准。
- 差异表区分原值、拟用值和单位。空值显示为估算，不把它当成0。
- 参数锁、未提交输入保护、审批、版本检查、重复审批拒绝及输入绑定结果继续生效。
- “新任务”只重置当前任务输入视图，不新建工程，不删除已保存计算。存在待审查提案时禁止直接新建以防静默覆盖。
- 左侧记录来自已有统一执行层的只读 provenance API；打开记录读取任务输入/输出快照，不重复计算、写入或自动重新批准。不是完整多会话自主Agent，也不表示并行任务已实现。
- 任务历史查询有取消/过时响应保护；查询失败明确提示，不伪造空历史成功。
- 不请求新云服务，无密钥时明确标注本地命令。模型服务发送仍需单独同意，不因参考 Codex 而新增 shell、网络或数据库权限。

## 图形资产

新增可复用 CablePortrait 与显示细节生成器。模式入口、Agent当前/候选附件和专业工作台使用同源尺寸定义。Three.js 绞线端面、屏蔽线外观只用于理解结构：不代表厂家真实股数、加工尺寸或电磁网格，不参与求解。原六层工程实体和GLB参数元数据保持独立，导出未伪装为制造图。

敷设附件从真实坐标绘制等比例截面，附埋深与间距；不使用伪造温度场。没有生成的场图、虚假达标徽章、假客户/员工/订单或无来源仪表盘数字。WebGL不可用时有等效二维截面回退，释放视图时回收GPU资源。

浅色界面采用系统可用中文字体、独立标题/正文/字段/数值层级。没有下载或分发字体文件，没有背景外部请求。没有企业沟体、井道、夹具资产库；不宣传这些对象已参与计算。

## 验证

沿用原228项后端测试；新增任务区测试涵盖入口无写入、工程预览与审批、原值/拟用值/单位、只读任务快照、待审批保护、旧提案失效、模块导航、移动布局、WebGL与无障碍自动规则。原双模式与早期功能回归继续运行。最终数量与结论以该提交CI工件为准。

本地构建与后端可执行；本地浏览器HTTP导航被环境策略阻止，不尝试绕过。真实浏览器截图和交互验收使用GitHub Actions，截图只代表同次提交实际渲染。云端OCR/LLM真实Key、COMSOL、独立工程认证不在本次验收内。

## 浏览器审查修正

- 实测入口图形说明与任务预览文字对比不足时修正真实文字颜色，保留WCAG自动检查。
- 参数差异保留15位有效数字（如R20 0.0601 Ω/km），不统一截为三位小数；新增资料提案精度回归。
- 历史工具记录先呈现当时输入和候选差异，原始JSON默认折叠；历史候选不代表曾被批准，不能重新应用。
- 专业模式删除重复的全局横栏，将产品/资料/方法入口并入工程导航；数值输入保持15px，字段名称14px。
