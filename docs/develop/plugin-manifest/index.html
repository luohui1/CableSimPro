插件清单字段

插件清单 plugin.json（cablesim.plugin/2）的结构：身份、运行方式、权限、资源、计算能力与封签。

每个插件在 plugins/<id>/plugin.json 中用 cablesim.plugin/2 格式描述自己。宿主只读清单：清单声明了什么，界面就展示什么、预检就检查什么。下面的字段表由仓库中的 plugin-spec/manifest.schema.json 在构建时生成，与宿主校验清单所用的规则一致。

顶层字段

字段类型必填
schema"cablesim.plugin/2"是
idstring是
versionstring是
namestring是
descriptionstring | null否
icon"assets/icon.svg" | null否
presentationPresentation | null否
publisherPublisher是
host_apiHostApi是
licenseLicense是
platformsstring[]是
runtimeRuntime | null否
permissions"project.read" | "study.run" | "artifact.read" | "artifact.write" | "project.propose"[]是
dependenciesobject[]是
resourcesResources是
capabilitiesCapability[]是
filesPackageFile[]是
字段说明
schema固定为 cablesim.plugin/2。
id、version、name插件标识（如 cablesim.iec60287）、版本和显示名称。已发布的版本内容变化时必须升版本号。
description、icon、presentation说明文字、图标和展示素材。
publisher发布者标识与名称。
host_api需要的宿主接口主版本和最低次版本。
license许可证（SPDX）及是否需要人工审查。
platforms支持的操作系统与架构。
runtime运行方式，例如 Python 版本范围和入口文件。
permissions申请的权限。
dependencies运行所需的依赖。安装插件不会自动安装依赖。
resources单次运行的超时、内存上限和网络权限（如 network: "none"）。
capabilities计算能力列表，见下节。
files封签：插件中每个文件的路径、大小和 SHA256。宿主每次调用前核对，不一致就拒绝运行。

kind"method" | "report-template" | "agent-skill"是
idstring是
titlestring是
solver"local" | "slurm" | "either"否
method_versionstring是
analysisstring是
input_schemastring是
outputsOutput[]否
artifactsArtifactSpec[]否
validationValidation是
limitationsstring[]是
descriptionstring | null否
parameter_schemaParameterSchema否
input_contractInputContract | null否
x-groupsParameterGroup[]否
x-headlineHeadline[]否
previewboolean否
preview_timeout_sinteger否
study_tasksstring[]否
categorystring | null否
x-temperature-field-bindingTemperatureFieldBinding | null否
report_templateReportTemplate | null否
agent_skillAgentSkill | null否
read_onlyboolean否
字段说明
kind、id、title能力类型（计算方法为 method）、标识和显示名称。
solver求解位置：local 只在本机，slurm 只在超算，either 两者均可；省略按 local。
method_version、analysis方法版本与分析类型。方法版本记录在每次运行中。
input_schema、input_contract输入格式（如 cablesim.domain/1 的 SI 领域输入）与绑定方式。
parameter_schema、x-groups方法参数的 JSON Schema 与分组。每个参数应有中文标题、说明、单位（x-unit）和范围。
outputs、artifacts、x-headline输出的量、结果工件类型和结论栏显示的关键量。
validation验证等级与用例。
limitations、description适用范围与已知限制、说明。界面和本站方法页直接展示这些文字。
study_tasks适用的研究任务（如 rating）。
report_template、agent_skill声明式的报告模板与 Agent 技能，见插件示例。

运行协议

插件以独立子进程运行（cablesim.run/2）：宿主把请求写入 input/request.json，插件在 output/result.json 中写出结果，每个工况的状态为 succeeded、not_applicable 或 failed。领域输入使用 cablesim.domain/1，全部为 SI 单位。宿主校验结果工件后才保存运行。

校验与封签

修改了插件源码或其静态引用的公共源码后，需要重新封签；已发布的版本先升版本号。
