# v0.4 电缆设计、资料与场分析

## 已实现 / 未声称

本版为本机工程辅助 Preview，继续支持单回路三根相同无铠装单芯电缆、水平或等边三角排列、均匀土壤直埋的稳态热网络。不是完整 IEC 60287，也不是已经通过厂家/标准算例外部校核的选型软件。

本轮增加：服务端 OCR / Agent 配置、原生 PDF 文字层解析、扫描图像的 OCR 适配器、资料页校对和来源版本、企业文字检索/有引用的可选模型问答、型号快照库、有限型号反向选型、二维土壤有限差分场、绝缘与三相磁场解析视图、高对比度界面。

“垂向”若指物理竖井或垂直敷设：本版**没有**竖井通风、烟囱效应、沿高度温差与轴向导热模型，不得用直埋边界替代。若指电缆垂直专业领域，本轮围绕中压载流量与设计工作流推进。

## OCR 与企业资料

上传格式：PDF、PNG、JPEG、UTF-8 TXT/Markdown。单文件 10 MiB，PDF 50 页；OCR 单请求最多选 10 页（当前界面逐页发起）。不接收 HTML、脚本、压缩包。PDF 本地读取文字层；空白或无文字页明确标为待 OCR，不伪造结果。PDF 在子进程内解析，22 秒超时，Unix 下另有 CPU / 地址空间限制；Windows 只使用父进程超时及上传限制。图片检查格式与像素数。损坏、加密或超限资料需要用户先处理。

页面识别流程：上传 → 本机文本层解析 / 明确同意云端 OCR → 校对原文和单位 → 确认页文字 → 提取单型号参数 → 参数差异送审 → 用户批准工程修改。原件只以下载附件返回。识别内容作为文本呈现，不执行其中脚本或指令。

已提供两种 OCR 协议：

- Mistral OCR：Base URL 默认 `https://api.mistral.ai/v1`，调用 `/ocr`，PDF / 图片通过 data URI 发送。服务商返回 0 起算 index 转成本系统 1 起算页码。
- 自定义 JSON OCR：POST Base URL + `/ocr`，Bearer 鉴权。请求为 `model/file_base64/mime_type/filename/pages`，pages 从 1 开始。响应必须为 `{"pages":[{"page":1,"text":"..."}]}`，包含全部已选页。不同 OCR 厂家不保证直接兼容；必要时需用适配服务转换。

每次 OCR 请求需明确同意。**完整原文件会发送到服务商**，即使只识别一页；可能产生费用。无 Key 时不调用云端，不预置假识别结果。契约测试使用模拟服务响应，不代表真实 OCR 服务联调或识别率。用户后续提供服务商、模型和有效 API Key 后，仍需选一份已授权资料实测。

提取器目前仅自动识别带明确标签和单位的四类字段：截面积 mm²、R20 Ω/km、绝缘厚度 mm、护套厚度 mm。支持 `label: value unit` 和简单分隔符。多型号或多列产品表不得猜测对应关系；冲突值要求用户选定单型号连续节选。未识别参数保留当前工程值，**不能据此宣称整根电缆已由厂家资料定义**。

资料库保存原文件 SHA-256、页号、文字、识别方式、核对状态、文字版本和历史快照；工程引用固化来源版本、原文与原文件摘要。摘要用于一致性追溯，不证明文件真实、获得厂家认证或用户有使用权。`GET /api/library/{id}/versions/{version}` 可核查历史页文字。

检索为本机分页文字匹配与中文短词回退，不是向量语义搜索。模型问答只发送本次检索片段和问题，需另行同意。回答要求 [S1] 等来源标记，程序校验引用编号范围；**引用格式有效不保证所有解释正确**，保留原文供用户检查。检索和问答不会修改工程。

## Agent 接入与密钥

设置页提供 OpenAI Responses 和 Chat Completions 兼容工具调用协议。保留人工审批、锁定参数与版本冲突检查。工程操作只允许已支持的 calculate / sweep / inspect，资料问答与候选选型通过各自有边界的工具完成；不是无限自主多 Agent，不允许运行 shell 或任意数据库语句。

地址与模型名写入本机 `providers.json`；界面输入的 Key 只存服务端进程内存，重启失效。GET 配置只返回“有无密钥”和存储来源，不回传密钥。输入校验错误剔除原始输入，避免异常回显 Key。持久使用请在服务端配置环境变量：

```
OPENAI_API_KEY=...
CABLESIM_AGENT_MODEL=...
CABLESIM_OCR_API_KEY=...
# 或 MISTRAL_API_KEY
```

不要把真实 Key 写入 Git、发到聊天或放进前端。清除内存密钥不等于删除环境变量。

HTTP 接口仅允许管理员许可的 HTTPS 主机。默认允许 api.openai.com / api.mistral.ai；自定义域名需由管理员在 `CABLESIM_PROVIDER_HOSTS` 声明。禁止 URL 中携带凭据、查询串或非 443 端口；不跟随重定向，也不继承代理。`/models` 连接检查不发送工程正文，只能说明服务可访问，不证明指定模型可执行。

本版增加本机 Host / 写请求 Origin 检查，但不是用户身份认证。默认只允许 localhost / 127.0.0.1；局域网需显式配置 `CABLESIM_TRUSTED_HOSTS` 并自行控制访问。不要直接暴露公网；尚无租户隔离、调用预算、权限体系与企业合规审计。

## 型号库与反向选型

12 个稳定 ID 的 Cu/Al × 95/150/240/300/400/630 mm² 种子条目均为**演示假设**，不是厂家产品；反向选型默认不包含它们。用户可核对当前电缆全部参数后保存不可变型号快照，并选关联工程来源。来源仅覆盖被引用字段。型号库声明的“user_reviewed”是用户确认，不是外部认证。

给定目标电流 I_target、预留 p：要求 `I_rating >= I_target*(1+p/100)`。每个候选使用其完整结构和电阻独立求解，不用面积比例缩放旧结果。约束包括导体材料、声明额定 U0、外径、几何适用性和工程参数锁。

土壤、埋深和间距保持原工程值；候选导体温度上限不超过原工程上限，也不超过型号上限。计算频率与 U0 为当前工程工况。当前不验证厂家声明电压等级的绝缘配合，不能把额定 U0 筛选视为完整电压等级认证。

可按截面积、运行损耗或采购估算排序。采购估算 = 三根单芯 × 线路长度 × 单芯每米价；缺价格或币种不符的候选不参与成本排序。没有汇率换算、施工附件税费、寿命期成本或自动成本预测。所有候选不满足时报告零可行，不放宽条件。

选型研究保存输入和全部候选快照；应用候选再生成审批提案。旧研究遇到新工程版本不能直接应用。短路热稳定、压降、保护配合、拉力、弯曲半径、端部接头和现场可施工性仍需后续独立设计校核。

## 场分析与数值验证

### 外部土壤热场：真实二维有限差分

在均匀土壤域求解 `-k*(∂²T/∂x²+∂²T/∂y²)=q`。热源功率来自现有稳态热网络的实际运行损耗；按双线性权重沉积到相邻网格，保证 W/m 功率守恒。采用五点差分、SciPy 稀疏直接解。地表恒温，侧面和底面由半空间解析解提供 Dirichlet 边界。

这是一项外部土壤场诊断，不独立求解完整电缆内部结构，也不回写载流量。线热源附近 2.5 个网格宽度或外半径内遮罩，不把网格峰值当作导体温度。热网络不稳定时拒绝本次热场，不悄悄改用额定工况。

显示线性残差（方程除以 k 后，K/m²）、离散边界净热流 W/m、源功率 W/m、守恒差和远离热源固定 0.3 m 外的解析对照 RMSE。129² 模式同时计算 65² 对照。测试含可制造的二次解析解、离散热量守恒、地表边界、实际工况粗细网格对比。诊断不是独立工程认证；边界来自同一个解析模型，不能把吻合当作外部参考软件验证。

### XLPE 绝缘电场：解析

同轴均匀绝缘、内屏蔽等电位、外屏蔽接地，`E(r)=U0/[r*ln(b/a)]`。显示 kV/mm RMS，沿绝缘半径积分应返回输入 U0。峰值为 RMS 的 √2 倍。没有缺陷、空间电荷、终端、接头、电树枝、绝缘击穿与试验判定。

### 三相外部磁场：解析

无限长、非磁介质 μr=1、平衡三相 RMS 电流相量 `[0,-120,+120]°`，按 Biot–Savart 的直导体解叠加 Bx / By。显示 `sqrt(|Bx|²+|By|²)` 的矢量有效值 µT。遮罩电缆内部。忽略屏蔽/铠装感应电流、集肤邻近与铁磁效应，不用于 EMC 合规判定。均匀电流密度 I/A 只是均匀导体假设，不是求解出的电流密度分布。

这些是有明确范围的三种场研究，**不是全耦合电磁热有限元**。有限差分热场、电场解析与磁场解析在界面上分别标注方法。修改输入后，旧场标记为历史并禁止按当前结果导出。
