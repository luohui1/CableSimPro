# 单参数扫描：从曲线到可复核的离散工况比较

本增量基于 PR #18 固定提交 `a37789d2935b7cae30224221c08535cf4421af6f`。
它不是新求解器、全局敏感性算法或 0.7.6 正式发布；不修改 main 或 PR #17。

## 研究依据与产品决策

1. NIST/SEMATECH e-Handbook §5.2.1.2 明确指出，一次改变一个因素不能识别因素间交互。
   因此界面称为“单参数离散点研究”，只给出所扫描点的范围，不把不同单位的斜率直接排名为“最敏感参数”，不声称全局最优。
   来源：https://www.itl.nist.gov/div898/handbook/pri/section2/pri212.htm
2. NIST SI Units – Temperature 说明 Celsius 有偏置零点、温差 1 °C = 1 K。
   因此温度扫描以 ΔI/ΔT 的 A/°C 表示区间变化率，不除以可能为零或负的摄氏温度基准。
   来源：https://www.nist.gov/pml/owm/si-units-temperature
3. Apache ECharts Handbook 的 Empty Data 区分缺失值和 0，缺失值应留下间断。
   因此显示层保留失败点的 x 和空载流量，并显式关闭 connectNulls，不先过滤失败点再跨越连线。
   来源：https://echarts.apache.org/handbook/en/how-to/chart-types/line/basic-line/

来源核对日期：2026-09-09。上述来源支持方法边界，不验证 CableSimPro 的物理内核或标准符合性。

## 已实现的行为

- 共享批准前面板显示扫描维度、单位、全部请求值，以及拟用输入原值是否包含在扫描中；挂载不调用求解器。
- 双模式共用 InlineResults 在有效扫描时显示研究表，不再给扫描结果展示“未计算”的三相单工况表。
- 自动比较基准只能是与原输入相同、唯一且成功的已扫描点。缺失时百分比留空，不暗中使用第一点或补算原工况。
- 用户可以显式选定另一个成功点作比较基准；界面明确提示它不是原工况。选择、视图切换与导出不写工程、不重新计算。
- ΔI = I_point − I_reference；相对变化 = ΔI / I_reference × 100%。
- 电流余量 = I_point − I_operating；不是温度裕量，不含另加的储备系数，也不是完整选型合格判定。
- 区间变化率在参数升序后，仅针对相邻、不同、成功且无重复的样本计算。不是解析导数；不会跨越失败点。
- 表格保留原请求顺序；曲线按参数值升序。失败、重复、全失败及非有限数据有显式处理，不以 0 代替无解。
- 扫描 CSV 包含单位、基准、运行电流、全部点及错误、运行 ID、工程版本与保存运行摘要；数字不按显示精度舍入。
- JSON 导出另外包含完整场景与设计依据。CSV 文本做引号转义和公式前缀防护，负数仍为数值。
- 工程输入变化后，复用已有 currentSweep 证据约束，研究表、曲线与导出入口同时失效。旧记录不被提升为当前结果。

## 验证范围

- `scripts/test_sweep_study.mjs`：40 项纯算术、空值、基准选择、温度零点、重复与非均匀间距、CSV 夹具。
- 新增两个真实后端浏览器用例（每个桌面浏览器项目各执行一次）：
  - 环境温度扫描先审查后批准，逐项对照真实响应、导出 CSV、改变输入后禁止继续导出旧比较。
  - 原工况不在埋深扫描中时不补值，显式改基准、导出 JSON 与切换曲线不发送 POST。
- 专项 workflow 执行既有 Agent/四维扫描后端回归、40 项算术检查、生产构建、Chromium/WebKit 新用例并保存截图与 JUnit。
- 完整矩阵仍要求 12 份无重复、无失败、无错误、无跳过报告。新增桌面用例使期望变为 Linux 169 / Windows 208，不减少既有测试。

完整本地应用没有在当前工具环境安装：本地网络无法解析 GitHub，且缺少 langgraph/React 等完整依赖。
本地只验证可独立编译的纯算术模块；真实生产构建与全栈浏览器测试以该增量提交的 Actions 为准。
