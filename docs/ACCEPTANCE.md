# Demo 验收与测试说明

## 验收目标

验收对象为有限范围的可运行工程辅助 Demo，不是标准合规认证。范围固定为单回路三根相同无铠装单芯电缆、均匀土壤直埋、恒温地表、平衡持续负荷。

## 自动测试分层

| 测试层 | 验证内容 | 不代表什么 |
|---|---|---|
| 几何及单位 | 面积影响导体包络与理想电阻；径向热阻、土壤自身/互热与手工表达式一致 | 不证明厂家结构尺寸或材料值正确 |
| 热网络 | 关闭温度系数后匹配闭式解；额定电流回代达到温限；三相对称性；径向及外表面能量平衡 | 不证明对所有真实电缆满足 IEC 60287 |
| 工况性质 | 更热环境、更高土壤热阻率、更深埋设降低额定电流；增大间距降低互热；损耗系数变化影响结果 | 不可用于推断本模型范围外的工况 |
| 边界及稳健性 | 非有限值、零/负尺寸、重叠、越地表、不支持敷设、负电流被拒绝；不稳定运行状态明确返回 | 不覆盖真实热失控、绝缘损伤等机制 |
| API 与存储 | 输入版本及字段校验、工程 CRUD、跨应用实例磁盘持久化、未知 API JSON 404、报告文本转义 | 不具备多用户认证、公开网络服务防护 |
| 浏览器 | 真正启动构建后应用，连接真实计算 API，验证模型、计算、参数失效、保存重开、文件导出、导入、扫描、对比 | 不是截图拼接或静态页面检查 |
| 打包 | 包中有构建后的前端，排除本地数据库、环境、依赖目录和 .env 文件 | 不打包 Python 解释器和 pip 离线轮子 |

## 浏览器项目

Playwright 在 Chromium、桌面 WebKit、移动 WebKit 三个项目中重复核心场景。Chromium 必须成功初始化 WebGL 并创建实际 Three.js 画布；不支持 WebGL 的环境允许明确切换到二维。移动项目模拟 iPhone 的尺寸和触控，不等于实体 iPhone/Safari 真机验证。

每个浏览器测试都检查未捕获 JavaScript 异常。测试包含以下路径：

- 初始载流量与真实 API 的同工况结果匹配，显示一位小数的误差小于 0.051 A；桌面/移动文档不发生全局横向溢出。
- 修改截面积立即清空旧结果，重新计算改变结果；数字输入留空后切换参数页，不能悄悄采用旧输入。
- 重叠电缆错误可见，不钳位为默认间距。
- 零运行电流、3000 A 不稳定热反馈工况有可辨别的输出状态。
- 保存工程、刷新、从库重开，输入保持；JSON、HTML 与 CSV 下载内容可检查；删除测试工程。
- 错误 JSON 版本导入不覆盖当前工程，正确项目可以导入重算。
- 两个工况快照、移除快照、敏感性扫描、参数变化清除扫描结果。
- 三维展开/重置、三角排列、敷设截面、土壤场、明细表、极限工况和方法文档。

## 运行与证据

参见 README 的测试命令。CI 为后端提供 Python 3.11、3.12、3.13 环境，并执行 TypeScript 类型检查和 Vite 生产构建。

GitHub Actions 是实际结果来源。不要把工作流 YAML 中列出的任务当作已经通过的证据；应核对具体提交 SHA、运行结论、每项测试步骤、日志及工件。

成功运行会发布 `CableSimPro-demo`；`browser-report-and-screenshots` 中包含 Playwright HTML 报告、JUnit 记录、工作台和土壤场等截图，失败场景保留 trace。每次安装解析出的前端锁文件另存为 `resolved-frontend-lock`。CI 工件存在保存期限，应按需自行备份。

## 手工工程校核清单（尚未完成外部验收）

正式采用前需要建立有来源和授权的基准数据集。逐项核对厂家 R₂₀、温度系数、绝缘尺寸、热阻率、屏蔽连接/接地及实际损耗，再独立计算分层热阻和互热关系。最终载流量偏差必须设定项目相关的允许范围；不能通过调整输入凑出一个匹配数字来掩盖模型差异。

当前没有宣称与任何特定商业软件、厂家载流量表或 IEC 完整算例达成误差指标。生产级工作仍需材料追溯、标准模块扩展、第三方复核、数据迁移、认证权限和部署运维。
