术语表

CableSimPro 中工程、型号、研究、运行、快照、发行、封签、提案等术语的含义。

工程与对象

术语含义
工程一项工作的容器，包含线路与敷设布置、研究、运行记录和交付文件。工程的每次保存形成一个修订，可以撤销和回溯。
型号设计在工程中编辑的一个电缆型号：结构、执行标准、标准依据、电气参数、短路容量、载流量表与规格书。
电缆型号版本资源库中的固定版本型号，例如“YJV22-8.7/15 kV 3×240 · 1.0.1”。研究引用某个版本，版本发布后内容不再改变。
系列同一厂家、同一型号族的一组规格，通常由一张厂家结构表导入，例如“人民电器 YJV22-8.7/15 kV 三芯”。
规格系列中的一个具体截面或芯数组合，例如 3×240。每个规格有自己的版本和状态。
资源计算会引用的基础资料：材料、部件、结构、敷设模板、计算方案和规则。资源有版本和状态（草稿、已审核、已发布、已停用）。
部件与研究模板从已保存型号的部件或成功运行的研究定义冻结得到的参考资料，可以在人工确认后采用到另一个工程。

计算

术语含义
研究一项计算任务的定义：分析类型（如额定载流量）、引用的型号版本、敷设与工况、计算方法及参数。
运行研究的一次执行。每次运行保存输入快照、方法版本和结果，不会被后续修改覆盖。
快照运行开始时冻结的完整输入，连同其来源；以后修改工程不会改变已有运行的快照。
预检运行前的检查：输入是否完整、是否在方法的适用范围内、在本机还是超算上求解。预检不通过时不能运行。
试算用当前输入（包括未保存的修改）快速计算一次，结果标为“未保存”，不生成运行记录，也不能用于交付。
参数扫描把一个输入按给定范围逐点真实计算，得到结果随该参数变化的曲线；失败的点保留为缺口。
方法对比比较本研究中已保存的一个基准运行和一至四个对照运行的输入差异与结果差异。
问询选型给定目标电流，对一组候选型号逐一计算并按判定排序，给出推荐型号。
收敛研究有限元结果的网格与计算域逐级加密，连续两级变化都小于门槛时才算收敛。
当前结果 / 历史结果当前结果对应现在的输入、型号版本和已安装的方法；三者之一变化后，原结果成为历史结果，保留原样，可查看和比较。
方法 / 能力插件提供的一项计算功能，例如“IEC 60287 稳态载流量”。每项能力有方法版本、适用范围、限制和验证等级。
验证等级方法的验证程度，例如参考算例核对、交叉校核、未经独立验证。未经独立验证的能力只作参考研究使用。
求解位置方法在本机运行还是提交到超算（Slurm 集群）运行，由插件声明。
核时超算作业消耗的计算量（核数 × 小时），设置中可限定单批和累计上限。

来源与可信度

术语含义
来源（出处）每个数值的依据：厂家资料、标准依据、文献资料、工程师填写或推导，并注明表号、页码等定位信息。
可信分档对数值可信程度的标记，例如原表实测、标准限值、工程补充、参考。不同分档不会混在一起。
标准依据库随插件发行的离线标准数据：尺寸、电阻、试验数值及原页出处。只覆盖已逐格核验的条款。
本库暂未收录标准依据库尚未包含某条款或版本。相应核对项显示为“未覆盖”，需要人工核对。
缺项计算或核对所需、但尚未提供的输入。软件列出缺项，不用推测值补齐。标准核对中显示为“待补数据”。
未覆盖方法或依据库不包含的条款、工况或分支。软件不给出判定，不能视为满足。

插件与发行

术语含义
插件提供计算方法的独立模块。平台本身不包含算法，所有计算方法都来自插件。
发行插件或安装包的一个版本，例如插件发行 1.8.6。发行中可以包含多项能力，每项能力有自己的方法版本。
封签发行时记录的清单、源码、依赖和资源的摘要。运行前逐项核对，不一致时拒绝执行。
发行摘要封签内容的摘要值，保存在每次运行中，用于判断结果是否仍对应当前安装的发行。
构建编号离线安装包的唯一标识（build_id），由包内全部不可变文件计算得出；/api/release-info 可查询当前构建编号。

Agent

术语含义
Agent工作台内的对话式助手，读取工程数据、调用计算插件并提出修改方案。
技能Agent 处理一类任务的工作说明，例如载流量研究、结构表导入、规格书与计算书。
提案Agent 提出的一次写操作（建立、修改、运行或导出），以待审卡片显示，内容固定。
接受 / 拒绝人对提案的决定。接受后平台按与工作台相同的路径执行；拒绝则不写入任何数据。
上下文压缩长对话时 Agent 自动概括较早的内容，保留目标、进度、待审提案和关键量，完整记录仍保存在原对话中。
对话服务（边车）运行 Agent 对话的本机进程，随平台启动和停止，只监听本机，不接触模型密钥。

交付

术语含义
正式交付文件由已保存的运行和型号生成的规格书、计算书、载流量表和研究报告（PDF / Excel），不重新计算。
正文与追溯正文呈现结论和工程前提；追溯章节列出每个数值的原始值、单位换算、修约与来源。
签栏设计、校核、审核、批准四个签字栏，只填写真实匹配的签核记录，缺签留空。
客户版 / 内部审核版规格书和计算书的两种版本。内部审核版另含完整输入与诊断，缺项随文列出；客户版须补齐缺项，或由人声明发布范围。Agent 对话中分别称为客户稿和内部审阅稿。
修约按 GB/T 8170-2008 把数值修约到规定的显示精度，只作用于显示，不改变保存的结果。
审核与发布型号规格书的人工审核、批准和发布流程，与文件下载分开记录。
