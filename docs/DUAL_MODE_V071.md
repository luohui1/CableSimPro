# 0.7.1 双模式工作入口

## 本轮范围

`/` 首先选择“专业工作台”或“智能工程流”。首页不会仅因访问而新建工程；进入模式时才创建，或恢复已保存工程。用户每次到工作入口仍可选择，记住上次方式只用于标记、不自动跳过。

专业工作台保留真实三维模型、参数校验、载流量计算、企业产品、资料和研究。工程流是单独任务页面，有任务输入、保存条件、缺参提示、参数差异审批、计算结果、企业候选、资料核对。不是把同一个界面换标题。模式切换不复制工程、改变版本或重新执行计算。

## 状态和路由

两个模式共用外层 StudioProvider。已打开的工作台留在树中；切换保留未提交输入、草稿、提案和结果。隐藏工作台不会响应全局快捷键抢焦点。工程流由同一后端 `task.plan` 能力产生计划，应用仍走原有版本/锁/生命周期检查。

可分享本机路由为 `/?mode=workbench&project=<workspace-id>` 或 `/?mode=agent&project=<workspace-id>`，需要接收端访问同一服务和数据库。它不是公网分享链接，也不是访问凭证。不存在的 ID 返回错误，不静默创建替代工程。旧版兼容入口 `/?enterprise=1`、`/?classic=1`、`/?legacy=1` 保留。

`GET /api/workspaces/{id}/session` 在单一 SQLite 读事务中返回工程、最近待审查提案和最近运行记录。只是读取，不批准/重算/创建版本。历史输出仍由输入与设计依据有效性检查决定能否作为当前结果；过期或旧版本提案保留用于查看，不可批准。恢复只选择最近一个待审查提案，不是全任务管理器。

工程、提案和计算记录重启可恢复；未发送任务文字和表单输入草稿仅保留当前页面内的模式切换，不保证刷新后保留。聊天全文不是持久化会话。云端发送同意不会跨刷新保存。

## AI 真实能力

无密钥时是明确标识的本地命令演示，支持既有载流量计算、明确参数修改与扫描，不是大模型。云端 Responses/Chat Completions 适配器由服务接入设置配置并经数据发送授权后使用。此版本没有真实付费 Key 的云端端到端准确率验收。

工程流中的企业选型和资料核对调用现有真实模块，但这不代表自然语言规划器已能自动串联所有17项能力。未支持任意自主多步骤设计、无人审批、取消恢复计算队列或完整多标准求解。用户确认的计算仍由确定性工程内核完成。

## 验证

新增会话读事务、刷新/重启恢复、过期提案、输入修改不重写旧结果、跨工程隔离测试。浏览器测试覆盖入口无写入、模式互转、模型保留、真实计算/审批、刷新恢复、项目深链、失效提案、未提交输入、中文组合输入、浏览器历史、移动屏幕和部分axe自动规则。

原企业界面用显式兼容入口继续回归。原选型报告断言改为接受400与400.0等数值等价显示，仍核对目标数值及产品内容哈希；未跳过功能。

本地浏览器 HTTP 导航被执行环境策略阻止，不能把本地构建或截图替代为浏览器验收。实际跨浏览器和 Windows 结果以本提交 GitHub Actions 报告为准。

## 限制

本机研究版无公网认证或多租户隔离。模式不是角色权限；两种操作方式有相同权限。没有新增物理方法、COMSOL连接、FEM或完整IEC条款。模型版本与计算方法版本没有随UI版本伪造升级。浅色入口示意图由界面元素组成，明确不展示虚构数值、厂家产品或“标准符合”徽章。

字体使用现有本地/系统回退，无新增默认外部字体或图片请求。包不分发字体二进制、Key、企业原件、数据库和依赖安装目录。
