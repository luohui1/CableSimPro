release.toml 配置

发行版配置文件各项的含义、默认值和取值规则。

安装包根目录带一份 release.toml（UTF-8 编码）；安装时把它复制到解压目录之外保存，启动时用 --config 指定（见安装）。相对路径以配置文件所在目录为基准；Windows 路径请写成正斜杠（如 D:/CableSimPro-data）或放在 TOML 单引号里。配置文件不在程序完整性摘要之内，可以随时编辑，升级时继续使用同一份。

[server] 服务

键默认值说明
host"127.0.0.1"监听地址，必须是 IP 地址或 localhost。只允许本机访问时保持默认；内网访问见内网部署。
port8100界面和所有接口共用这一个端口。端口已被占用时启动失败，不会改用别的端口。
open_browsertrue启动后是否自动打开浏览器。服务器上设为 false 或启动时加 --no-browser。
startup_timeout_seconds300等待服务就绪的上限。首次生成示例可能需要几分钟；超时即判定启动失败，升级时会恢复升级前的快照。
trusted_hosts[]允许出现在浏览器地址栏里的主机名或 IP。只接受明确的名字，不支持通配符。

[storage] 数据

键默认值说明
data_dir"~/CableSimPro-data"工程库、数据集、复现资料、工程证据、备份和保留的各个程序版本都放在这里。~ 指用户主目录。必须在解压目录之外。

数据目录里的主要内容：

位置内容
engineering.sqlite工程库（工程、研究、运行、型号、交付记录）
datasets/、library/、engineering-evidence/数据集、复现资料、工程证据
programs/<构建编号前16位>/已安装的各个程序版本及其独立 Python 环境
release-snapshots/每次升级前自动创建的工程库快照

[initialization] 初始化

键默认值说明
seed_examplestrue只在工程库不存在时生效：用随附的公开教学输入生成示例工程。设为 false 得到空工程库。已有工程库无论如何都不会被重新生成或替换。

[model] 模型

键默认值说明
base_url""OpenAI 兼容接口的完整 API 基址，如 https://llm.example.com/v1。留空表示不调用模型。
model""模型名。
api_key_env"CABLESIM_LLM_API_KEY"保存密钥的环境变量名。密钥本身不要写进配置文件。

这些值只是初始连接。管理员在界面“设置 → AI 模型”里保存过的设置优先于本文件。写了 base_url 或 model 其中一项时，整个连接以本节为准，密钥只取 api_key_env 所指的变量；两项都留空时，本节不指定连接，环境变量 CABLESIM_LLM_* 照常生效。完整的优先顺序见 Agent 对话服务。

[agent] Agent 对话服务

键默认值说明
enabledtrue是否随程序启动 Agent 对话服务。设为 false 时完全不启动，工作台其余功能不受影响。
port8111对话服务的本机端口，只监听 127.0.0.1，须不同于 [server] port。被占用时启动前即失败。

对话服务的随包内容、安全边界与故障排查见 Agent 对话服务。

回退到旧版本前

不含 Agent 的旧版本不认识 [agent] 一节，会拒绝启动。回退到这类版本前，先从 release.toml 删除整个 [agent] 一节。

[[processes]] 伴随进程

可以追加随应用一起启动和停止的其他进程（Agent 对话服务由 [agent] 管理，不需要在这里配置）。安装包自带的 release.toml 中，这一节是注释掉的示例，格式如下：

  • command 是参数数组，直接执行，不经过 shell；不会自动下载进程依赖。
  • 占位符 {python} 是发行环境的解释器，{app_dir}、{data_dir} 是当前程序目录和数据目录的绝对路径。
  • env 只放非敏感设置。
  • required = true 的进程退出会停止整个应用；可选进程退出不影响核心工作台。
