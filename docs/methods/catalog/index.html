方法清单

当前发行的全部计算插件、计算能力、方法版本、验证等级与求解位置。

下表由各插件清单（plugins/*/plugin.json）在构建时生成，与软件实际安装的插件一致。每项能力的适用范围、输入参数和验证用例见对应的方法页，或在软件的“方法 → 插件”中查看。

验证等级的含义：

验证等级含义
解析基准核对与独立的解析解或手算逐项核对。
参考算例核对与公开算例、标准附录、文献或商业软件的保存结果核对。
接口测试验证了输入输出契约和拒绝规则，数值本身另有出处。
未经独立验证仅作参考研究使用，结果不能单独作为工程依据。
