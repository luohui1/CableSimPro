IEC 60287 地下稳态温度与载流量（cablesim.iec60287）

插件的精确包版本与各能力方法版本以 plugins/cablesim.iec60287/plugin.json 为准。steady-rating 主契约为 cablesim.domain/1；显式 single-core/1 验证输入改由 reference-rating 能力使用原接触品字形算法（数值版本 0.1.0）。工作台分别提供领域 schema 和 standalone_schema，不将旧三根等负荷模型当作 N 电缆契约。

所有物理计算在插件中执行；宿主只保存和呈现。每个电缆结果保留实体、工况与 SI 单位。目标判定逐回路 / 逐电缆保存，避免相同结果键覆盖其他对象。

皱纹铝护套与缓冲层

领域层 form=corrugated 的 thickness 为金属壁厚，新增 corrugation_depth 为波峰到波谷的径向深度（不含壁厚），corrugation_pitch 为轴向节距，两者单位 m。径向包络计入壁厚与波深；单回路模板调用统一的 CableType.radius()，同时计入芯内层、公共层和波纹，不再只累加公共层。缺波深/节距时定位到该层具体字段；不能根据简化型号外径猜值。

工程算例与核对表

“新建研究 → 敷设算例”提供九种输入：单回接触品字形、单回水平、双回品字形、双回水平、品字形排管、2×3 排管、3×3 排管、矩形回填、3×3 包封排管。唯一输入定义位于 backend/kernel/scenarios.py；创建独立研究，插件实际运行后才有结果。

110 kV 使用 YJQ02 800 mm² 校核模型：型号系列与导体包络参考厂家资料，其余尺寸及物性为明示假设。10 kV 使用 6/10 kV 240 mm² 校核模型：Tratos 官方表提供导体参考直径 18.2 mm、绝缘 3.4 mm、R20 0.0754 Ω/km。原产品是铜丝屏蔽，本模型声明采用光滑铝管套，不是厂家该产品。现场条件、负荷与导热回填料为设计假设，未冒充测量。混凝土包封算例采用 Table 1 的 1.0 K·m/W 参考值，实际配比需核实。

每次领域运行保存 verification 工件：不读取求解器土壤矩阵，以独立对数式重建自热 / 镜像热阻和内部热路；代入最终损耗核对逐根温度（1e-4 K）；分别核对管内空气与管壁；以最终 Rac、λ₁、空气均温做固定参数二次式允许电流手算（0.001 A）。核对失败则拒绝生成可用结果。

研究“诊断”和计算书列出插件值、手算值、差值、单位、容差及条款。此检查验证热路与最终状态闭合，不构成独立电磁复算、完整标准认证或现场试验。

公开测试位于 plugins/cablesim.iec60287/tests/test_iec60287_group.py；真实宿主 / 报告回归位于 tests/test_design_studies.py。受控 TB880 夹具默认从 .data/tb880/fixtures 读取，也可用 CABLESIM_TB880_FIXTURES 指定；不存在时明确 skip。14 项历史测试及领域算法 9 个工况均由同一物理输入运行；参考数值只用于断言，不输入求解器。
