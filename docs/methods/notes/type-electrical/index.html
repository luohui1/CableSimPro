型号电气参数与短路容量

插件 cablesim.type-electrical，两个能力分别保存为宿主研究和不可变运行：electrical 与 short-circuit。cablesim.standard-check 0.1.1 读取独立出厂数据记录；设计参数不会被实测值覆盖。算法只在插件内，页面只展示计算工件。

原文与数据口径

  • IEC 60287-1-1:2023：交流电阻 §5.1.1–5.1.5（正文16–18 / CMV合订PDF64–66）；电容、介质损耗 §5.2（19 / 67）；温度系数表1（35 / 83）；ks、kp表2（36 / 84）；三芯长度修正附录A（38 / 86）。
  • IEC 60287-1-3:2023：导体几何感抗从 §4.2 式(9)及表1的等距平衡回路导出（正文第 11 页 / PDF 第 13 页；表 1 正文第 12 页 / PDF 第 14 页）。这只是导体几何项，不包含护套环流、大地返回或完整序阻抗。
  • IEC 60949:1988：第2、3章（9 / 摘录PDF3），第5章（11、13 / 4、5），第6章（13、15 / 5、6），材料表I、II（17 / 7），导体非绝热表III（19 / 8）。铜 K=226 A√s/mm²、β=234.5 K；铝148/228；铅41/230。XLPE导体的表III铜X/Y为0.41/0.12，铝为0.57/0.16。
  • AMD1:2008第4章补充：并联屏蔽、护套、铠装的电流分配与初始温度分别确定，不能累加单个组件最大容量。

60949来源是公开可读的原始英文页图摘录，按原貌封装；不是完整双语出版物。官方预览、英文摘录和修订文本三份均登记在标准库的《标准题录与数据用途.md》；SHA256见插件 sources.json。全文仅保留受控资料库及.data，不提交Git。

运行参数用SI：温度K、时间s、中心距m、相电压V。界面显示°C、mm、kV。每个方法参数都带条款、报告或明确的计算条件；空来源保持缺项。运行相电压不从型号U₀推断。R20的数据性质与每米成品电缆/直线线芯的长度基准分别明确，避免三芯绞入系数重复计入。

短路容量手工核对

结果页先展示结论与保存的计算条件。输入、出厂数据或方法变更后标为历史；三芯结构、实测记录和输出完全相同时合并为“芯 1–3（相同）”，不同芯分别显示。电流显示三位有效数字、修正因数三位小数，完整精度保留在右侧依据栏与运行工件。

短路工件包含 cablesim.short-circuit-curve/1：0.1–5 s 对数采样、当前计算时间及最多20个用户关注时间点。每个曲线点由插件的同一个绝热/非绝热分支计算；页面不按时间缩放已有电流。缺少输入的组件保留空采样，不插值补造结果；图域外的当前计算时间单独说明。0.25 s、4 s 曲线点同时与独立45位 Decimal 手算对拍。

出厂数据与拓扑

领域文档 measurements[] 存放稳定ID、型号/线芯/层角色、量、SI值与单位、实测或厂家声明性质、报告/样品编号。相同对象同一量只留一个当前记录；旧记录保留在工程修订和运行快照。最薄点和最大厚度只有同一报告/样品出处才计算均匀性。设计R20与记录R20分开展示；标准上限仍由标准插件确定。屏蔽截面有数据也不自动生成不存在的故障电流要求或合格判定。

复用接地拓扑契约的实际回路身份；方法条件明确声明金属连接、回流路径及出处。1.2.1 方法按 IEC 60287-1-3:2023 §4.2 式 (9)、§4.3 的阻抗矩阵计算长直、非磁性、圆实心或紧压圆形的三相回路，保留自感、互感与复数阻抗（正文第 11、12 页；本地 PDF 第 13、14 页）。三芯使用保存坐标，单芯须填写排列和中心距。品字及平排的正序量经平衡相量投影，不把三个部分自感相加。

零序只开放明确两端连接、三条同心非磁性金属回流、无大地分流的分支；必填每相金属交流电阻、平均半径及非磁性确认。单端、交叉互联、大地回流及钢铠装完整阻抗须另行线路研究；缺系统条件标“需工程输入”，不得把局部几何感抗当完整线路阻抗。

IEC 60949:1988 + AMD1:2008 的短路材料常数、绝热、非绝热、螺旋带面积与并联分配依据经 Executor 实际查询 cablesim.standards-basis，保存逐条快照及摘要。用户明确选择绝热或非绝热容量口径；非绝热必须有相邻介质热阻率、体积热容和接触条件。并联分支按 AMD1 §4 的逆电阻比例分配已声明故障电流，逐组件重新计算初末温度对应的容量并比较余量，不把组件容量相加。遗漏任一回流部件、重复部件、缺来源或无效单位拒绝计算。钢带此处分支只作短路热容量，不声称得到钢铠装线路阻抗。

消费清单只在依据发行变化时运行 python plugins/cablesim.type-electrical/src/cablesim_type_electrical/basis_catalog.py --write 机械生成（LF）；不加 --write 校验一致。封签只写本插件。实际计算仍查询依据插件，不以清单快照代替查询回执。
