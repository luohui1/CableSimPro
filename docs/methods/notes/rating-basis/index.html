计算方法与载流量口径

现行载流量结果契约

IEC 新输出的每个 ampacity 数量及对应计算工件条目都有 rating_basis：

kind显示名含义
single_circuit单回路能力只有一个回路，内部三相互热仍参与，按该回路各电缆温限求上限。
common_balanced全回路共同能力所有回路同时采用相同平衡 RMS 电流，任一电缆首先达到温限即限制共同电流；独立于原目标负荷。
conditional_fixed_load其他回路固定负荷下的条件上限只调节目标回路，其余电缆保持保存负荷，检查全部电缆温限；各条件上限不能同时使用。

对象还包含 display_name、varied_circuits 和 fixed_currents_a。最后一项按物理电缆 ID 保存固定 RMS 电流（A），不平均不平衡相负荷；条件上限的显示名同时列出这些负荷。单回路与共同能力的固定负荷字典为空。IEC 波形、电磁耦合及不平衡适用边界仍按插件契约执行，不因显示口径而扩大。

case=rating 仍是逐回路结果，case=rating-simultaneous 为等负荷结果，不能合并。新的扫描请求未指定 driver.rating_basis 时采用 simultaneous；明确指定 individual 以及已保存的旧定义保持原口径。output.default_result 提供完整的 key/entity/case/unit 默认选择器，前端必须按四项匹配，不能取第一条 ampacity；失败采样点保留缺口。显示文案取数量自身的 rating_basis.display_name。旧运行/尚未声明的插件缺此字段时不补造口径，旧数据必须显式重跑才能取得新工件。

IEC 0.9.1修正三芯公共内衬T2后，三回排管 YJV22 3×300 在土壤0.6/0.8/1.0 K·m/W下共同能力为417.384/386.973/362.238 A。旧0.9.0的428.635/395.847/369.460 A及固定400 A时181.274 A仅保留为历史口径核验；新热阻与损耗逐项核验见IEC方法说明，历史对照见选型契约。

接口路径不变：研究预检、提交运行、读取运行及运行列表的响应中，cases[].results[] 使用 OpenAPI QuantityResult，其可选 rating_basis 使用 AmpacityBasis；运行的 output.default_result 使用 ResultSelector。响应省略原工件未提供的可选字段，避免给历史输出补 null 而改变内容摘要。新数量示例：

领域 Layer 新增 corrugation_depth（径向波峰至波谷深度，不含金属壁厚，m）与 corrugation_pitch（轴向节距，m）；均须为正值且只适用于 form=corrugated。IEC 另要求声明缓冲层物性和 parameters.corrugated_gap[型号ID] 的有效热阻率及来源，见皱纹护套契约。

热网络交叉校核参考 · MV-THERMAL-0.1.0

以下仅描述热网络参考方法，正式 IEC 能力及适用范围见IEC 方法说明，不将参考方法边界当成全平台边界。

1. 身份与范围

本内核是可审计的稳态热网络 Demo，而非完整 IEC 60287 实现。标准目录仅用于说明稳态损耗和热阻问题的范围，不表示本仓库包含标准全文、逐条实现或已通过合规验证。

范围参考：

  • IEC 60287-1-1:2023，稳态载流量及损耗：https://webstore.iec.ch/en/publication/68118
  • IEC 60287-2-1:2023，热阻：https://webstore.iec.ch/en/publication/68134

适用几何：单回路、三根相同单芯无铠装电缆；同心层；水平或等边三角排列。介质为无限横向延伸的均匀土壤，地表为恒定环境温度，轴向无限长近似。三相承受相同有效值电流，但因散热位置不同，温度及电阻逐相求解。

不支持排管、空气敷设、回填分区、干燥带、多回路、铠装、外热源、接头及端部、谐波、暂态、循环与应急负荷。U₀ 和绝缘尺寸的组合不进行电气强度或绝缘配合校核。

5. 电阻热反馈和载流量

令 b = I²R20,AC α，qambient = I² R20,AC [1 + α(θambient-20)]，则：

在 b × max_eigenvalue(H) >= 1 时，拒绝运行电流的解，提示已超出此线性热反馈模型的稳定范围。不得把该条件直接解释为真实电缆的精确热失控阈值：材料、边界和损伤机制未完整建模。

允许载流量由二分法寻找 max(θA,θB,θC) = θlimit，70 次迭代，搜索上界在奇异反馈阈值之下。若零电流的介质损耗已使温度达到上限，则该工况没有可用正载流量，返回错误。

给定运行电流单独求温度。运行无稳定解时，允许载流量仍可独立有效；运行温度、裕量和损耗返回 null。高于温度限值有明确警告；超过 150 °C 的运行温度额外警告材料线性外推失去工程可靠性。

6. 结果核算

每次求解输出温度方程最大残差。径向层节点温度逐层扣除相应损耗乘热阻；最外节点应与矩阵表面温度一致。线路长度只改变总损耗，不改变无限长截面模型的载流量。

8. 追溯与数据完整性

输入经 Pydantic 规范化后，将完整 JSON 按键排序、无多余空格、保留 UTF-8 编码，计算 SHA-256；输出模型版本和 UTC 时间。SHA-256 识别的是输入内容，并不是数字签名、计算认证或防篡改数据库。

现有工作台以完整输入内容判断结果是否过期。新研究 API 从保存的工程和研究配置生成固定快照，记录输入、方法发行、环境与输出摘要；工程后续修改只把原运行标为历史。新计算书读取指定运行的封存结果，不重新计算，也不接受前端替换结果；旧演示 /api/report 接口保留原有重算行为。

9. 工程应用之前

IEC 插件 1.1.0 的交叉热源子集采用 IEC 60287-3-3:2007 §4.1–4.3；逐式说明、适用范围与附录 A 中间量验证见 交叉热源降额。允许电流的原口径保持，结果另外标明降额前能力、降额后能力、DF和固定热源出处；不把未求解的给定电流三维温度或二维场图作为交叉后的结果。

新建研究默认从选中插件清单复制参数默认值；工程师明确选择“沿用最近研究”才复制同工程同方法最近研究的保存参数（包括显式边界），来源随研究保存。此规则不重写既有研究与运行。旧有限元运行缺 outer_boundary 时，先读封存 bundle.result.outer_boundary.kind，仍缺才按历史截断边界 ambient_truncated 展示，不用当前插件默认值重标旧结果。

研究单项及列表响应新增 latest_module_run_ids（模块标识到已保存运行 UUID 的映射，空标识代表主任务），保留 latest_run。普通入口仅按其模块读取一份详情；显式选中运行优先读该运行，运行历史在打开抽屉后才读取。路由预取与组件详情共享 saved-run 缓存；没有修改历史列表或运行详情路径。

方法对照的 quantities[].title 为可选显示名，读取保存结果的物理量标题；交叉降额前允许电流、降额系数和交叉温升沿用插件清单的标题与 SI 单位，不按扩展键猜中文名称。

工作台保留的热网络是简化参考方法，实现位于插件 plugins/cablesim.thermal-network（原 backend/engine.py，公式与数值不变，由 tests/test_engine_golden.py 经插件执行复现）。按 IEC 60287 拆分计算并经 CIGRE TB 880 算例逐项核对的单芯方法见 IEC60287_SINGLE_CORE.md，已接入保存研究 API 和工作台的显式输入表单，可按直埋子集适用范围选择。黄金值用于重构回归，不是正确性证据。

必须针对目标电缆和敷设方式，用有使用授权的正式标准文本、厂家结构材料数据、独立实现或参考软件以及可用实测结果，分别验证电阻、损耗、热阻、温度与最终载流量。本仓库尚未完成此级别的外部验证；自动测试通过不能据此升级为设计用额定值。
