# 0.5 工程工作台、能力接口与设计依据

## 交付性质

本版本改进人机操作与 AI 共用服务，不把原有原型求解器自动升级为 IEC/GB 合规软件。当前为可信本机使用的工程研究版。原始模型边界见 METHOD.md、ENGINEERING_V04.md、UNIFIED_V041.md。

## 界面与术语

默认入口按任务组织：电缆结构、敷设布置、计算分析、电缆选型、设计依据、企业资料、计算结果、任务记录。属性只在建模任务中显示，助手按需打开；不再同时呈现所有五个停靠区。`?legacy=1` 保留旧停靠界面，仅用于迁移和功能回归。

没有使用“工程智能操作系统”等称谓。前端的工程名、型号、导体、绝缘、敷设环境、边界条件、载流量、损耗、温度限值均对应实际对象或计算量。

字号分为主标题 24–26 px、分区标题 16–18 px、正文/输入 13–14 px、元数据 10–12 px。字体优先 IBM Plex Sans / 思源黑体、数值优先 IBM Plex Mono；默认只匹配已安装本机字体，没有字体时回退。显示设置可明确授权 Google Fonts 在线加载，默认不联网加载字体；可访问该服务不等于离线可用。没有分发或提交字体文件。

新交互使用 Radix Dialog 的焦点管理、Escape 和可访问描述，图表采用 Apache ECharts Canvas，支持范围缩放、图例、实际数据表和 CSV 导出。旧有 Dockview/Konva/TanStack/Three.js 继续复用，不是删除旧能力后用静态截图替代。

## 参数化三维模型

参数化模型从与求解器相同的 Cable 输入生成同心六层。Three.js 采用正交投影、真实米制半径、方向视图、网格、轴向剥切和分层展开；可隐藏各层并导出二进制 glTF (.glb)。文件附输入快照、单位、内外半径和展示长度。

展示长度固定为 360 mm，不代表工程线路长度。导体几何是圆形等效实体，不是绞线制造模型；金属屏蔽为连续等效层。没有任意 CAD 布尔运算、网格生成或通用几何求解能力。

“生成电缆模型”修改只产生服务端提案，人工审查后才保存。只修改截面积不能推断绝缘厚度；其他物性沿用当前工程但明确注明。改变导体后不允许未经确认保留原厂家 R20。模型尺寸、几何碰撞和锁定参数继续由后端校验。

## 共用工程能力执行层

`GET /api/runtime/capabilities` 返回 12 项能力、结构化 JSON 输入定义、效果分类和审批政策。`POST /api/runtime/{workspace}/invoke` 使用：

```json
{"capability":"analysis.buried","expected_revision":1,"request_id":"00000000-0000-4000-8000-000000000001","arguments":{}}
```

能力包括读取工程、生成模型、提出参数变更、解析任务、直埋计算、竖向计算、截面场计算、候选选型、资料原文检索、依据范围检查、依据提案与计算书。界面与受限 Agent 可以使用同一能力契约；旧 HTTP 接口保留兼容，调用的版本/校验/求解服务不再由页面各写一份。

每次调用保存输入版本、参数及设计依据快照、来源标识、执行状态、结构化输出、运行层版本与输入哈希。相同请求 ID 和相同输入重试返回原结果，不再重复求解；ID 用于不同输入、同请求尚在执行、工程已改变均明确拒绝。UUID 只是请求标识，不是身份认证。重启可读取已有记录；意外退出留下的 executing/running 任务不自动再执行，需要查明状态并发起新任务。没有宣称分布式工作流恢复能力。

任务输入与工程引用形成可查询的关系数据；目前不是全面语义知识图谱。`provenance` 只列统一运行层任务和已保存引用，不能把此前未登记的操作补成“完整审计”。

注册表不提供 shell、SQL、任意 URL、密钥修改、解锁或自动批准。审批独立于工具调用，模型不能借注册表自行通过自己的变更。现有自然语言规划器仍是有限操作规划；无云端密钥时明确为本地命令解析器，不是通用大模型。本轮没有真实付费 OCR/LLM 联调，不据此报告识别准确率或任务成功率。

运行、审批、资料入库等功能并未全部迁移为事件溯源系统；云端费用控制、任务中断恢复、多租户权限、所有工具的完整 Agent 自动编排仍需后续开发。

## 设计依据与标准边界

2026-09-08 依据官方题录核对：

| 依据 | 当前程序实际支持 |
|---|---|
| IEC 60287-1-1:2023、IEC 60287-2-1:2023 | 作为既有受限稳态热网络的方法参考；不是全部结构、损耗与散热公式实现 |
| IEC 60502-2:2014+AMD1:2024，含 COR1:2026 | 题录、6–30 kV 产品范围、2026-07 勘误版本记录；未编码全部尺寸/公差/试验表 |
| GB/T 12706.2—2020 | 官方题录显示现行；产品额定电压范围检查；未将修订计划当已发布标准 |
| IEC 60228:2023、GB/T 3956—2008 | 导体标准题录与版本区分；未载入所有导体类别的最大电阻表 |
| IEC 60364-5-52:2009+AMD1:2024 | 标为低压且当前未支持，禁止把它当本中压求解方法 |
| IEC 60853-2:1989+AMD1:2008 | 标为暂态方法未实现，禁止把稳态结果包装成循环/应急结论 |

项目可记录 U、Um、标准标识、敷设环境和依据说明。适用范围检查包括电压顺序、产品范围、尚不支持的标准方法与敷设环境，并提示电阻估算、损耗系数和空气边界。合法记录并不等于符合标准；输出固定 `compliance=not_assessed`。

记录设计依据必须人工审批。选择标准不会悄悄换材料物性、温度限值或环境条件。已选空气域不能调用直埋求解，反之亦然；重新改电压导致依据不适用时，也会拒绝计算。电场几何研究不依赖土壤/空气散热域，但仍不构成绝缘试验合格判定。

计算结果与依据绑定。计算书读取原有不可变运行记录，而不是用当前工程重新算一次；保留该次依据和计算输入，文本经 HTML 转义。历史结果不得当作当前值导出。

未取得完整标准授权正文或可靠参考算例，因此本版本只能称“设计依据及范围检查层”，不能称“已完成多标准载流量引擎”。

## 验证范围

新增软件测试覆盖能力契约、严格输入、锁、审批、幂等重试、并发重复、旧版本拒绝、重启、来源关系、模型几何、厂家电阻确认、标准题录、环境不匹配、不可变报告与脚本转义。既有热平衡、解析退化、网格加密、数值守恒及 OCR/provider 模拟协议测试继续运行。

新增默认界面测试与旧界面迁移回归分别标识。默认界面执行模型生成审批、实际 GLB 文件/尺寸检查、图表数据、跨页未提交输入、设计依据、竖向求解、资料引用、移动导航、axe 可访问性扫描和截图。axe 自动扫描不覆盖全部人类可用性，移动 WebKit 模拟不是实体手机验收。云端接口模拟不是 OCR 真正精度测试。

数学一致性和软件集成测试不替代标准算例、厂家结构实测、商业软件对比与真实工程验证；没有任意给出的“IEC 误差 < 1%”或“AI 原生程度 70%”指标。
