## 本次实际修改

真实共享 `StudioProvider` 原先仅按参数和设计依据相等决定 `current`；手动选择历史记录把 `outputRevision` 设为 null，但该判断忽略了它。因此同版本历史记录、或撤销到相同输入的新版本，可被错误呈现为当前结果。

新增 `outputEvidence.ts`，将输出与返回它的工程 ID、版本、运行 ID、运行输入摘要一起保存。显示当前数值、场图、曲线和计算书之前统一核对上下文、记录绑定、输入快照与设计依据。显式历史选择永远只读；未提交输入、旧版本或缺失证据不提升为当前结果。报告请求在排队后再次核对所选工程与输出，拒绝静默改用后续状态。

当前后端 workspace fingerprint 与 solver input_sha256 的 Python 数字序列化存在 240 / 240.0 差异；它们属于不同摘要域，不能直接相等比较。实现保留运行摘要绑定，并比较解析后的参数快照，不修改旧摘要或冒充重新验证了数字签名。该前端检查不是完整响应 schema 验证，也不是新的求解器、制造数据或工程认证。
