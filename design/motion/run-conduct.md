# 运行传导

- 触发：明确点击运行后。
- 参与元素：带原始 run 图标的运行按钮、按钮至截面的连线、导体与两个铜色细环。
- 关键帧：0→200 ms 铜色描边沿连线传入截面，320 ms 前消隐。两个细环分别在 120→680、240→800 ms 从导体半径 12 扩至外护套半径 36；透明度按 0 / 15 / 75 / 100 % 时点从 0→.9→.75→0。直接改变 SVG 半径，不缩放整个元素，环心始终与导体重合。
- 时长与缓动：总计 800 ms；半径线性，透明度及连线用标准缓动。完成后显示“已发起”，不冒充计算完成。
- 减少动态效果：直接显示“已发起”，连线与截面保持静态，不扩散、不缩放。
- 演示位置：[动效总览 · 运行传导](./index.html#run-conduct)，控件与结果位于同一行组。
- 页面进入后台时取消演示并恢复静态截面，显示“演示已暂停”；可再次点击重播。

配色检查：演示按钮严格沿用 §5.2 的浅色铜与按钮文字角色，文字对比度约 4.26:1，低于小号文字的 4.5:1 目标。素材未自行调整色值；该项需在共享视觉规则中统一处理。

颜色、字号和圆角引用 [前端需求 §5](../../docs/design/FRONTEND_REQUIREMENTS.md#5-视觉规则) 对应的共享变量；时序依据 [视觉素材需求 §5](../../docs/design/VISUAL_ASSETS.md#5-动效规格)。同一演示重触发时取消前次动画与回调，以最后一次操作为准；切换减少动态效果时直接到目标状态。所有数值与任务文本均为演示。
