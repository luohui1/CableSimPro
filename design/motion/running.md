# 执行中

- 触发：任务排队转入执行；演示按钮可开始／停止。
- 参与元素：10 px 虚线状态环、状态文字。
- 关键帧：开始时排队空心点切换为铜色虚线环；0→1200 ms 匀速旋转 0→360°，循环。停止即取消循环，显示静态停止状态。
- 时长与缓动：1200 ms，linear，无起止加速。
- 减少动态效果：静态铜色虚线环与“执行中”文字，停止仍即时生效。
- 演示位置：[动效总览 · 执行中](./index.html#running)，控件与结果位于同一行组。

颜色、字号和圆角引用 [前端需求 §5](../../docs/design/FRONTEND_REQUIREMENTS.md#5-视觉规则) 对应的共享变量；时序依据 [视觉素材需求 §5](../../docs/design/VISUAL_ASSETS.md#5-动效规格)。同一演示重触发时取消前次动画与回调，以最后一次操作为准；切换减少动态效果时直接到目标状态。所有数值与任务文本均为演示。
