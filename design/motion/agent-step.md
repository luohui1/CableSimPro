# 工具调用

- 触发：工具步骤开始与完成。
- 参与元素：读取、预检、提案三行，以及原始 step-read、preflight、proposal 图标；图标始终可见。
- 关键帧：当前行切换到光纤青浅底，对应图标叠加光纤青描线。读取描书页路径，预检描勾选路径，提案描内容与加号路径。每步完成后保留静态原图标，文字切为“已读取 / 预检通过 / 待审核”，再启动下一行；不以通用转圈替换工具图标。
- 时长与缓动：行背景与颜色过渡 200 ms 标准缓动；图标描线 800 ms 线性。演示每步模拟 800 ms，共 2400 ms；实际接入时由工具开始、完成或失败事件驱动，不用演示计时器判定结果。提案生成不等于批准或应用。
- 减少动态效果：演示直接显示三行静态终态；真实工具仍等待实际完成事件，图标不描线。
- 演示位置：[动效总览 · 工具调用](./index.html#agent-step)，控件与结果位于同一行组。
- 页面进入后台时取消演示计时，当前行保留图标并显示“已暂停”；重播从读取开始，不把暂停当成完成。

颜色、字号和圆角引用 [前端需求 §5](../../docs/design/FRONTEND_REQUIREMENTS.md#5-视觉规则) 对应的共享变量；时序依据 [视觉素材需求 §5](../../docs/design/VISUAL_ASSETS.md#5-动效规格)。同一演示重触发时取消前次动画与回调，以最后一次操作为准；切换减少动态效果时直接到目标状态。所有数值与任务文本均为演示。
