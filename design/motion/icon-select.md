# 图标选中

- 触发：点击或用方向键 / Home / End 切换导航、工程目录或工具模式；重复点击可重播。
- 参与元素：当前位置灰底、原始 SVG 轮廓、内部描线。图标形状、描边粗细与布局尺寸保持不变。键盘焦点保持独立的 2 px 外框。
- 关键帧：灰底从当前实际位置移到目标，200 ms 标准缓动；参与动画的原始笔画降到 12% 透明度作为位置参考，对应描线从 0→1 线性显现。单路径 320 ms；多路径每条 200 ms、总计最多错开 120 ms。未参与描线的外框保持完整。结束后移除描线层，恢复完整原图，避免把笔画显现做成单纯颜色加深。
- 结构语义：电缆与材料从核心到外层；线路先路径后节点；计算图标保留外框，描内部字段；精确工具先基准再标记；其他图标描原始轮廓。结束后保留完整静态图标，不循环。
- 状态：导航与工具当前位置用共享灰底；图标总览使用文字色墨线框。图标总览的操作按钮只预览素材，不触发业务操作。不可用项不参与选择，焦点与选中分别表达。
- 减少动态效果：系统或页面开关启用时直接显示目标灰底与完整图标；播放中启用会清除描线层并落到已选中项。页面后台隐藏也落定选中状态。
- 打断：同一区域只保留最近一次选择；快速点击会取消旧描线。窗口变化重新定位灰底；组件销毁清理动画、监听与观察器。
- 演示位置：[动效总览 · 图标选中](./index.html#icon-select) 与 [图标体系](../icons/index.html)。二者共用选择组件。
- 图标页提供“重播选中”与“慢放 3×”；慢放只用于素材预览，不改变正常时长。系统减少动态效果的实际状态会显示在控件旁，启用时慢放不可用。

配色、圆角、字号引用 [前端需求 §5](../../docs/design/FRONTEND_REQUIREMENTS.md#5-视觉规则)；不新增色值。
