# Agent 流式输出

- 触发：一个完整段落已到达。
- 参与元素：新到达的段落。
- 关键帧：仅该段 opacity 0→1，无位移；示例第二段在首段后 240 ms 到达，此间隔模拟到达事件，不作为真实网络节奏。
- 时长与缓动：每段 120 ms，标准缓动。
- 减少动态效果：每段到达即完整显示。
- 演示位置：[动效总览 · Agent 流式输出](./index.html#agent-stream)，控件与结果位于同一行组。

颜色、字号和圆角引用 [前端需求 §5](../../docs/design/FRONTEND_REQUIREMENTS.md#5-视觉规则) 对应的共享变量；时序依据 [视觉素材需求 §5](../../docs/design/VISUAL_ASSETS.md#5-动效规格)。同一演示重触发时取消前次动画与回调，以最后一次操作为准；切换减少动态效果时直接到目标状态。所有数值与任务文本均为演示。
