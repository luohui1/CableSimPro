# 运行失败

- 触发：预检未通过或运行失败。
- 参与元素：10 px 状态点的斜线、原因文字。
- 关键帧：斜线描边进度 0→1；原因 opacity 0→1；不移动状态点。演示原因：缺少导体 R₂₀。
- 时长与缓动：200 ms，标准缓动。
- 减少动态效果：斜线与原因同时立即出现。
- 演示位置：[动效总览 · 运行失败](./index.html#run-failed)，控件与结果位于同一行组。

颜色、字号和圆角引用 [前端需求 §5](../../docs/design/FRONTEND_REQUIREMENTS.md#5-视觉规则) 对应的共享变量；时序依据 [视觉素材需求 §5](../../docs/design/VISUAL_ASSETS.md#5-动效规格)。同一演示重触发时取消前次动画与回调，以最后一次操作为准；切换减少动态效果时直接到目标状态。所有数值与任务文本均为演示。
