# GB 50217 载流量校正

独立方法插件 `cablesim.gb50217-correction`，发行1.0.9。原 `steady-rating` 方法仍为1.1.0；新增 `outdoor-unshaded-rating` 方法1.0.0，独立提供下文受限D.0.7户外无遮阳校正。两者均复用标准依据库0.9.1，不增加标准数值。旧研究保持原固定发行，原方法三个桥架参数全部不提供时仍为原D.0.1–5语义，不静默换表或补布局。宿主只保存输入、依据回执、运行和交付，不包含校正算法；两项能力沿用同一载流量研究工作流，名称由清单提供。

## 输入与适用范围

原 `steady-rating` 能力的基准载流量必须来自可复核的厂家原件或保存的载流量表 / 运行工件，填写原件名称、页码、SHA256，并由工程师确认其为**单根电缆**、同型号、同正常导体温限；直埋工况还须同中心埋深。该确认不等于插件验证了厂家保证值。

原方法的实际温度、正常温限、系统线电压、介质、并列根数和间距取自同一份保存的领域输入，不能用另一份工况给对照补参数。其空气基准为 40 °C，直埋基准为 25 °C。原方法支持均匀土壤直埋、空气单层水平等间距排列，以及下述受限D.0.6桥架布局；不支持排管、回填、日照、强制风冷或外部热源。D.0.7使用独立能力及不同的基准口径，不能自动叠加在原方法上。

### D.0.6 的明确声明与保存布局

原研究参数增加三个无默认值的可选字段：`tray_kind`为`ladder`（梯架）或`tray`（托盘），`tray_layout_source`保留4–2000字的完整图纸、现场或明确研究输入出处与版本，`tray_layout_confirmed`必须为真正的JSON布尔`true`。三项全不提供保持原分支；只提供部分、显式null、空白出处、未确认或用数字/文字代替确认均拒绝，不回退其他表。

同一保存Domain必须是一个空气截面，所有回路使用同一型号三芯电缆、相同实际系统线电压且每回路一根。每根必须明确关联`type:'tray'`的容纳结构；通用`rack`不能证明原表梯架类别，拒绝从名称推断。一个容纳结构只对应一个实际水平层，成员与位置精确一致，层内高度相同、每层至少7根、各层高度不同，1–4层间根数和横向排列相同。每个相邻中心距与同一保存径向结构得出的外径逐项比较，只允许1e-8 m数值噪声，不用工程公差或平均间距套表。原Domain重叠校验继续执行。

实际使用的外径构造、位置、容纳关系、系统电压、正常温限、环境温度与明确为零的日照/风速均须有字段或明确父路径来源。缺原始坐标或波纹深度时不采用模型缺省值。回执保留每层ID、实际坐标/间隙/数量及命中的原始来源路径、原kind和reviewed；布局声明仅标为`declared`/`reference`、`approval:not_granted`。不推断标准层间距，也不将人工确认变为产品批准或厂家实测。

这些字段沿既有Study参数及`input_sources`保存；仍使用原研究保存、预检、运行和回读接口，不增加型号库私有算法或另一套数据。D.0.6与D.0.5只选其中一项，不重复相乘；结果是共同工况下每根的允许电流，不乘总根数或层数。

## 依据获取与追溯

系数通过 v2 `Executor` 调用 `cablesim.standards-basis/lookup`。只接受已核验、唯一命中、含原件摘要和页码的回执。方法契约固定依据库发行摘要；库更新时拒绝静默换表。每个系数保存请求条件、单元格行列、公式输入（如适用）、原件 / 单元格 / 查询工件 / 发行摘要。总系数为各适用系数之积，校正后载流量为基准值乘总系数；表外土壤、根数或间距不插值、不外推。

输出工件 `cablesim.gb50217-correction/1` 包含基准、实际工况、系数回执、总系数、校正结果、适用范围、条款和中文结论。它不输出负荷温度。结果页及客户计算书直接读取保存回执，不重新查询当日依据库。每回路仅支持一根电缆；并列校正结果是所有回路等负荷时的每根允许电流，不是并联电流之和。与 IEC 比较使用研究已有的“同输入方法对比”，只与 `rating-simultaneous` 全回路共同能力配对，分别列出保存运行的允许电流、差值及方法范围，不判定优劣。

## 核验

`python -m pytest tests/test_gb50217_correction.py` 使用真实封签依据库。四组独立手算分别为 400×1.09=436 A、400×1.05×0.93=390.6 A、400×0.96×0.85=326.4 A、400×1.09×0.98=427.28 A；仅验证系数运算，400 A 为明确标记的合成基准，不冒充表 C 的额定值。另验证 D.0.2 公式、表外拒绝、发行变化拒绝、错误字段定位、v2 工件和报告保存回执。

D.0.6新增八格回归复用封签转录：梯架1–4层的400 A机制结果为320/260/220/200 A，托盘为280/220/200/180 A，逐项核记录ID、完整条件、页码、原件/发行摘要，并验证缺声明、缺来源、非接触或不支持布局拒绝，以及真实v2研究保存、运行与重启回读。400 A和这些布局均明确为合成机制输入；原标准依据真实，但这些测试不证明厂家额定值或真实线路正确，也不表示本轮重新亲阅了标准原PDF。完整行业示例仍须提供符合基准口径的真实资料并完成浏览器验证。

浏览器验收：`node scripts/isolated-e2e.mjs verify-gb-correction.mjs`（从 frontend 目录运行；源库由 `E2E_DATABASE_SOURCE` 指定），仅向隔离库写入。

## D.0.7：独立的户外无遮阳校正

“GB 50217 户外无遮阳校正”只执行表D.0.7：**基准已经是按同一实际户外环境温度取得的户内空气单根载流量**，因此只乘这一个系数，不再乘D.0.1/2温度系数或D.0.3–6土壤/分组系数。保存的正常导体温限必须与基准一致，由工程师核对真实原件；不得把未经条件核对的40℃厂家数值直接用于30℃户外输入。

首版只接受一个空气截面、一个三相回路的一根完整三芯电缆，明确整体相位与并联序号1；额定线电压`rating.u`与实际`system.voltage`都必须有来源且相等为1000或6000 V，三芯标称截面须相同。电缆额定15kV即使运行于6kV也不能套用6kV行。原SDK结构验证、实际摆放、字段来源及数值有限性仍执行；缺并联序号不能借模型默认1，精确空出处不能借父级来源通过。

13个三芯数值格用于这一受限执行范围。6个空格不填值、不插值；1kV三芯95→120mm²的0.90→0.98按原值保留，不平滑。另5个单芯数值保留原查询功能，不把单个单芯实例的结果冒充完整三相回路能力。出处为同一GB原件印刷74/PDF84页，全部24格保留历史双路verified记录；本次不声称重新亲阅标准原PDF。

新能力的参数为`baseline_current_a`、`baseline_ambient_k`、`baseline_environment`（仅`indoor_air_at_outdoor_ambient`）、`baseline_source`、`baseline_sha256`、`baseline_page`、`baseline_reviewed`、`outdoor_exposure_source`、`outdoor_unshaded_confirmed`及`basis_release_digest`。不接受旧土壤/埋深/桥架参数，不填写无关占位数字。新增参数类型严格：数值字符串、布尔数值、非有限值、空白出处、非法SHA或页码均拒绝；两项确认须为真实布尔true后才可运行。false只表示未确认的保存草稿，不生成结果或批准。

户外明敷无遮阳及自然通风必须明确且有出处，不能从工程名称或温度推断。本表没有量化辐照/风速轴；因此`solar_irradiance`和`wind_speed`保持未提供或null，不补0或1000 W/m²。首版对任何量化辐照或风速输入明确返回范围拒绝，不声称计算了未消费的换热作用；其他既有材料物性仍保留但不是该表的计算输入。桥架/排管、并列回路、外部热源和强制风冷不在本能力范围。

结果沿原Study/Run与`cablesim.gb50217-correction/1`工件保存完整基准、唯一系数回执、实际条件及来源路径、标准/原件/记录/查询工件/发行摘要；仅有一个三芯回路，输出`single_circuit`允许电流，不乘芯数。可信档为reference、输入为declared，`approval:not_granted`；工程师确认输入不是产品批准。已有客户计算书读取相同保存回执，不重新查表。

`python -m pytest tests/test_gb50217_outdoor.py`的400A为明示合成机制输入，30℃/40℃均在同一人工基准原件中逐条声明，不是厂家额定值。13格查值与手算、全部空格/单芯拒绝、同温不叠表、完整v2及Study保存回读验证功能边界；真实厂家/线路正例仍需要对应来源，不填入发布seed。
